# Arugula 0.56.1

## Changes

- **GitHub webhooks and the App's key move to the platform** (M161,
  #1255). The webhook keeps its address, `/github/webhook` on control's
  site; the hub forwards it to the platform, which checks the signature,
  drops redeliveries it has seen (kept 7 days), and hands the pokes back to
  the hub to relay. The `may()` check and App token minting move with it.
  Daemons see no change on the wire.

## Fixes

- **The platform page has the desktop app's window chrome.** In the desktop
  app on Linux, app.arugula.io's bar is the titlebar, so it now has the
  window buttons. On macOS, the bar leaves room for the traffic lights
  (#1284, found in M157's live checks, #1183).

## Tests

- The Linux app keeps the platform page in its own window, under Xvfb
  (#1279).
