# Arugula 0.60.11

Made as a deploy.

## New

- **Choose what you're pushed about** (#1435). Once a device's push is
  on, **Notify this device** gains three toggles: **Push: Chat** (team
  channels, DMs, pane threads), **Push: Machines** (a pane or an agent
  that needs you) and **Push: Projects** (inbox, deploys, runs,
  workspaces). They're the account's, for every device it turned on, and
  start on, so nothing changes until you choose. Control holds back what
  you turned off; notices about your account (a device or a person
  waiting, a new agent token) always go. `GET`/`POST /api/push/prefs`
  serves them.
