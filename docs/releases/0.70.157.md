## Fixed

- **The Overview's boards as designed** (#3004). Needs you rows no longer show an internal kind name, and the agent panel's head ends in an ellipsis, with the whole line in its tooltip, when it doesn't fit.
- **A board's thread reaches its lead after a rename** (#3008). A post on a board's thread now goes to the pane its lead leads from, not only to the session's name. Rename the lead's session, or restart it under another name, and the board's thread still reaches it. A pane that's gone falls back to the name, as before. The event catalog gains `board.lead.lost` (a board's lead can't be reached), which control emits.
- **A board says when its lead isn't reachable** (#3010). A board whose lead is offline, or whose lead's session was lost, now says so after the lead's name, in `board_read` and on the board's page, instead of naming it as if it were live. A lost lead says how to take the lead again, with `board_write` `lead_board`.
- **Agents answer chat once** (#3012). An agent that answers a chat message in its thread ends its turn with one line pointing there, not a second copy of the answer.
- **Releases go out again, with editor extension 0.2.4** (#3011). Since 0.70.142 every release stopped at publish: the extension's themes changed,
but its version stayed 0.2.3, which the stores already had with other bytes.
A test now fails on a pull request that changes the extension without bumping it.
- **A board fills its tab, and your agent reads as yours** (#2997). A board's own tab now reaches the right panel as a Doc tab does, with no empty column at wide windows, and something your own agent made reads "your agent on <machine>", not "you's agent".
