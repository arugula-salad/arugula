## Added

- **A prototype Doc fills the view** (#2381). A prototype Doc is drawn like an artifact: the title, the one line under it,
and the prototype running in a frame that takes the rest of the view, edge to
edge, and follows it as it is resized. It does the same in the app, on the
Docs page, on the platform and behind a share link. A Doc that doesn't hold
exactly one prototype is drawn as a plain Doc. Tabs and prototype Docs have a
small mark before their title in both Docs lists.
- **A Doc can show its sections as tabs** (#2381). A tabs Doc shows each section's heading as a tab, in a strip that stays at
the top as you scroll and scrolls sideways when the view is narrow. The arrow
keys, Home and End move between tabs. A section still to come has its heading
greyed, and a prototype in a tab gets the whole width. On the platform a tab
is in the page's address (`#s2`), and a share link can name one after its key
(`&s=s2`); choosing a tab never adds a history entry.

## Fixed

- **An agent session says why its branch isn't pushed** (#2380). `read_session`, `wait` with `agent_session` and the list of a project's sessions add the error after "not pushed" (or after the last push time). It clears once a later turn pushes the branch.
