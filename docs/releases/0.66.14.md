# Arugula 0.66.14

Agents can now reach each other's sessions and know what happened. A mention to an agent block arrives as its next prompt. A mention never types into a session mid-turn: without hooks it waits as a card until you deliver it. A mention no session took, or one for a machine that can't read the room, raises a card for the machine's owner. Replies to an agent come in one thread at a time.

## Changed

- **A mention reaches an agent block** (#2076, #611). `@machine/name` naming an agent block by its title is delivered as the block's next prompt, after any turn in progress. It reports **working…** when that turn starts and **read** when it ends, as a terminal session does.
- **A mention never types into a session mid-turn** (#2100, #579).
  - A mention for a terminal whose Claude Code hooks aren't listening is held as a card on that session: "‹who›'s agent mentioned this session in #room". Nothing is typed until you tap **Deliver**, and **Dismiss** drops it. The poster reads "held: no hooks, waiting for ‹machine›".
  - `arugula mentions off %N` silences one session, and `on` turns it back. The poster reads **silenced**. Only you can do either; an agent can't.
- **A mention no session took raises a card** (#2096, #551). It's one card per room in the attention drawer and on the phone, and it counts up ("2 mentions in #agents"). **Open chat** goes to the room. Reading the room, or dismissing the card, clears it. A restart raises it again from the unread mentions.
- **A mention of a machine that can't read the room asks its owner** (#2102, #578).
  - The owner gets a card that names what a grant reaches, for example "Let geek's agents read Acme's channels and issues (including #agents)?"
  - **Grant** makes the grant from your own session (never the machine's) and delivers the waiting mention once. **Not now** keeps it waiting. **Never for this room** leaves it **not granted**, and granting from settings undoes that.
- **Replies to an agent arrive by thread** (#2101, #580). Replies that wait between two turns come in as one message per thread: the thread's first line, then each reply oldest first. `read_thread` with `replies: true` lists your unread replies grouped by thread. A person who replies to an agent now sees the reply's delivery status too.
- **Agents can list a teammate machine's sessions** (#2074, #577). `read_thread` with `machine` lists the sessions you can mention there. `arugulad sharing agent-sessions work|names|none` sets what your machine shows: names by default, and nothing while mentions are off.
- **A running session takes a mention at its next tool call** (#2118, #644). A Claude Code session with hooks used to get a mention only when its turn ended, which in a long turn was a long silence. It now gets it at its next tool call, still never typed into the terminal.
- **A message waiting for an agent says when it will read it** (#2120, #643).
- **A dropped mention says so** (#2097, #613). A mention waiting in an agent block that is stopped, or that ends mid-turn, reads **dropped**, with why. A dropped mention never changes again.
- **Agents are told how to reach each other** (#2092, #574). `post_thread` says a mention is the way to reach a teammate's session, relaying your person's request is fine, and to check what became of it. `read_thread` says how to find the sessions instead of guessing names.
- **A board's lead hears its thread** (#2090). The session that creates a board leads it, and `board_write lead_board` hands it over. A post on the board's thread reaches that session on any machine. The board header says who leads it.
- **A board link in chat unfurls as a live card** (#2104, #627): title, goal, progress, who needs you and who leads it.
- **Boards: the find bar is always there** (#2088), with Label, Person and Clear, at every width.
- **Docs move to the platform** (#2078, #2080, #2095, #2079, #418, #608).
  - While chat is on, your machine copies each Doc to the platform, private to you, and keeps it up to date.
  - `/docs` lists every Doc you can read across your projects.
  - Picking a Doc in a list shows the whole Doc beside it.
- **The shell's bars name their places** (#2107, #2108, #2109, #2112, #2117, #635–#637, #640).
  - The rail is the whole app on every page: Projects, Panes, Swarm, Chat and Settings.
  - Boards, Docs and Agents now live in the bars:
    - a project's bar has Overview, Docs and Agents;
    - All projects has Projects and Boards;
    - a machine's bar has Panes, Docs and Recipes.
  - Projects on the rail returns to the page you left (#2110, #638).
- **The swarm clusters by Repo** (#2111, #639). Its "Project" grouping was a git repository, and is now called one.
- **The Agents page reads like the Docs page** (#2059, #590): Recipes and Team are searchable lists with one preview beside them.

## Fixed

- **A synced passkey opens a new computer on its own** (#2113, #641). Signing in on a new computer no longer needs another device when your passkey is synced.
- **An agent run that ends waiting on background work fails** (#2085, #552). It used to exit 0 with its work stopped.
- **A comment on an issue sent to GitHub answers at once** (#2086, #584, #585), and two comments with the same text both land.
