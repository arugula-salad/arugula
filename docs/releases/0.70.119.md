## Fixed

- **A board's lead starts in its repo** (#2884). Approving Run this board started the lead in the home folder when the project linked more than one repo, so its first turn went looking for the repo. It now starts in a worktree of the machine's clone of the board's repo: the one its rows' pull requests go to, else another of the project's repos, found where the machine's terminals work or in its home folder. The card asks each machine it offers before you approve: its lead goes on one that has a clone, and a machine with none is said on the card. A machine with no clone of any of the project's repos doesn't start the lead, and the card says which repo to clone there.
