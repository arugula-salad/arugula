# Arugula 0.60.2

The first Arugula release made as a deploy (M221): planned in Arugula's
project, approved on an owner's phone with a passkey, and pushed by a
fresh deploy box with a GitHub token minted for that one push. It also
removes Managoat.

## Hosted workspaces

- **Managoat is gone** (#1385). Its Cloud workspaces had one user, and
  their Managoat resources were deleted on 2026-10-23. This release
  removes the code that ran them, their 43 `/api/cloud/*` routes, the
  Managoat flags, and the daemon's proxies to them. Cloud workspaces are
  hosted workspaces now: `arugula cloud create`, and MCP's `cloud` and
  `read_cloud` serve them. Migration 0030 drops the 11 old `cloud_*`
  tables; it isn't additive, so a rollback past this release can't bring
  them back.
- **A turn past the runtime cap pushes you** (#1382). When an agent turn on
  a hosted box runs past E2B's 24-hour cap, the box is woken so the turn
  keeps going, and the workspace's maker gets a push that opens it.
- **Push taps open hosted workspaces** (#1382), as inbox and deploy pushes
  open their items.
- The public preview domain is in both apps' Fly config (#1382).
