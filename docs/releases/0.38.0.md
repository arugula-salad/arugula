# Arugula 0.38.0

Port and editor blocks open on any joined machine from control's page,
with nothing set up on the machine (#150). Before, a block needed the
machine's own block listener, a wildcard name and a certificate, so in
practice only one machine had them.

## Blocks through control

- **A dev server or an editor on any joined machine** (#150): *Open a
  port…* and *Open in editor* work from control's page for every machine
  joined to control, with no `--block-listen`, DNS or certificate there.
  Each block gets an origin of its own, `b-<key>.arugula.run`, served by
  control.
- **End to end encrypted:** the block's page talks to the machine over a
  Noise channel through control's relay, as terminals do. Control serves
  the block's bootstrap page and worker and relays ciphertext; it never
  sees what the block shows. Each block gets a short-lived grant from
  one of your devices, scoped to that block on that machine, with its
  expiry set by the machine's clock.
- **Hot reload, cookies and code-server work:** a block's WebSockets ride
  the page's own channel, and each block keeps its own cookies.
- **Which way it went:** a block opened through control says *direct* or
  *relayed*, and the host menu shows the same for blocks. A block that
  can't open through control (a browser without service workers) uses
  the machine's own block site when it has one, and says so when it
  doesn't.
- **Machines with a block listener keep it:** `--block-listen` and the
  tailnet and dev block sites work as before, for setups without control.
- **Self-hosted control:** set `ARUGULA_CONTROL_BLOCK_DOMAIN` to a domain
  of its own, with a wildcard DNS record and certificate
  ([control-ops.md](../control-ops.md)). Without it, nothing changes.

## Also

- **A WebKitGTK page never calls itself Safari or Firefox** (#817): the
  Linux app's window without its own name is "Arugula app", and GNOME
  Web is "GNOME Web on Linux".
- **The old control host is retired** (#535): control answers only at
  control.arugula.io (already deployed).
