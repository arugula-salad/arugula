## Changed

- **A pr watch takes a head sha** (#2994). `watch` kind `create` takes `head` with one `pr`: a commit's sha, or its first 7 or more hex digits. Only that commit's checks count. Without it, a PR whose head just moved waits for the new head. A `pr` can already be several PRs in one watch.
- **watch types lists pr, session, run and room targets** (#2994). `watch` kind `types` lists, after the bus events, the other targets with an example each: `pr`, `session`, `run` and `room` (with `parent` for one thread and `from` to wake on one person's reply). `board_write`'s description says blockers and order are the `link` tool's, kind `blocks`.
