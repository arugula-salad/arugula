# Arugula 0.44.0

Huddles are gone, and Arugula's VS Code extension is on the Visual Studio
Marketplace and Open VSX (#529), with each release now publishing it there.

## Huddles are removed (#999)

Voice calls on a session (the `huddles` Labs flag, M63) are taken out
for now: the huddle buttons in the session bar, on the phone and in the
chat page, the huddle bar, and the chat sidebar's *Huddles* section.
Control no longer hands out TURN credentials.

- **`huddles` is a retired flag.** A `flags.json` that has it on still
  loads and turns nothing on; `arugulad flags huddles on` says it was
  removed.
- **Mixed versions keep working.** A page from an older daemon that asks
  for a call is ignored, and an older daemon falls back to public STUN.

## The editor extension

- **Install it from your editor.** Search for *Arugula* in VS Code's
  extensions, or run `code --install-extension arugula.arugula-editor`.
  Cursor, VSCodium and code-server get it from Open VSX under the same
  name. `arugula editors install` still installs the copy your daemon
  carries.
- **0.2.1.** No changes from 0.2.0: it's the first version a release
  published by itself (#934).

## Upgrade notes

Editor blocks pick up 0.2.1 the next time they start. An editor where you
installed the extension yourself updates from its marketplace as usual.
