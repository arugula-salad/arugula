# Arugula 0.70.122

A Doc takes up to 60 pictures (it was 20), as long as they come to 40 MiB or less, so a reference board needn't be packed into composite images. A prototype that links to another prototype of its Doc by file name now shows it in place, instead of stopping with "tried to leave the page". watch create takes a board's brd_ id as its room, and a refusal says why instead of claiming cloud keeps no watches. A watch on session.needs_input or session.idle can match by, the login of the session's owner, and me is your person, so a chief of staff wakes only for its own person's sessions.

## Added

- **Session watches can match the session's owner** (#2896). A watch on `session.needs_input` or `session.idle` takes a `by` match: the
login of the session's owner, with `me` for your person. The chief of staff
sets `{"by": "me"}` on its `session.needs_input` watch.

## Changed

- **A Doc keeps 60 pictures, up to 40 MiB together** (#2895). A Doc takes up to 60 pictures (it was 20), as long as they come to 40 MiB or less, so a reference board needn't be packed into composite images.

## Fixed

- **A Doc's prototypes can link to each other** (#2895). A link or `location.assign` to `next-screen.html` shows the prototype titled "Next screen" in the same frame. Anything else a prototype goes to still stops it. Prototypes shown from a share link switch on a link click; a write to `location` there still stops it.
- **Agents can watch a board's thread by its brd_ id** (#2895). watch create takes a board's brd_ id as its room, and a refusal says why instead of claiming cloud keeps no watches.
