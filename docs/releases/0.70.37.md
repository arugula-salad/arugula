## Fixed

- **Mentions reach a daemon started in a pane** (#2666). A daemon started from another daemon's pane, such as a dev daemon, no longer lists a hooked Claude Code session twice, so a mention naming it reaches it instead of the inbox.
- **Team pickers offer only teams that take the machine** (#2663). When you add a machine and pick a team for it, the list now holds only the teams
Arugula will put it in. Adding a waiting machine in one click offers the teams you
own, and those you edit unless they're locked. Move to… on a machine offers the
teams you're in, and only those you own while they're locked.
