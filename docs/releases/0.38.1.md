# Arugula 0.38.1

- **Blocks through control open every time** (#848). A block's frame
  could ask control's page for its grant before the page had started
  answering it (its worker serves the page from cache, so it asks within
  milliseconds), and it asked only once. The block then said "the page
  around this block didn't answer". Control's page now answers the frame
  from the moment it's inserted, and the frame asks again until it hears
  back. Found in 0.38.0's live check on control.arugula.io; control has
  run the fix since then.
