# Arugula 0.39.1

A fix from the live run of conversations (#859): an agent's file edits can
now be approved from the conversation.

## Conversations (Labs: chat)

- **Edits are cards too** (#887): when a linked Claude Code wants to write
  or edit a file, Arugula (Claude Code's IDE) shows the edit as a diff, and
  until now the conversation never offered it. It's now a card with the
  file, its `+N −M` and the diff, and **Accept** and **Reject**. Anyone in
  the conversation can answer it from chat or the phone. Both machines
  need this release: the pane's machine to send the edit, and the
  conversation's home to post it.
- **A card that's no longer asking says so:** answering one that was
  answered elsewhere (at the terminal, say) marks it *Answered elsewhere*
  instead of leaving its buttons.

## Also

- **`arugula` is on PATH in a new terminal** (#883): `arugulad install`,
  install.sh and the desktop app put Arugula in `~/.local/bin`, which stock
  macOS zsh doesn't have on PATH. When the login shell lacks it, they add
  one marked line to its startup file (`~/.zprofile` on macOS).
