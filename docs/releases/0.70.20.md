## Added

- **Agent sessions on a hosted box can watch too** (#2578). A hosted session's agent has a `watch` tool beside its issues and Docs tools: `kind` create (the default), list or cancel, with the same targets as the `watch` tool on your own machine. When a watch fires, or ends without firing, Arugula cloud queues a prompt to the session marked as Arugula's word (`source` `arugula`), and the box gives it to the agent as information from Arugula, not a person, in a fence. A box from before this release shows such a prompt as quoted text "from GitHub, by arugula" until it's updated.
