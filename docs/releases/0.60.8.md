# Arugula 0.60.8

Made as a deploy and approved on a phone: the release platform step 7's
M221 asked for.

## Fixes

- **A browser approved by one you've since revoked can allow runs**
  (#1424). Control's page walked back to your first device through the
  devices you trust now. So a browser approved by one revoked since
  wasn't a browser there: **Allow runs**, **Renew** and **Revoke** were
  disabled with "the desktop app doesn't". Control itself counts a
  revoked device as a link for what it approved before (0.60.3), and now
  the page does too.
