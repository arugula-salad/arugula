## Added

- **Done picks up an agent's ended conversation** (#2911). It's the same conversation, continued where it left off, on the machine it ran on. With no note, it's told the to-do is done. An answer to an approval card or a board question continues it the same way. Can't doesn't start it again: your answer stays on the card. A Codex conversation isn't continued yet.
