# Arugula 0.45.0

A release that takes things out: the daemon's own Managoat integration,
the terminal UI and tmux `-CC`, and compatibility bridges that outlived
the versions they bridged. About 33,000 lines are gone, and the `arugula`
CLI builds without libghostty and Zig.

## Daemon-side Managoat is removed (#1007)

Cloud agents run through your Arugula account on control (DECISIONS.md
"Cloud execution is owned by Arugula control"), so the daemon's own
Managoat sign-in, account view, account stream and *Run on Managoat* are
taken out. Control's cloud agents are unchanged.

- **Gone from the CLI:** `arugula managoat`, `agent --managoat`,
  `agents run --managoat` and `rules --managoat-approvals`.
- **Gone from MCP:** the Managoat kinds and `start_agent`'s `on: managoat`.
  A call that still asks for them gets a message pointing to cloud agents;
  it's never run locally instead.
- **Saved layouts load.** A saved Managoat agent block comes back as a
  stopped, read-only transcript. A saved Managoat account view, or a diff
  or file view of a Managoat sandbox, is dropped at start-up.
- **`--managoat-account-stream`** still parses, so an older service file
  starts the daemon; it does nothing.

## The TUI and tmux `-CC` are removed (#1005)

`arugula tui` and the tmux control-mode front end (`arugula tmux -CC`, for
iTerm2) are taken out. The web client and the desktop app are Arugula's
clients; `arugula attach`, `ls`, `run` and the rest of the CLI stay.

- **A smaller CLI.** It no longer links the terminal engine, so building it
  needs no Zig, and 94 crates leave the build.
- **Older CLIs still work.** An older `arugula tui` or `tmux -CC` attaches
  to a 0.45 daemon as before.
- **A leftover `tmux` symlink** to the CLI now says the front end was
  removed instead of misreading tmux's arguments.

## Expired compatibility bridges are removed (#1006)

- **Daemons before 0.17 are refused by control** with "update Arugula
  (0.17 or newer)". Every daemon since signs the current way.
- **The old `labs` marker file** (#385) is no longer read. Daemons from 0.29
  on moved it into `flags.json` already; a machine that skipped every
  release since 0.24 starts with Labs off.
- **Pre-rename leftovers.** `arugula hooks rename-old` is gone, and setup no
  longer looks for hooks, an MCP server or editor extensions under the
  `illogical` name. Hooks still written as `illogical hook` show as
  missing: `arugula hooks install` adds the current ones.
- **MCP tool names from before #349** (`capture_screen`, `open_port`,
  `read_pr` …) answer "no tool". They haven't been listed since 0.24.

## Upgrade notes

Nothing to do on a machine kept up to date. If you used `arugula tui`,
open the web client (`arugula web`) or the desktop app instead. There is
no app release with this one; the desktop app's daemon updates itself.
