## Changed

- **The board header leaves the lead to the panel** (#3022). The "lead … · machine …" block beside a board's title is gone. The agent panel's Lead tab on the right already names the board's lead and its machine, so the header keeps the title, the meta line and its actions (changed by · Reset, + pane, Filter, Add row, ⋯).
