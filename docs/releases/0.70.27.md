## Added

- **See who reached your machine** (#2627). Each machine has kept its own record of every remote session since the remote-input switch (aru-141), in `remote-sessions.jsonl`, but nothing showed it. Now the machine's Settings page has a Remote sessions section, for its owner only: one row per session, newest first, with who, the role, relayed or direct, when it opened, how long it lasted or that it's still open, and whether remote input is on. `arugulad sharing log`, on the machine, prints the same list, with the daemon running or not.

## Changed

- **Quiet hours pick days as chips, times as one range** (#2605). The kit gains `Weekdays` and `TimeRange` (web/src/shared/ui/schedule.tsx), in the quiet hairline look. Quiet hours' schedule is edited as windows: a day is in one, so picking it in another moves it there.
- **Joining Arugula cloud is one click** (#2626). Getting started's Cloud step no longer asks you to approve a code on a device you already use. Connect opens Arugula cloud with the machine's code, signed in as you (or signing you in first), and Add there puts the machine in your account or a team you own or edit. A browser that isn't one of your devices adds it as the signed-in person, and the machine joins on Arugula cloud's word (aru-141), so there's no account fingerprint to check on the machine afterwards. A browser that is one of your devices still signs the join, as before.
