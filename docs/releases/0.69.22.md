## Added

- **A row says which session holds it** (#2447). The session that starts an agent on an issue holds its row until the issue closes or it lets go with `board_write` `release_row`. The web row and `board_read` say who holds it. A start from another session, on this machine or another, is refused naming the holder; with `take` the row moves and the old holder is told.

## Changed

- **A board's header is a Doc's** (#2463). The title row has the Doc's icon buttons and a ⋯ (Rename…, Edit goal… and, on an
open board, Close epic…). Under the title, "Created 3 Nov · edited 2h ago". The
goal reads as plain text; for someone who can write, hovering it shows a box and
a pencil, and a click opens it for editing in place (Cmd or Ctrl+Enter saves,
Esc cancels). The board's Docs are a column of titles at its right, under the goal
on a narrow board, with Link a Doc. The progress bar is the header's bottom rule.
