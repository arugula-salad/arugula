# Arugula 0.29.0

## Developer settings

- **Each Labs feature has a switch of its own** (#665, #464). Chat,
  huddles, VMs, Fountain, studio apps, chant workspaces, guest ssh, the
  swarm's extra views and Forgejo and GitLab blocks are each a flag, all off
  on a new install. *Developer settings…* in the session menu turns them on
  for the machine, and the page follows at once with no reload. The menu
  offers it once `arugulad flags` has been run on the machine; the desktop
  app's *Daemon* menu has it either way.
- **`arugulad flags`** lists the flags; `arugulad flags chat on` (and
  `off`) sets one from a terminal, with the daemon running or stopped. They
  live in `flags.json` in the state directory and survive updates.
- A machine that had Labs keeps all of it: the old `labs` file becomes
  every flag on, and turning one off leaves the rest.

## Also

- **Sharing says when a grant reaches more than one device** (#663). A grant
  goes to a tailnet login, so everyone signed in as it gets the role; the
  share dialog, `arugula access` and `arugula status` now say when a login
  has called from more than one device, and why a tagged device is refused.
