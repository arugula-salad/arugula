# Arugula 0.63.4

A fix for agent sessions that stopped updating partway through.

## Fixed

- **A long command no longer stops a session's card** (#1561). A box tells control which tool its agent is running, and for a shell command that's the whole command line. Control refused a name over 200 characters and then refused every later update from that session, so its card went to "Stopped responding" even though the turn finished and pushed. Control now keeps a long name cut to 200 characters. One refused update no longer blocks the ones after it, and replays are still refused. This takes effect for every box once control is deployed, whatever its template.
