## Added

- **Swipe between panes on a phone** (#2328). On a phone, swipe sideways to move between a tab's panes, with dots showing which one you're on.

## Fixed

- **Steps arrows point into the bar** (#2326). Bars fill their step's column, so a link to the next step had only a few pixels to travel sideways. The arrow is now an elbow: down from the bar's bottom, near the end that faces the later bar, then a short level run into that bar, which carries the head. An arrow's colour still follows the link's kind: `before` is accent, `blocks` heavy and yellow.
