## Added

- **An agent's chat post that reached nobody says so** (#2957). When an agent posts to a channel without mentioning anyone, and no session leads that room, nobody is told. The agent's `post_thread` reply now says so on its own line, with what to do, instead of looking like it landed.

## Changed

- **Getting started is one screen, Add a machine** (#2952). The Welcome, Agents and Things to try steps went. An agent's adapter is set up from Start an agent and the agent's block. Claude Code's one click ("Use Claude Code with Arugula": its adapter, Arugula's MCP server and hooks) is under Add a machine whenever Claude Code is on the machine and isn't fully set up, and Set it up… on the hooks' note opens it there.
- **No bell on a machine's page** (#2954). A machine's page no longer has a bell in its top bar. What wants you is counted once, on the rail's Inbox. To see what needs you on every machine, open Go to… and pick "Needs you, every machine", or use the sessions sidebar's Needs you.
- **The agent panel beside the Inbox** (#2958). The Inbox now has the agent panel on its right, as the Overview does. Moving through the rows with `j` and `k` shows who asked in the panel: an agent's session, or the chief of staff of that item's project. Answer in the row or in the panel; once answered, it's gone from both.
