## Changed

- **Your machines leave a team with you** (#2394). When someone leaves a team, or is removed, the machines they had put into it
go back to being their own at once: the team's members stop seeing them and
reaching them, and they stop hearing the team's member list and
notifications. Followed threads stop notifying people who can no longer see
the room. An agent session asked in a private channel or a DM, its card, its
row on the Sessions page and its transcript, are for the people in that room.
- **GitLab and Forgejo blocks are on for everyone** (#2398). The `additional-forges` flag (once `forges`) is retired: a link to a GitLab
merge request or a Forgejo pull request or issue opens as a block on every
machine, `capabilities` lists your `tea` and `glab` logins, and the
Forgejo and GitLab webhook routes take signed deliveries. Either name left in
`flags.json` or a team's Labs does nothing.
- **A plainer way to log in to Claude Code** (#2399). An agent block whose turn fails for want of a login used to say to run
`env -u CLAUDE_CONFIG_DIR claude`, which read oddly to anyone who never set
that variable. With Claude Code's default login it now says `claude`, then
`/login`; a block that used another `CLAUDE_CONFIG_DIR` still names it.
- **Waiting for approval names the devices that can approve** (#2401). A browser or a machine waiting to be approved lists your devices that can approve it, with when each was last used, and says plainly when none can.

## Fixed

- **Control keeps up with many more machines** (#2373). The load test of control (#530) found that every signed request from a
machine, and every page's list of machines, read whole tables: at 5,000
machines a page's calls took seconds. They're found by an index now
(at 5,000 machines, 17 ms). Control also keeps more threads than cores, so
a write waiting on the disk no longer holds up the relay, and it records
when a machine was last seen once a minute instead of every 15 seconds.
