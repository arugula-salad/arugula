## Changed

- **A watch's note goes with any target** (#2781). `watch create` took a `note` only with an `event`. It now goes with any target, with the same 200-character limit, and comes back in the message when the watch fires or expires. `match` still goes with an event.

## Fixed

- **Overview board level spacing** (#2782). On a board opened from Overview, a group's title and its count have a gap, and a GitHub item's pointer shows as repo#N on one line.
