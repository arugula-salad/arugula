# Arugula 0.60.7

Made as a deploy, like 0.60.6, and approved on a phone.

## New

- **A hosted MCP endpoint** (#1407, platform step 8's M230). Project
  owners mint bearer agent tokens on the platform page. An agent holding
  one gets typed project operations: issues, threads, runs, deploy plans
  and asks, project secrets' names. It never approves anything.
- **The hub as an issuer** (#1403, M228): OIDC-shaped authorize, token
  and userinfo with PKCE, a JWKS, and key rotation with overlap. It's off
  until control is given `ARUGULA_ISSUER_KEY`.

## Fixes

- **A hosted box checks a standing run grant as strictly as the hub**
  (#1421, M253). It counted the desktop app's old browser-kind windows as
  browsers anywhere in a grant's chain, even as its signer. Now an old
  window counts only directly above a browser it approved before the app
  had its own kind, the rule deploy approvals got in 0.60.3, and the hub
  and the box share that one check.
- **A dialog's end is reachable on a phone** (#1419). An old height rule
  outranked the one sized by `dvh`, so on iOS Safari a long dialog ran
  under the toolbar: a deploy's **Approve with passkey** and **Deny**
  couldn't be scrolled into view. Dialogs now end above the toolbar.
- **A tapped keyboard suggestion replaces the word, not the line** (#1381).
  Gboard edits the terminal's hidden textarea anywhere, and xterm.js read
  every edit as text added at the end. After the keyboard's keys, the
  terminal now mirrors the textarea: back to where it differs, then the
  rest.
- **A check run starting isn't drift** (#1416). GitHub never sends a check
  run's start, so one the reconcile finds in progress came from the poller.
  Counting it made most of the drift on busy repos.
