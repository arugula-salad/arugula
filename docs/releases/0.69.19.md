# Arugula 0.69.19

A chat search link without a project, such as /chat/search?q=deploy&all=1, now opens with All teams still on, not narrowed to your current team. Deleting a team Doc puts it in the team's Trash for 30 days, and an owner, an editor or the person who made it can restore it. A session joins the project its first linked repo belongs to, and stays there. Project… in the session's menu moves it to another of your projects, or out of one. Share a team Doc with a link anyone can open, from its page, the Docs list or doc share, and update or stop it any time.

## Added

- **A 30-day Trash for team Docs** (#2430). A team Doc has no other copy, so a delete is no longer for good straight away. The team's Docs page has a Trash link: each Doc there says who deleted it, when, and how many days it has left, with Restore. After 30 days it is deleted for good. A machine's copy of a Doc is still deleted at once, since the machine holds the original.
- **Sessions belong to a project** (#2434). A session joins the project its first linked repo belongs to, and stays there. Project… in the session's menu moves it to another of your projects, or out of one.
- **A board row says where its PR is in the merge queue** (#2449). On a project whose repo has a merge queue, a row's PR chip reads `queued 12m` while the PR is in the queue, and `left queue: checks timed out` once GitHub took it out, with GitHub's reason in words. A PR that left the queue puts its row in "Needs you", as failed checks do. `board_read` says the same. This needs the platform's GitHub webhook to include merge queue events; a queue's position isn't shown.
- **A team Doc can have a public link** (#2431). A team's Doc can now be shared with a public link, as a Doc on your own machine can. Owners and editors make it from the Doc's page or its row in the Docs list; the page says when the link shows an older version, and Update brings it up to date. Stop sharing takes it down, and so does deleting the Doc. Any member who can read the Doc sees the link; a viewer can't change it.

An agent's `doc share` on a team Doc asks the owner first, with the same card as a Doc on a machine: nothing is made public until they tap Share.

The link's key stays with the Doc on the platform and in the link's address; control only holds the encrypted copy.

## Changed

- **Says when Claude Code's hooks are only partly installed** (#2426). An `arugula hooks install` from an older version can leave Claude Code's
settings with most of Arugula's hooks but not all: no SessionStart, say, so a
mention that arrives mid-turn reaches the agent unexplained. `arugula hooks
status`, `arugula status`, Getting started's Agents step and a once-only line
under the top bar now say which hooks (or read-only permission rules) are
missing, and that `arugula hooks install` adds them without changing anything
else. Hooks that aren't there at all are still an offer, the acting rules
(`--allow-acting`) stay a choice, and when a Claude Code policy blocks the
hooks, that's said instead.
- **Cloud workspace setup sets its env after cloning** (#2443). A cloud workspace's env from its secrets is set for the packages and setup script once its repos are cloned, and clone credentials are scoped to each repo's host.
- **Capture reads a board block** (#2445). A board block's capture is its lanes, then Steps and Chain. If control can't be asked (offline, or no grant), it is one line saying why. A Doc block's capture is its Markdown.

## Fixed

- **Chat search links keep All teams** (#2432). A chat search link without a project, such as /chat/search?q=deploy&all=1, now opens with All teams still on, not narrowed to your current team.
- **A Doc's prototype runs when you switch to it on a phone** (#2438). On a phone, a Doc whose prototype was already there when the page loaded no longer says "This prototype tried to leave the page" when you switch to it. It runs.
- **A failed session push is tried again** (#2448). The session keeps showing why its last push failed until a push succeeds. A new turn stops the retries: its own finish step pushes.
