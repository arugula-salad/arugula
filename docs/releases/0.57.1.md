# Arugula 0.57.1

## Fixes

- **Control's GitHub calls say who they are.** Control's HTTP client sent
  no User-Agent, and GitHub refuses a request without one. In 0.57.0 that
  stopped the forge mirror's poller (backfill and reconcile) and the
  GitHub checks behind linking a repo (#1300, found in M164's live check,
  #1210). Webhooks were unaffected.

## Tests

- doc-share's e2e control skips the disk guard. CI pods share their node's
  disk, and on a full node the guard refused the test's Docs (#1301).
