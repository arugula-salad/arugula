## Added

- **Share several Docs with a team at once** (#2330). Each Doc in Mine has a box (on hover, and always once one is ticked). Shift-click
ticks the range between two as they're shown, a group's box ticks the group,
Space ticks the row you're on and Esc clears. The bar says how many are selected
and shares them with your team (or the one you pick, when you write Docs in
several). Each Doc then says whether it was made in the team, was already there
(with a link), or was refused and why. A Doc written on the platform comes
without its pictures, and says so. The originals stay in Mine.

## Changed

- **Share a Doc from the Docs page without opening it** (#2329). Share asks first, as it did, then makes the link and copies it; a Doc whose link is older reads Update. The Doc stays closed, and a pane that shows it says it's shared at once.
- **Back goes up a level in chat** (#2331). Opening a room or a thread adds a history entry, and Back pops it. Moving
sideways (to another room, or another thread) replaces the entry instead, so
ten rooms later it's still one Back to the list. A thread or room opened by a
link gets the list (and the room) put under it.
- **Every Doc has the same three actions** (#2332). Share on the platform puts a Doc in a team ("Share with Acme", or "Share with…" when you write Docs in several), and reads Update, with a dot, once the team's copy is older. Share on a machine's Docs is still the public link, and its tooltip now says "Share with a link".
- **Steps keeps done rows in place** (#2333). The Steps chart no longer has a ✓ column or a "now" band. Every row, done or open, sits in the column its links put it in, so the chart keeps the plan's shape as work finishes. A done row's title is struck through and its bar stays faded green; an arrow out of a done row is green, because what it waited on is met. Ready rows are still filled bars and waiting rows outlined.

## Fixed

- **A delegation's revoke stays** (#2192). Every owner's revoke is kept, and control says the delegation ended to the
browser, the CLI, daemons and hosted boxes, which remember it. Delegating
again while another delegation stands is refused: revoke that one first.
