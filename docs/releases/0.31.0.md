# Arugula 0.31.0

## Your team's agents (Labs: `agents`)

- **Agents is a place in the bar** (#714), beside Panes, Swarm and Chat,
  for the machine's owner. It was *Agents…* in the session menu. The phone
  still opens it from its sheet.
- **The Agents page says what to do** (#715).
  - Each tab opens with a line on what it is and what its buttons do.
  - Recipes, the team's agents, waiting tasks and grants are cards with
    real buttons: *Run here* in the accent color, *Delete*, *Deny* and
    *Revoke* in red.
  - An empty machine says to make a recipe or add a project. An empty team
    says to offer one, with a link to Recipes.
  - *Offer* is now *Offer to team*.
  - A recipe you just offered shows on the Team tab right away. Before, it
    waited for *Ask every machine again*.

## Agent blocks

- **Agent blocks can be named** (#629): `title` on MCP `start_agent`,
  `arugula agent --title`, and later `arugula call %N set_title
  '{"title":"…"}'` (an empty title clears it). The name survives a restart
  and a resume, and Claude Code's own session title no longer replaces it.
  Without one, the block shows Claude Code's session title, as before.

## Claude Code in a pane

- **`arugula hooks install` also writes permission rules** (#655), so an
  agent in a pane can use the arugula CLI and its MCP tools in Claude
  Code's auto mode. By default it allows only the read-only commands and
  tools (`ls`, `tail`, `wait`, `history`, `read_thread`, …).
  `--allow-acting` adds the ones that change things (`run`, `send`,
  `agent`, `close`, …). It only adds rules and never duplicates one.
  `hooks status` reports each tier as present, partial or missing.

## Also

- A block or command started with `--session NEW` is the new session's
  only pane. Before, it opened beside an empty shell tab (#236).
- A failed PR comment, review, merge or issue comment, or a failed app
  prompt, is recorded in history as an *action*. It no longer shows up in
  `history --failed` or the pane's command status as a failed command
  (#411). `--kind action` lists them.
- Inside the daemon: its core is moving into a library crate,
  `arugula-mux` (#460, #701–#703), and more routes and MCP tools run as
  operations (#576–#578). Nothing changes for you.
