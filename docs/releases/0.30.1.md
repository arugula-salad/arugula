# Arugula 0.30.1

## Your team's agents (Labs: `agents`)

- **A delegated task's work comes back reviewed** (#402):
  `delegate {kind: review}` (or `arugula agents review TASK`) puts the
  task's patch on a copy of your checkout and shows it in a diff block, and
  nothing in your checkout changes. `{kind: apply}` (`arugula agents apply
  TASK`) applies it with a three-way merge, and names the files changed,
  any conflicts left to resolve, hunks that didn't apply, and new binary
  files the task left out. 0.30.0's notes described this, but it wasn't in
  0.30.0.

## Also

- A daemon shutting down stops its panes' scopes after itself, so the
  shutdown can't race saving the layout (#696).
