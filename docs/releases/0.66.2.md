## Added

- **Plane projects** (#1833, #1843, #1842). A project's owner or editor can connect a Plane project in project settings. Control keeps the API key sealed and mirrors the project's work items. Plane's webhook keeps the mirror fresh, and a 5-minute reconcile catches anything a webhook missed. Work items can go on boards and show in the work picker and Triage. A card reads like `ARUGU-12`, with Plane's own state name and a link to the item in Plane.
- **Boards across projects** (#1844). The rail's Boards opens `/boards`: the boards of every project you belong to, grouped by project, with closed ones folded under *Done*.
- **Edit in nvim** (#1847). + Pane and Getting started have an "Edit in nvim" checkbox, which sets the same Editor preference as Settings > Editor.

## Fixed

- **"Finish in your browser" in the desktop app** (#1841). Adding or removing a passkey, linking or unlinking GitHub, signing out everywhere and deleting your account opened control's account page as a tab in the app, where they can't finish. With app 0.32.1 they open in your browser. Older apps behave as before.
- **Review webhook timing** (#1840). A PR review is timed from when it was submitted, so a review on a quiet PR no longer reads as a late delivery.

## Note

- Control serves `editors/nvim` as a git repository at `/git/nvim.git` (prototype, #1813).
- Control gains `tracker_connections` and Plane columns on `forge_items`; both are additive.
