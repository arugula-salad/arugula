## Fixed

- **Watches on a Cloud workspace** (#2877). The `watch` tool used to refuse every call on a Cloud workspace's box, so a chief of staff started there got its staff posts but couldn't arm its doorbells. A Cloud workspace is now one more machine: `watch` and `wait` with an event work for its agent blocks and terminals the way they do anywhere else. Hosted agent sessions keep their own `watch`, unchanged.
