## Changed

- **The first screen asks nothing; hooks offered at a prompt** (#2828). Getting started stays in the command palette (Help), Settings and the phone's sheet, now without its Phone step: Tailscale is in Settings › This machine. A first visit no longer stacks the usage-reports card, What's new or the agent adapter's banner on top of your work; the card asks once you've continued a conversation, or on your next visit.

When Claude Code waits at a permission prompt in a terminal and Arugula's hooks aren't installed, that pane's header says *Answer these from anywhere*. **Turn on** runs `arugula hooks install`, nothing more, and says which file it changed (`~/.claude/settings.json`). Claude Code picks them up the next time it starts. Turned on or dismissed, the offer doesn't come back.
- **Your work is the first screen** (#2830). Your work replaces the Claude Code conversations picker. Each repo shows its three newest conversations, then *N more*. A row's button continues it in a terminal pane, goes to the pane that has it, or, for one running in another terminal, moves it here. `⋯` has *Open as agent block* and *Fork here*. Conversations from every Claude Code entrypoint are listed now, not only the terminal's, the desktop app's and VS Code's; `claude -p` and SDK runs stay out. The Open now and All switches and the cost column are gone from it, and the "Pick up a Claude Code conversation" tip is retired.
- **Your work on your project's Overview** (#2832). Signing in no longer empties the screen: where a new personal project said "Nothing in flight.", its Overview now shows the same Your work list as your machine's page, read from each of your machines directly. Continue here (or Move here) opens the conversation in a terminal pane on its machine. A conversation already open in a pane shows in *Not on a card* instead. A teammate's machines never show, and a team's projects don't list conversations.
