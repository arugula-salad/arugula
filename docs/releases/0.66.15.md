# Arugula 0.66.15

You choose who a message in a thread wakes, and an agent told of a thread hears who's already working on what. Under that, control can now serve a native app, with the switch off for now.

## Changed

- **A thread's composer chooses who a message wakes** (#2127, #647).
  - A To row above the composer starts on the thread's lead: its hosted session, else the first agent in the thread.
  - Pick one or several for that message. Nobody posts without waking anyone, and the choice goes back to the lead after sending.
  - `@wake`, `@machine` and `@machine/session` in the text pick that agent, and the row shows it.
  - An older client sends no choice and works as before. An agent's post ignores it.
- **An agent told of a thread hears who's already on what** (#2129, #649). A mention in a thread says which other agents are in it, and `read_thread` with a thread says what each is on.
- **Control can serve a native app, with the switch off** (#2106, #600). This changes nothing for anyone until `ARUGULA_NATIVE_CLIENTS` is set on the hub.
  - A native app pairs by code, approved in a signed-in browser, as the CLI does.
  - Its signature counts only on routes marked `native` in `routes.toml`. It's refused everywhere else, account security and billing included.
  - Only a device paired as an app can sign. A key taken from a browser's page signs nothing.
  - Decision records: the switch and the signing rule are in aru-131, the app's design in aru-132.
- **A shared core for native apps can reach control and machines** (#2115, #602). `native/core` (#2103, #601, in 0.66.14) now pairs, signs requests and opens encrypted channels. `just testnet test control native` runs it with no phone against a real control, including a daemon from 0.60.0.

## In 0.66.14, not in its notes

These shipped in 0.66.14, but its notes were written before they merged.

- **Agents wake each other only by name** (#2114, #642). An agent's plain reply used to wake the agent that spoke last, so two agents could keep each other going on their owners' accounts. Now it wakes nobody unless it names one, and a chain stops across machines.
- **The strip at the top of a thread shows its agents** (#2124, #646; #2122, #645). Each agent's state, name and what's waiting, from control and the machines that are online.
