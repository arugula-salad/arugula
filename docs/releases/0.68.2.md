A machine can have a shorter name than its hostname, so `@mini/<session>` reaches its agents, and the old name keeps working in mentions.

## Added

- **Who can reach a machine** (#2170). One screen and one command answer "who can reach this machine?": its owner, the team's people by their role from the roster the machine checked itself, each session's shares and their floors, links and when they end, ssh guests, and trust live now. Each row says whose word it is: this machine's, or the team's roster. The machine's agents' powers are listed under them, labelled as Arugula cloud's word. Nothing changes in what's enforced, and the machine stores and sends nothing new for it.
- **The Docs page says where a Doc's copy is** (#2174). After a machine copies a Doc up to the platform, its row on the Docs page says **on the platform**, and the preview's **On the platform** opens the copy. Agents see the same link in `doc list`. The note goes when the machine leaves control, and a team's other owner isn't shown it, since the copy is in the owner's own Docs.
- **Rename a machine** (#2191). Rename a machine from its settings, the switcher's machine menu, or `arugula machine rename <name>`. The new name shows everywhere straight away and survives a reconnect. A name that another of your machines, your team's machines or a teammate's machine already uses is refused. Old names still reach the machine in `@` mentions, unless another machine now uses that name.

## Changed

- **A viewer's drafts** (#2214). A viewer of a project reads its linked repos' pull requests, issues and
drafts, drafts for themselves, and sends their own drafts with their own
GitHub rights, as before. An agent on one of their machines, or running
the CLI as them, makes no drafts on the platform, whatever the machine
was granted: the block's own drafts stay on the block, where the person
sends them with their own `gh`, and its card asks only about the
viewer's own platform drafts, though the block still lists the others.
The CLI's case rests on the CLI saying an agent runs it. A viewer, and a viewer's
machine, discards only the viewer's own drafts. Owners and editors are as
before. A viewer's own comment on an exported issue still goes to GitHub
as them; their agent's stays here.

A cloud workspace names who made it only while that person is in the
project. One a former member made shows no maker, on the page, in the
list and on a chat link's card.
- **A board's chip opens a machine Doc's copy** (#2162). A machine Doc linked to a board (`board_write link_doc`) showed the title it had when it was linked, and opened nowhere with the machine off. Where the Doc's copy sits, a board of your own project, the chip now shows the copy's title and how much is written, and opens the copy. On a team's board the chip keeps the title it was linked with.
- **Compact board cards** (#2221). The Boards page and All boards list boards as compact cards in a grid, as the
design showed. The Open and Done label is gone from the card; a Done board's card
has no progress bar.

## Fixed

- **A board's machine Docs are checked** (#2213). Linking a machine's Doc to a board now checks who may make the link, and a board names the machine only to readers who may reach it.
- **Long-press a link to copy it** (#2216). Long-pressing a link, or text you've selected, in a pane on a phone opens the system menu, so you can copy it.
