# Arugula 0.60.19

Made as a deploy.

## New

- **Issues show their Markdown** (#1468). An issue's description and
  comments used to show only bold, italics, code and links, so issues
  moved from GitHub showed raw `##`, `- [ ]`, tables and `<details>`.
  They're now drawn like a PR's description, with headings, task lists,
  tables, quotes and code blocks, and comments keep their @mentions.
  GitHub's `<details>` folds now fold, in issues and PR descriptions
  alike, and a task's wrapped lines line up with its text.

## Fixed

- **A green PR whose merge state is still unknown isn't called done**
  (#1467). After its base moved, a conflicted PR could show as done on
  its block until GitHub worked out that it conflicts. It now waits, as
  the inbox already did.
