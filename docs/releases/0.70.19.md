## Added

- **Watch sessions, threads, runs and deploys** (#2575). `watch create` takes `session` (a hosted agent session, `ses_…`, until it settles: done with nothing queued, waiting for input, failed or stopped), `run` (a run, `run_…`, or a deploy, `dep_…`, until it ends) and `room` (a chat room's id, with `parent` for one thread and `from` for one person's reply) beside `pr`. Any of them fires the watch, and the message names ids and states only: never a reply's text. Arugula cloud checks again when the watch fires that you can still read what it watched.
- **See which agents are waiting on a PR or a thread** (#2576). Under a PR block (one the mirror has) and at the top of a thread, "Watched by" lists each live watch: whose agent waits, for what (merged, ready, a reply from someone), and until when. It's shown only to members of the project who can read the PR or the room, however public the repo. A session is named only if its owner shares session names with teammates (`agent_sessions`); otherwise it's their agent. Your own watch has Cancel, and its session is told it was cancelled.
