# Arugula 0.66.0

A hardening release across the daemon, control, the web client and the desktop app. Update every machine, and reload any Arugula tab open from before.

```whats-new

  {"id": "local-signin-key", "title": "Signing in on this computer", "line": "A browser on this computer signs in with a key the page keeps for itself, not a cookie. Tabs open from before need one reload."}

```

## Changed

- **Signing in from this computer** (#1830). `arugula web` and the desktop app still open the page signed in, but the page now keeps its own key instead of a cookie, and sends it only to this daemon's API. For 14 days after the update, a browser that signed in before is signed in once from its old cookie and the cookie is deleted; after that the cookie counts for nothing. Programs keep sending `local-token` as `Authorization: Bearer`. Several daemons on one computer can no longer share one page through `--allow-origin` between loopback ports (tailnet daemons are unaffected).
- **Tailscale identity on macOS** (#1830). A daemon believes `tailscale serve`'s identity header only from a connection it can see belongs to root or to its own account. On other Unix systems besides Linux it doesn't use the header.
- **Approvals** (#1827). Control checks that the approving device is trusted now, whatever kind of device it approves, and that the approval was signed within 10 minutes. Removing a device signs out its sessions; a removed browser shows Sign in, and after signing in again says it was removed. A recovery code lets in one device, for good.
- **Trust only moves forward** (#1828). Every daemon keeps the revocations and team rosters it has learned, and only takes a roster version that follows the one it holds. The owner's page checks a team's roster history before signing a change, shows when a member's root changes, and holds changes if it can't keep its record.
- **Following a pane** (#1825). A follow (`tail`, the API, a shared view) ends when its reader can no longer see the pane: a removed share, a pane made private, a lowered role. Channels from a device whose role changes reconnect in the new role. Reading another host's synced history needs the owner, as in History.
- **Links** (#1826). Captures as HTML keep only web links and run nothing. The desktop app opens only `http` and `https` links in your browser. An agent's link question carries only a web link. A page on another site can't open the daemon's API addresses.
- **Agents in a guest's sandbox** (#1823). An agent that runs behind a guest uses only its own tab's tools; the owner's Cloud workspaces, linked repos, devices and other owner tools refuse it.

- **Settings > Editor can remove arugula.nvim** (#1835).

## Note

- `docs/control-e2e.md` now says exactly what holds against control after these changes, and what still doesn't.
- Control gains a `recovery_uses` table and a roster history route (`GET /api/teams/{id}/rosters?since=`); both are additive.
- A control page open from before this update may refuse an approval request older than 10 minutes; reload it.
