# Arugula 0.63.7

Projects have Docs of their own, and an agent session can make one and open issues. Boards pin beside a pane and show agent blocks live, behind the Labs flag.

## New

- **Project Docs** (#1584, aru-118). A project now has Docs on the platform, beside its issues and boards.
  - Its Docs are at `app.arugula.io/p/<project>/docs`, and the project's home lists the newest five. Each Doc has a page of its own, drawn like a Doc block, charts and drawings included, and it updates live while open.
  - Members read them, and owners and editors make, write and delete them. A Doc never leaves its project.
  - They're plaintext, like the project's issues and chat. The Docs a machine's agents make (the `doc` tool) still live on that machine: publishing one to a project is #249.
- **A session's agent makes Docs and opens issues** (#1584). On a cloud workspace box, an agent session gets three more tools:
  - `create_session_doc` makes a project Doc and returns its link;
  - `fill_session_doc` writes the Docs that session made;
  - `create_session_issue` opens a native issue.

  They work with the asker's rights, in the session's own project only. What the agent writes is the session's own, mentions nobody and pushes nobody. A review session only reads. A box needs 0.63.7's template for these.

### Labs: boards

- **Pin a board beside a pane** (#1585). The pane menu's *Open beside* has *Pin a board…*, and agents can `show {kind: "board"}`.
- **Board rows show their agent blocks live** (#1575). A row that points at an agent block shows its state (working, needs input, idle, closed), its branch, HEAD, whether it's pushed, and its changes, as the machine reports them with the `boards.write` grant.

## Changed

- **Finish in your browser** (#1586). In the desktop app, installing the GitHub App and upgrading your plan open the browser, and the window waits with *Check again* until you're back. In a browser they work as before.

## Note

- The server's crates build in a Cargo workspace of their own, `server/Cargo.toml` (#1576). Nothing that ships changes.
- The platform gains migrations `0063` (board block states) and `0064_project_docs`, both additive.
- The macOS desktop app's notification fix (#1583) ships with the next desktop app release.
