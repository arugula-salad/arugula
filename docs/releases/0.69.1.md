## Changed

- **One card for boards, the swarm and board rows** (#2292). A board on the Boards page, the cards of the swarm's lists (projects, issues,
runs, sessions, the inbox, settings) and the rows of a board are one card.
Hovering lifts its edge instead of glowing, a state's tint is the same in every
place, and on Latte a board's rows take the swarm's lighter tint, so a warn row
no longer reads as a brownish grey.
- **Agents stand out in chat** (#2287). An agent's message shows the agent icon in a teal-ringed circle on its avatar,
and its name is its tab, written the way a mention tags it, such as
`aarons-mac-mini.local/ux-improvements`. The old "AGENT" badge and the
separate session name are gone. Click the name to open that pane when the
machine is yours or shared with you; on someone else's agent it is plain text,
and its tooltip says whose agent it is. Search results, threads and saved items
name an agent the same way.

A reaction chip counts people first, then a teal divider and the agent icon
with the agents' count, such as `👀 2 | [agent icon] 1`. Clicking it still toggles your own reaction.
- **Chat's icons match the rail's** (#2291). Every icon now comes from one set, drawn on one grid at the rail's stroke. Chat's bookmark, smiley, magnifier, agent and message-menu icons were drawn thinner on a smaller grid, and may sit a pixel or two differently.

## Fixed

- **Menus' submenu rows line up** (#2293). In a pane's right-click menu and others, a row that opens a submenu (Open beside, Move, Share…) starts its label where every other row does instead of in the middle, and a menu no longer draws two lines together.
