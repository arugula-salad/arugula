# Arugula 0.28.0

## Right-click

- **A right-click opens the pane's menu in every pane** (#658). Over a
  program that takes the mouse (Claude Code, vim, tmux, htop) the browser's
  own menu used to come up instead. Such a program no longer gets the
  right-click; **Shift+right-click sends it on** as a plain right-click,
  with no menu. Shift used to do the opposite there.

## Swarm

- **A workspace's open decision points are cards** (#621): the question,
  a button for each choice, and the answer a model proposed marked as
  such. They reach the phone like gates do, and the card closes saying who
  answered. Needs chant 0.91 or newer.
- **A card's next step is its main button** (#634): *Open* on a card that's
  waiting for you or finished, *Answer…* on a bundled question. *Dismiss*
  sits beside it, quiet.

## Also

- A workspace member's agent sessions come from `chant workspace ls` where
  chant lists them (#590).
- In WebKit on Linux, a device's keys are generated again when the first
  try fails (#524).
