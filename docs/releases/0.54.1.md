# Arugula 0.54.1

Control's chat and Cloud now run on a platform of their own, behind the
hub (the window on 2026-10-21). This release makes the platform answer
without asking the hub each time.

## Control

- **The platform keeps what it learns from the hub** (teams, machines,
  accounts, Labs flags) for as long as it follows the hub's change feed,
  and the hub tells it how far the feed has got on every call, so a change
  you just made is there on your next request. Listing grants, billing,
  chat and Cloud make no calls back to the hub once warm.
- Making an account now records a change in the hub's feed.
