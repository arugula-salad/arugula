# Arugula 0.60.4

Runs and deploys run on hosted boxes: the first real one found E2B's
kernel refusing the rules that keep a run off the daemon's ports.

## Fixes

- **Runs and deploys start on E2B** (#1397). Before a run, a hosted box
  keeps the run's user off the daemon's ports, E2B's own agent and the
  privileged ones on loopback, and runs nothing until it can. It used
  iptables' owner match, which E2B's kernel doesn't have, so every run and
  deploy on a hosted box was refused before it started. The box now uses
  nftables (`meta skuid`), checked live on E2B, and iptables where there's
  no nftables.
- **A deploy approval asks only for your own passkeys** (#1396). A
  password manager could offer a passkey control never kept (from an add
  that failed), and the approval then failed with "that passkey isn't
  registered here".
