## Changed

- **Every key in one place** (#2915). The keys are one table now, so the footer's chips, `?` and the menus' hints all read the same list. A letter is never taken from a terminal or a field you're typing in. The footer under a machine's panes is the new frame's: the place, its keys, how many agents are running and `?`. It no longer shows the machine's name, the focused pane's repository and branch, or what needs you (the rail's Inbox has that).
