# Arugula 0.41.0

Cloud agents now run through your Arugula account and open as agent panes.

## Cloud agent panes

- Choose **This machine** or **Cloud** in the agent launcher. Cloud runs use
  a fresh repository checkout and continue while your browser is disconnected.
- Cloud panes share the agent transcript and approval presentation, appear
  beside machine tabs, return after reload, and show waiting work in the swarm.
- Download saved changes and transcripts from a finished pane. **Run again**
  starts a fresh checkout with the previous task prefilled.
- Manage custom agent definitions, secrets, imports, and run history from
  **Cloud agents** in the account menu.

## Managed execution

Cloud inference is configured by the Arugula platform. Beta access and
per-account run limits are enforced by control. Temporary environments are
removed after results are saved; incomplete file recovery retains the
sandbox for operator recovery.

## Upgrade notes

Direct Managoat logins and execution are retired. Saved local Managoat panes
remain readable as archived transcripts. Import old agent definitions through
Cloud agents and reconnect their secrets; existing remote conversations are
not transferred. Cloud execution processes prompts, repositories, selected
secrets, and results through control and its backend; encrypted terminal relay
behavior is unchanged.
