# Arugula 0.66.12

The Docs page is rebuilt: search, a picture of each Doc's shape, and a live preview beside the list. On boards you can move a row by hand and filter by label or person. A native issue can go to GitHub as a new issue, as you. Chat mentions now reach a machine that was offline, and `send --enter` submits in Claude Code.

## Changed

- **The Docs page is rebuilt on a shared list page** (#2056, #587, #588, #589).
  - A row shows the Doc's title, opening line, age and shape: a segment per section, sized by length and brighter where there's a figure.
  - An open Doc carries its pane (`%3`) and an accent bar.
  - The counts filter the list, `/` searches titles, opening lines and section headings, ↑↓ and `j`/`k` move, and Enter opens. Docs are grouped by age.
  - The preview shows a Doc's facts, opening text and outline without opening a pane. Delete moved behind its ⋯ menu, and Copy link is there for a shared Doc.
  - You can drag the divider. On a phone or in a narrow window the list stands alone, and a tap opens the preview, so opening a Doc from there takes two taps.
- **Move a board row by hand** (#2048, #494). Drag it to another lane, or use its menu or the drawer. Next, Doing and Review set a lane that holds while the work still derives the lane it had when you set it. Done closes a native issue, and moving out of Done reopens it.
- **Find and filter on boards** (#2047, #546, #2050, #547).
  - `/` finds a row on a board and filters the lists of boards.
  - Cards show labels and owners. The find bar has Label and Person menus kept in the URL, and `label:` and `@` work in its box.
  - `board_read` takes `q`, `lane`, `group`, `label` and `person`.
- **Send a native issue to GitHub** (#2044, #62). From the issue page or `arugula issue open-on-github`, a person sends an issue to a linked repo as a new GitHub issue, as themselves. An agent can draft it with `forge_draft` kind `open_on_github`, for its person to send. After that, new comments cross between the pair, each once.
- **`doc.preview`** (#2056). A new operation reads a Doc's first paragraphs without opening it. Read-only MCP tokens can call it, as they can other plain reads. The `/api/docs` list now carries each Doc's summary and section headings, and the `doc list` tool leaves the sections out.

## Fixed

- **A mention reaches a machine that was offline** (#2038, #419). A mention is delivered after its post returns, and sent again when the machine reconnects: within 24 hours, at most 20, oldest first. One that fails again shows as missed.
- **`send --enter` and `send_input` submit in Claude Code** (#2045, #573). The Enter is now its own write after the text. Sent together, they read as a paste, and the Enter stayed inside it.
- **A pane's session name is that pane's own** (#2043, #512). It comes from the pane's hooks. A subagent or a nested `claude -p` no longer replaces the pane's conversation.
- **russh 0.65 and pageant 0.2.5** (#2041). This clears Dependabot alerts on both, including a peer-declared zero maximum packet size stalling a channel (GHSA-fw5c-8223-6h42) on guest SSH and control's jump host.
