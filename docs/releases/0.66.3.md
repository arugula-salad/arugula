# Arugula 0.66.3

Machines and pages keep what they've learned about trust, and a team's lock is an owner's signed word. Boards look like the rest of the platform, and Deploys rows open the right deploy in Safari and the app. Update every machine.

## Changed

- **What a machine has seen stays seen** (#1836). Every daemon, hosted machine and the owner's page records when it first saw each certificate and each removal. A certificate first seen after its approver's removal doesn't count, whatever date it carries. What a machine or page already holds can't be undone by a later answer from control.
- **The page keeps its trust between visits** (#1836). The owner's page keeps the certificates, removals and team rosters it has checked, in one transaction across tabs. If the browser can't keep them, the page lists no one else's machines and signs no team change, and says why.
- **A team's lock is signed by an owner** (#1836). Locking or unlocking a team signs a record on the owner's page; control stores the latest, and machines take a lock change only from an owner in the roster they hold. Control's plain flag can still lock a team but never unlock it. Teams shows an unsigned lock as control's claim. Hosted machines take the lock too, and keep retrying a save of what they've learned if one fails.
- **Boards pages as cards** (#1858). A board is a card with its goal or done note, and each list has stats, like Issues and Docs.

## Fixed

- **Deploys rows in WebKit** (#1857). In the desktop app and Safari, any click on a project's Deploys page opened the last row's deploy. Each row now opens its own, and a deploy's page goes back to Deploys.

## Note

- Control serves `/.well-known/webauthn` with the platform page's origin (#1868), the first step toward passkeys working on the platform page itself (spike S46, #1865).
- Control gains a `teams.lock` column (additive). A page open from before this update can't lock or unlock a team until it's reloaded.
- `docs/control-e2e.md` lists exactly what still assumes an honest control.
