# Arugula 0.46.4

- Session attention badges and action menus have reserved space beside the session details, keeping timestamps readable even in a narrow sidebar.
- Terminal text adjusts its contrast against program-supplied backgrounds. Switching between light and dark palettes no longer leaves normal composer and status text unreadable when a terminal program keeps its own fill colors.
- On macOS, the workspace reserves a full-width strip for the native window controls so the traffic lights no longer straddle the rail and brand. Native tab bars keep their existing measured inset.
- The desktop shell no longer inherits padding and gaps from workspace blocks, aligning its header, sidebar and footer with the navigation rail.
