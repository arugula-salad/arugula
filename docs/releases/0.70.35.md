# Arugula 0.70.35

A mention of a session that isn't there shows one line under the message, and tapping it lists that machine's sessions to pick from.

```whats-new
[
  {
    "id": "mention-chip-one-line",
    "title": "A \"no session named\" chip is one line",
    "line": "A mention of a session that isn't there shows one line under the message, and tapping it lists that machine's sessions to pick from."
  }
]
```

## Fixed

- **A "no session named" chip is one line** (#2661). The chip under a message that `@machine/name` couldn't reach used to spell out
every session on the machine, wrapping into a paragraph. It now reads
"geek: no session named name" on one line, cut short if it's long. Tap it for the
machine's sessions; choosing one puts `@machine/session` in the composer.

A warning for a machine the message never typed (a thread's routing sent it
there) is no longer shown under that message.
