# Arugula 0.60.6

The first Arugula release made as a deploy (M221): planned in Arugula's
project by Jake's agent, approved in his browser with a passkey, and pushed
by a fresh deploy box with a GitHub token minted for that one push.

## Fixes

- **chant→Fly deploys get their result back on a hosted box** (#1411). The
  driver reopened its result pipe (`/dev/fd/3`), which the run user can't
  open when the daemon's user made it, so every chant→Fly deploy stopped
  with "there's no pipe for its result". It writes fd 3 itself now, and
  every program it runs starts with fd 3 closed. Checked live on E2B.
