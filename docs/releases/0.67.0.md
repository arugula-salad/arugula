# Arugula 0.67.0

Several agent blocks on screen no longer freeze the page, and Settings is now one page, on Panes and on Projects. Rows on a board can be dragged between groups, and the Boards page says when your agents can't see it. MCP's tools use the launch's public names, and every old name still works.

## Changed

- **Settings is one page** (#2178, #695, #464). The rail's Settings opens a page on both Panes (`#settings`) and Projects (`/settings`), and each page's index links to the other's sections.
  - Rows sit under what they reach: This device, All your devices, Preferences, This machine, Account and Help.
  - Where a rail has Settings, your user menu goes from 29 rows to 16 or fewer, and the machine menu has one row, **Machine settings…**. Remove arugula.nvim moves from Editor to This machine.
  - A phone's sheet gets a Settings button, and the command palette still finds every setting.
  - A daemon's own page with no account no longer has a user button.
- **Drag a row into another group** (#2169, #664). On a board with groups, dropping a row on another group, or on No group, moves it there and keeps its lane. The whole group shows the drop outline. Dragging within its own group still changes its lane.
- **The Boards page says when your agents can't see it** (#2167, #313). When one of your machines has no Boards grant over the project, a line under the header names it, with a link to Settings → Agents. Only owners and editors see it, and only about their own machines.

- **MCP's agent-session, run and Cloud workspace tools use one set of words** (#2172, #668).
  - `agent_session` (was `session` on `wait`, `session_reply`, `session_stop` and `read_session`).
  - `cloud_workspace` on `start_run` (was `box`).
  - `agent_block` for a Cloud workspace's agent block (was `tab`).
  - `list` kinds `agent_sessions` and `cloud_agents` (were `sessions` and `cloud_tabs`), and `cloud` kinds `open_agent` and `close_agent` (were `open_tab` and `close_tab`).
  - Every old name still works, and results carry the old field names beside the new.
- **The platform's Agents page is now Agent sessions** (#2172).

## Fixed

- **Several agent blocks on screen no longer freeze the page** (#2166). Plain tool output draws as text rather than as a terminal, and older transcript entries aren't laid out until they scroll into view. In a replay of seven real blocks, the worst freeze on load went from 5–8 seconds to under half a second. Output with escape codes or a line-redrawing carriage return still gets a terminal. Older tool cards now open at the end of their output rather than the start, as the newer ones do.
- **The Copy link button is readable in light themes** (#2171, #462). Its text now passes 4.5:1 contrast on boards and Docs, and the button keeps a visible edge in every palette.

## Removed

- **Daemons made resident in a provider's sandbox, and the tunnel that reached them** (#2173). `arugula sandboxes promote` and `demote` are gone, along with the daemon's `--static-dir` and `--provider-token-sha256`. A `provider` host an older daemon kept in its host list is dropped on the next start, with a log line, and your other hosts stay. Opening a shell on a sandbox still works.
