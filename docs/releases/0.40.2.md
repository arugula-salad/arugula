# Arugula 0.40.2

Choose a default tool approval policy for new Managoat conversations on each
machine (#956).

## Agent approvals

- **Remember your Managoat default:** choose Ask or Auto approve in Permission
  rules, or run `arugula rules --managoat-approvals auto_allow`. The default
  remains Ask until you change it.
- **Override one conversation:** choose its Tool approvals in the agent launch
  dialog, or pass `arugula agent --managoat AGENT --permission auto_allow`.
- The setting applies to new Managoat conversations launched through the web,
  CLI or MCP. Existing conversations and local agents keep their policies.

## Upgrade notes

The preference is saved on each machine, not synced across your account.
Managoat's agent policy and runtime sandbox still apply; choosing Auto approve
in Arugula does not grant credentials or change the remote sandbox.
