# Arugula 0.63.3

Agent sessions survive a rebuilt box with their conversation, and see why CI failed. Four Labs flags get clearer names, and four features leave Labs.

## Changed

- **Labs flags rethink** (#1548, native #202–#205, #207; aru-117).
  - **Renamed:**
    - `vms` → `sandbox-providers` (External sandbox providers);
    - `workspaces` → `chant-workspaces`;
    - `forges` → `additional-forges` (GitLab and Forgejo);
    - `agents` → `agent-delegation` (Local agent delegation).

    The old names stay readable everywhere (`flags.json`, `arugulad flags`, `PUT /api/flags/<old>`, control), and control also sends a renamed flag under its old name, so older daemons still read it.
  - **Out of Labs:**
    - **Chat** is a team's setting in control (Teams, "Chat · on"), and the legacy pane-thread import is gone.
    - **Docs** (Doc blocks, the `doc` MCP tool, the Docs page) are on every machine.
    - **Guest SSH** is a machine sharing setting, off by default, that only the owner can turn on, on the machine.
    - **Swarm themes** (Blocks, City, Hive, Timeline) are a swarm setting for everyone.
  - The `studio` flag stays in Labs for now.
- **CI rounds send the failing job's log, and count only required checks** (#1557, native #210).
  - A failed GitHub Actions job's log tail now goes in the session's prompt, fenced as GitHub's text, where before there was only a link.
  - Only checks the base branch requires (its rulesets or classic protection) spend one of a session's two CI rounds. A failure in a check that isn't required is listed as "not required", and on its own sends nothing ("none required to merge; not sent"). With no protection, every failed check counts, as before.

## Fixed

- **A rebuilt box's session keeps its conversation** (#1558, native #209). Before a rebuild deletes a running box, the platform asks it to archive its open agents' transcripts (for up to 10 seconds), so the session on the new box starts from them. When nothing could be archived, the session's card says its conversation was lost with the box. This needs a box made from 0.63.3's template.
