# Arugula 0.70.6

A pane in a project's session shows its project and card above it (under its title on a phone), goes to the card on a click, and can be put on a card, moved to another or taken off. Mention an agent with a screenshot and it looks at it before it answers: it saves the file on its machine and reads it, if its machine may read the room.

## Added

- **Every pane names its card** (#2521). The chip reads *Arugula › #983 L2: the platform knows…*, cut to the pane's width:
the title first, then only `#983`. Clicking it opens the card's place on its
board in Arugula cloud, with the card open; its ▾ menu has **Change card** and
**Take off the card**. A session in a project with no card has a dashed chip,
**Put on a card**, which picks one of the project's open issues by number or
title. A session row in the sidebar counts a card its panes share once.

## Changed

- **A session's project follows its repo** (#2525). A session takes its project from the linked repo of its first pane. The machine now remembers which repo that was. When the repo is linked to another project, those sessions take the new project. A machine checks each such repo whenever it connects to Arugula, so one that was offline catches up when it's back. Nothing restarts: only the session's project changes. A project set from the session's menu, or taken away there, never moves. Sessions whose project was inferred before this release didn't record a repo, so they stay where they are.

## Fixed

- **Agents can see the files you post in chat** (#2526). `read_thread` lists each file's id, and its `file` saves that file next to the
agent's pane for the agent to read. It goes through the same `threads.read`
grant as the room's messages, so an agent whose machine can't read the room is
refused. A mention that reaches a session names the files it carries and says
to look before answering. That part needs an Arugula cloud that sends the
files with the mention.
