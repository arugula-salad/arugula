# Arugula 0.36.0

Programs can say what they're doing: a pane's attention comes from the
program's own OSC 7501 status when it sends one, instead of being read off
its screen (#720). Share a session from your phone (#237). Labs flags now
switch their features off for real (#347), and agents can ask a machine
what it offers (#229).

## Attention from the program itself

- **OSC 7501 program status** (#720): a program that reports `working`,
  `blocked`, `done` or `error` sets its pane's attention directly. A
  `blocked` report with a message becomes a Needs you card with that
  headline; `error` becomes a Failed card. A pane that reports isn't
  overridden by screen rules, while open asks and hook cards still win.
  `working` and `blocked` are dropped when the prompt comes back or the
  program exits; `done` and `error` stay until someone looks at the pane.
  The feature query (`OSC 7501 ; ? ST`) is answered, so programs know to
  send it. Text from programs is cleaned of invisible and bidi characters,
  and notifications from status changes are limited to one per pane every
  10 seconds.

## Sharing from the phone

- **Share session…** in the phone's sheet (#237) opens the same picker as
  the desktop's session menu: a person or everyone in a team, to watch or
  drive.
- **Share** on a swarm card for one of your panes, and on a push when it
  has room for another button.

## Labs flags

- **A flag that's off switches its feature off** (#347): its routes, new
  blocks, MCP tools (even when called by name) and huddle joins are
  refused with a message naming the flag:
  `arugulad flags NAME on`, or Developer settings. No restart needed.
  Anything made while the flag was on is kept.

## Agents

- **`capabilities` MCP tool** (#229): tells an agent what this machine
  offers: the blocks it can open, its tools and Labs flags, the forges
  you're signed in to, whether Claude Code's hooks are live in its pane,
  and whether the machine is joined to control or a team. Allowed outright
  with the other read-only tools.
- **Issue drafts on GitHub** (#229): `draft` takes a repository link
  (`https://github.com/OWNER/REPO` or a git remote) and the link's host
  picks the forge, so an agent can draft an issue or comment on GitHub
  from anywhere.

## Keys

- **Ctrl+Enter** in web and desktop panes reaches programs that use the
  kitty keyboard protocol as Ctrl+Enter (`CSI 13;5u`), not a plain Enter
  (#412). **Shift+Enter** is `CSI 13;2u` under the protocol (#806).
- **Every pane answers a program's kitty keyboard query** (#806), so
  Claude Code and Neovim turn the protocol on in panes watched only from
  the web, and in panes started with nobody attached (`arugula run`,
  delegated agents).

## Also

- **Less traffic for busy agents** (#739): a page is sent an agent block's
  updates only while it shows that block. A page showing something else
  now gets none (before: about 19 KB/s per busy agent).
- **The directory picker** waits for a move into a folder to finish before
  *New pane here*, *New tab here* or *cd there* act, so a quick tap no
  longer opens the pane one folder up (#805).
- Two flaky tests steadied: control-smoke's join (#724) and the summaries
  `ls` test (#725).
- S35: one crypto backend and the hand-written hyper proxies, both no-go
  for now (`spikes/s35-one-backend/`, #463).
