# Arugula 0.27.0

## Security

This release fixes an access check in the daemon
([GHSA-9vfc-56v6-5vqr](https://github.com/arugula-salad/arugula/security/advisories/GHSA-9vfc-56v6-5vqr)).
Someone you had given editor access to a shared session could reach
actions only the owner may take. Viewers and people without access were
never affected. Update every machine you share sessions from: *Update now*
in the page, or `arugulad update`.

## Sharing and teams

Sharing a session got easier to follow (#551):

- *Share* sits on the bar beside the session's name, and a team's role is
  picked beside it. A change of role is said to the person it affects.
- The share dialog says what the other person will see, where a first
  device's fingerprint is, and closes on Escape.
- *+* says which machine the new tab opens on, and someone else's machine
  that just joined your list is named under the bar.
- A pane someone else controls offers *Take control*.
- Joining a team you're already in says what to do instead.
- The Swarm says where its projects come from, and leads back to the panes.

## Pull requests and issues

- Forge blocks render Markdown, with status chips, two columns and actions
  that stay in view (#605).
- An agent's draft of a new issue is shown once on its block, with *Send*,
  *Edit*, *Ask for changes* and *Drop* (#632). A new issue for an
  `OWNER/REPO` from another repository's GitHub clone goes through `gh`
  (#630).

## Also

- On a phone, the sheet's *New tab*, *New agent* and *Conversations* work
  with no session open (#331).
- The desktop app writes panics to a log file (#560), no longer crashes on
  a file picker after an update in place (#557), and on Linux opens
  `arugula://pane/%N` links at that pane (#299).
- The Mac app's daemon keeps its install flags, and uninstalling knows
  about it (#550).
- The MCP tools answer with typed results (#448).
