# Arugula 0.66.10

The panes page downloads far less on each load: a Doc in a tab you haven't opened fetches nothing, and connections that only need summaries stop receiving every block's state. An agent can hold a PR's merge until it's ready, and a mention finds a session by its tab's name. Update every machine: the download savings from a machine start when its daemon runs this.

## Changed

- **Doc blocks draw and fetch pictures only once shown** (#2012). A Doc in a tab nobody has opened no longer renders or downloads its pictures. On a machine with several Docs that was 2.4 MB of a 5.7 MB page load. Opening its tab for the first time fetches them.
- **Summaries-only connections are sent no blocks** (#2013). The fleet connects to each of your machines for its summaries, and each of those connections was sent the full state of every block it could see, which it never read, and then their updates. They now get none, which was another 2.4 MB of that page load. It takes effect on each machine as its daemon updates.
- **An agent can hold a PR's merge** (#2010, #495). `draft` kinds `hold` and `release`, and `hold` on `show kind pr`, keep a PR block from offering its merge until the agent is ready. A hold ends when the agent drafts the merge or releases it, when its pane closes, when the PR merges or closes, or after 24 hours.
- **Mention a session by its tab's name** (#2007, #491). `@machine/name` matches a session's own name first, then the session in a tab with that name, when there's exactly one.
- **Settings, Plane shows recent changes and failed moves** (#2011, #441). Each connection lists Arugula's latest moves and agent writes, and every failed move with Plane's reason and a Retry.

## Fixed

- **A mention inside code mentions nobody** (#2005, #492). An @-handle in inline code or a fenced block no longer notifies anyone, reaches a machine or starts a cloud session.
- **A terminal's session is the conversation running in it** (#2006, #512). A Claude Code terminal's posts could carry the name of a tool or workflow session it had started, and mentions could reach that one instead.
- **The reaction button is a smiley** (#2004, #501). The hover bar's "Add a reaction" drew a ☺ character that read as a small ring; it now uses the same icon as the reaction row.

## Note

- A client that connects and sends nothing now gets its blocks after one to two seconds instead of at once. Anything that sends a message gets them straight away, as before.
