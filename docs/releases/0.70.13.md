## Changed

- **A machine's Doc can move into your personal project** (#2564). A Doc goes where its project goes, a team's or your own. `arugula doc move
--project <your personal project>` and an agent's `doc move` move a Doc from
this machine into it, leaving the usual pointer, so its pane, `doc open` of
its old id and old links follow it there. Someone else's personal project is
refused. Without `--project`, `doc move` still moves to the current project
only when it's a team's.

On Move to project…, with a personal target, Docs on your own machines that
the page reaches can be picked and are moved after the rest, as for a team's.

## Fixed

- **A mention line for each session a post names** (#2565). A post that names two sessions on one machine shows where each mention got to on a line of its own, naming the session.
- **Agents can save any file chat takes** (#2566). An agent in a VM pane still saves up to 20 MB, as its file goes on to the VM
whole. A bigger one is refused, naming its size and the
limit.
- **Agents see the files on replies to their posts** (#2567). When an agent reads the replies to its posts, each reply lists its files the way reading a room does, so the agent can save and read them.
