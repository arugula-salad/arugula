# Arugula 0.37.0

Labs flags can now be set once on control for a whole team or account,
and a machine's own setting still wins (#347). Phones reach the account
menu (#820). Agents get Arugula in one Claude Code plugin install (#229).
VM panes can come from loam (#829).

## Labs flags on control

- **Flags per team and per account** (#347): team owners set Labs flags
  for the team's machines in the Teams dialog, and anyone sets them for
  their own machines under *Your machines*. Control sends them to joined
  machines. A flag a machine's `flags.json` names wins; otherwise the
  account's value, then the team's, then the default. Machines that
  aren't joined don't change.
- **Follow control** in Developer settings (or `arugulad flags NAME
  unset`) hands a flag back to control. Developer settings says where each
  flag's value comes from: this machine, your account or your team.
- **`guest-ssh` and `agents` are only ever set on the machine**: control
  can't turn them on or off.
- The flag lists on control's page show only for people with a machine
  that has Developer settings unlocked.

## Phone

- **The account menu on the phone** (#820): the sheet has *Teams…*,
  *Devices and machines…*, *Add a phone or browser…*, *Sign-in and
  account…* and *Sign out*, so a machine or device can be removed from
  the phone.

## Agents

- **Claude Code plugin** (#229): `/plugin marketplace add
  arugula-salad/arugula` then `/plugin install arugula@arugula` adds the
  MCP server, the hooks and a short skill in one go. It runs your own
  `arugula` from PATH.

## VMs (Labs)

- **loam as a VM provider** (#829): with `--loam-url` (or `LOAM_API_URL`)
  and a project key in `~/.config/arugula/loam-key`, VM panes come from
  loam instead of wisp or Fly's Sprites. Sessions survive a daemon
  restart, and idle machines pause after 5 minutes and wake on the next
  keystroke. Without the flag nothing changes.

## Desktop app (with the next app release)

- **Restarts into an installed update once it's idle** (#561): no window
  focused and, on macOS, no input for 5 minutes, no huddle live and no
  dialog open. Windows come back on the pages they showed, without taking
  focus. macOS and the Linux AppImage; Windows' installer already closes
  the app.
- **An AppImage with its own profile names itself "Arugula app
  (AppImage) on <host>"** (#817), so it's told apart from the .deb in the
  device list.

## Also

- **Opening `#developer` or a pane link as control's page loads** waits
  for the machine's connection instead of asking control and showing
  "HTTP 200".
- The daemon's dial, sites and provider tunnel share one HTTP/1 client
  helper (#811).
- CI: the systemd tests run again, on runners that boot systemd, and fail
  instead of skipping when they can't (#735).
- Flaky tests steadied: a new session's block test on macOS (#819), the
  released client fixtures (#818), testnet's team join, and the Labs flags
  e2e spec.
