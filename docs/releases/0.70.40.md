## Added

- **Agents run on Windows** (#2672). Agent blocks on Windows used to fail at once with "agents don't run on Windows yet". The daemon now starts the agent's adapter itself, with no console window, in a job object: closing the block stops the adapter and every program it started, `claude` included. mise's Node is found in `%LOCALAPPDATA%\mise` there.

One difference from Linux and macOS: an agent doesn't outlive a daemon restart on Windows. The block starts it again and reopens its conversation, as after a reboot (or waits for *Resume*, by its restart setting).

## Changed

- **Move to project lists the project's sessions** (#2671). A session a picked repo placed still comes with it, ticked and locked, even from a machine that's offline (it moves when the machine is back). Any other session on your own online machines can be ticked by itself: it moves to the new project as set by hand, so its repo doesn't move it back. Sessions on someone else's machine, or on an offline one, are listed without a box, saying why. Before you move and Comes along say who will see the sessions once they've moved.
