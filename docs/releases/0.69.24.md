## Added

- **Settings for each team, and project overrides** (#2476). A team's settings are at `/t/<team>/settings` and Personal's at `/settings/personal`. Plan and billing moved there from your account's settings, and team chat's owners-only switches from a project's. In Project defaults, change any project's value from one table: changes wait for Save.

## Changed

- **Agents work in their session's project** (#2477). When a tool isn't told a project, it takes the first of these that has one: the project of the issue the agent was started on, the project its session is in, the project its clone's GitHub repo is linked to, then your default project. Issues, boards, links, Plane writes, agent sessions, `start_agent` and new Docs all follow this order, and the answer says which step chose. The session's step needs an Arugula control that knows it.

## Fixed

- **Opening the project menu no longer hangs the page** (#2482). The bar's project menu froze the page as it opened. It now opens at once, and the bar's other menus redraw less.
