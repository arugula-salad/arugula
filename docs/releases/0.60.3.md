# Arugula 0.60.3

Accounts whose browsers the desktop app's window approved before 0.59.0
can approve deploys and add passkeys again.

## Fixes

- **Browsers an app window let in before 0.59.0 count again** (#1394).
  0.59.0 stopped counting the desktop app's window as a browser, since a
  program on its computer can read its keys. That also cut off every
  browser an app window had approved before then, so some accounts had no
  device that could approve a deploy, add a passkey or raise an owner, and
  no way to get one. An app window's approval now counts on the way back
  to the account's first device if control stored it before 0.59.0
  shipped (control's own record, which nobody can backdate). The window
  itself still can't approve, and what it approves from now on doesn't
  count.
