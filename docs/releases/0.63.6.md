# Arugula 0.63.6

A shorter pane menu, and agent sessions that are easier to work with: they speak as themselves in their threads, end with their real answer, run on Opus, can read their project's issues, and park when idle.

Most of this release was found, and some of it built, by running real work through agent sessions on Arugula's own cloud workspaces (native #215).

## New

- **A shorter pane menu** (#1568, #1573). Right-clicking a pane opens a menu of about 13 rows instead of about 35.
  - Copy, Paste, Select all and Clear scrollback come first, then the splits.
  - Open beside, Move, Share, Thread and Pane settings are submenus that open in place. → opens one and ← closes it.
  - The menu takes keyboard focus when it opens, and Escape gives it back to the pane.
  - **Forget history** asks for a second click before it runs, and the command palette asks you to type "yes".
- **A session's agent can read and comment on its project's native issues** (#1567, native #216). On a cloud workspace, the agent gets two tools: read the project's issues, and comment on one.
  - They work with the asker's rights, in the session's own project only, and the comment is the session's own. They need no login and no token: the box knows the caller by the session user its connection comes from.
  - Agents that don't support HTTP MCP (Codex today) don't get them.
- **Sessions run on Opus, and say so** (#1574). Claude Code sessions now start on Opus 5.5 instead of whatever the account's default is, and the card shows the model.
  - A project's **Agent model** setting picks another (Opus, Fable, Sonnet or Haiku), and "use sonnet" in the ask picks one for that session.
- **Idle sessions park** (#1569). A box now runs 3 sessions at once and holds up to 6.
  - A finished session that's been idle for 30 minutes is parked: its agent closes to free memory, and its checkout and conversation stay. A reply opens it again where it left off.
  - New sessions spread across awake boxes, by how many sessions each is running.
  - Boxes made from 0.63.6's template hold 6. Older boxes hold 3, as before.
- **Tools for session users** (#1571). A cloud workspace's setup can publish tools to `/opt/arugula/tools` with the new `arugula-tools` helper, and every session's agent finds them on its PATH. There's also an opt-in sccache build cache per session user, and `packaging/hosted/examples/arugula-dev-setup.sh` is an example setup for Rust and web work. Before, a setup that installed tools in its own home left session agents without them.

## Changed

- **A session's answers and reviews are its own messages** (#1572). In the thread they show as the agent session, with its own look, not as the person who asked.
- **A prompt typed straight into a session's block shows in its thread** (#1572), as one line: "Asked in the session by …".
- **A turn's answer is its final message** (#1570). The thread gets the agent's last message of the turn, not everything it said along the way. A long one keeps its end, where the summary is, behind a link to the session.
  - A turn that pushed ends with "Pushed N commits to `<branch>`".
- **An answered question in a thread says who answered and what they picked** (#1574).

## Fixed

- **A session's posted answer no longer starts with fragments of its earlier messages** (#1570).

## Note

- The platform gains migrations `0061_session_model` and `0062_session_users`, both additive.
- To get six session users and the tools directory, rebuild a cloud workspace on this release.
