# Arugula 0.63.6

Agent sessions on cloud workspaces get more room and more say: a box runs three sessions and holds six, parking the idle ones; sessions run on the strongest model and show which; their answers read as the session's own, end with what the box pushed, and keep their end when they're long. A session's agent can read and comment on its project's issues, and session users can run the tools a workspace's setup installs. The pane menu is shorter, with the rest in submenus.

## New

### Agent sessions

- **Three running, six held** (#1569, native #215). A box runs at most three sessions at once and holds at most six, each with its own user, checkout and conversation.
  - A done session that has been idle for 30 minutes is **parked**: its transcript is archived and its agent closed, and its checkout and conversation stay. A reply opens it again on the same user and picks up the conversation. The card says "parked".
  - Replies to parked sessions get a running slot before new sessions do. The pool passes a box by once it holds six.
  - A box rebuilt on this release has six session users. One on an older template keeps holding three, so nobody has to rebuild.
- **Sessions run on the strongest model and say which** (#1574). Claude Code sessions now ask for Opus explicitly instead of the account's default, which on the boxes was Sonnet. The card shows the model the session runs on (`· Opus 5.5`).
  - A project's **Agent model** setting (owners and editors) picks `opus`, `fable`, `sonnet` or `haiku`.
  - A word in the ask wins: "use sonnet", "with haiku". Codex runs its own choice.
- **A session's agent reads and comments on its project's native issues** (#1567, native #216). Two tools, `read_session_issues` and `comment_session_issue`, served to the session's agent by the box's daemon. The project is always the session's own, the agent acts as the person who asked, capped by their role, and a review session can only read. Claude Code only: Codex has no HTTP MCP yet.
- **Tools session users can run** (#1571). A workspace's setup can now install tools in `/opt/arugula/tools`, which every session user has first on its PATH, with the new `arugula-tools` helper (`link`, `rustup`, `wrap`, `env`, `as`). Before, tools the setup installed in `user`'s home were "Permission denied" to sessions. `packaging/hosted/examples/arugula-dev-setup.sh` sets up Rust, Zig, just, nextest and pnpm this way, with an sccache build cache per session user. See "Session users' tools" in docs/control.md.

## Changed

- **A session's answer is the agent's final message only** (#1570). Before, a long turn posted its status lines and plan, and the real summary was cut off; an echoed user message could also start the answer with fragments of earlier ones.
- **A long answer keeps its end** (#1570). Past 2,000 characters it starts with a link to the whole message in the session, then the end.
- **The thread always shows a push** (#1570). A turn that pushed ends its answer with "Pushed N commits to `<branch>`", from the box's report, not the agent's words.
- **Answers read as the session's own** (#1572). A turn's answer and a `@codex review` are posted as the session, drawn with its agent ("Claude Code · session 1a2b3c4d") and a badge, not as the person who asked. When a later session reads the thread, they're credited to the session.
- **Prompts typed in the session's block show in the thread** (#1572): "Asked in the session by <who>: “…”", the first 300 characters.
- **An answered ask says who answered and what** (#1574): "<who> answered: …", "allowed it", or "denied it: <reason>". Agents reading the thread see it too.
- **The pane menu** (#1568, #1573). A terminal pane's menu starts with Copy, Paste, Select all and Clear scrollback, then Split right and Split down, Copy working directory and Attach file…, with Close pane last: about 13 rows instead of about 35.
  - Open beside, Move, Share, Thread and Pane settings open as submenus under their row. → opens one and ← closes it.
  - Copy is disabled with nothing selected, and Paste is offered only when you may type in the pane.
  - **Forget history** is under Pane settings and asks you to click again to confirm.
  - The command palette still lists every row by name.
