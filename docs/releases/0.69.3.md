## Added

- **A design reference page** (#2301). The platform app has a page at `/design` that draws type, colour, buttons,
headers, rows, chips, cards, icons, dialogs, menus, empty and error states and
spacing with the real components, in Slate or Latte. Open it from the command
palette (*Go to Design reference*) or from the link at the top of
`docs/design/language.md`.

## Changed

- **Arrows, closers and ticks are icons** (#2299). The ▾ ▸ ‹ › on menus and folds, the × on dialogs and chips, ⋯, ↗, ✓, ↻ and ✎ are drawn with the same icons as the rail, at four sizes, so they line up with the text beside them in every font. An icon-only button has both a hover tip and a name for screen readers. A Doc prototype's kit has `ar-icon` and `--ar-icon-xs` to `--ar-icon-lg` for the same.
- **The last one-off badges are the app's chips** (#2300). A pane's thread button is a count and its attention a state chip; the
"unused" device mark, the Cloud workspace label and the palette's "on" are
tags. An agent's mark on an avatar and an item's reviewer mark share one
class, and the update button, the terminal's toast and the agent hooks offer
are named for what they are.
