# Arugula 0.62.1

The hosted template builds again, so boxes get 0.62's agent sessions (#1534). This release also brings the second round of UI consistency fixes (#1532).

## Fixed

- **The hosted template builds** (#1534). 0.62.0's template build waited forever for a sandbox id that a build doesn't have, so no box got 0.62's daemon and an `@arugula` session was never taken. The box's service now waits 10 s at most. If the daemon doesn't answer within a minute at build, the start command logs why and runs the daemon itself.
- **Block bars leave room for the pane's drag grip** (#1538), so their last button can be clicked in a narrow pane.

## Changed

- **UI consistency, round 2** (#1532, native #162–#186):
  - **Chat:** scoped by project, with DMs under their project; it sits in the page frame, and search highlights matches.
  - **Issues and Runs:** the issues list loads without waiting for chat, label menus offer every label, and closed rows say who and why. Runs filter by trigger, Deploy included; ended runs say why, and spec instructions render as Markdown.
  - **Project and account settings:** one rule for empty sections, a section index, and the team chat switches moved to the team project.
  - **Deploys and Inbox:** digests are readable, and the inbox gets a deploy card and an unseen count in the bar.
  - **Control:** one session menu, tabs sized to their names with an overflow menu, and Swarm names that keep their case. Needs you rows are titled by subject. The machine picker lists online machines first, and the command palette reaches every dialog. Every block has its own icon, one bar and one error and loading look.
  - **Everywhere:**
    - one state chip;
    - one time format: relative, with the full time on hover;
    - corners that follow Appearance → Corners;
    - shadows that lighten on light palettes;
    - "cloud workspace" as the noun, and "Control" in the bar;
    - menu buttons that announce themselves and take arrow keys;
    - a 390px phone pass, with columns folding at 700px and long project names truncating.

## Note

- "Hosted workspace" is now "cloud workspace" in the UI, CLI help and MCP tool text. Routes, ids and wire strings are unchanged.
- DMs on the platform page moved to `/p/:project/dm/…`. Old `/dm/…` links redirect.
- To get 0.62's agent sessions on an existing cloud workspace, rebuild it once this release's template is out.
