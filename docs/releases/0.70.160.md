## Added

- **Answer an ask from a chat thread** (#3017). When an agent asks you on a board row, it gets the ask's link to post where you're talking, such as the board's channel.
The thread shows the ask as Needs you does: the question, its options with the recommended one marked, and why.
Answering it there answers the row, so Needs you and the agent hear it too, and the card then shows who answered and what.
Opened in a browser, the link goes to the board at that row.
