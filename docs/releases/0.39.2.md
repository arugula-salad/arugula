# Arugula 0.39.2

The rest of the follow-ups from the conversations live run (#859), and
fixes for a few races that CI kept catching.

## Conversations (Labs: chat)

- **A turn nobody prompted isn't one** (#888): once a linked pane has been
  prompted, a turn that starts without a prompt and ends with no summary
  and no question no longer posts a "worked 2s" line.
- **A link starts from its ask** (#895): linking a pane while it's already
  asking something puts that question in the conversation at once, instead
  of waiting for the next one.
- **Small things** (#889): turn summaries render Markdown; chat shows an
  owner's short name rather than their email; the phone's Chat page has a
  search button.

## Also

- **An open question keeps wanting you** (#912): a command start that
  reached the daemon after a question no longer turned the pane's
  "needs you" dot off while the card was still up.
- **A device the daemon doesn't trust yet hears so** (#913): a browser
  approved a moment ago that reached a machine before it had heard of the
  approval was hung up on, and settled on the relay for good. The daemon
  now says it doesn't trust the device yet, and the page tries the direct
  route again shortly after.
- **The editor's paused card keeps its line** (#903): in VS Code, the
  card for a paused debugger switched from where it stopped to a frame in
  Node's loader after half a second.
