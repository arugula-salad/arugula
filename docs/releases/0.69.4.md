## Changed

- **Section headings as written** (#2302). Section headings show their titles as written, not in capitals.
- **A dialog's explanation is plain text** (#2303). Appearance, Sandboxes, the Doc share dialog and the other dialogs that explain themselves in a line now draw it as dim text. The tip chip keeps its own look.
- **A Doc's three actions** (#2305). In a Doc open in a pane, the buttons now end the bar instead of sitting mid-bar, and stay there in a narrow pane. Share reads "Update the shared copy" when the shared copy is older. The Docs page's preview has all three too: Share opens the Doc beside first, then its share dialog.
- **Docs use a wider column** (#2306). A Doc's column is 68 characters wide in a narrow pane, 88 from 1100px of width, and 100 from 1500px. It follows the Doc's own width, not the window's, so a Doc in a pane beside a terminal stays as it was. The Docs page and a shared link get the same. A phone is unchanged.
