# Arugula 0.40.1

Fountain is now called Managoat (managoat/managoat ADR 0082), and Arugula
uses the new names (#954). Nothing you set up stops working: every old name
is still read until Managoat ends its deprecation window (managoat#2776).

## Managoat

- **The new names come first** (#954): `arugula managoat …` (login, status,
  logout, agents), `arugula agent --managoat`, `arugula agents run
  --managoat`, `arugulad --managoat-account-stream`, `MANAGOAT_API_KEY`,
  `MANAGOAT_BASE_URL`, `MANAGOAT_PROFILE` and `~/.managoat/credentials`.
  The web, the phone and MCP say Managoat; MCP's kinds are `managoat`,
  `managoat_agents`, `managoat_agent` and `managoat_conversations`.
- **The old names still work:** `arugula fountain …`, `--fountain`,
  `--fountain-account-stream`, the `FOUNTAIN_*` variables (the daemon log
  warns once) and `~/.fountain/credentials` when the new file is missing.
  Saved blocks of type `fountain` / `agent: fountain` load as Managoat, and
  MCP calls with the `fountain` names are still accepted.
- **Your sign-in moves by itself:** on its first start the daemon renames
  `state/fountain/` to `state/managoat/`, keeping the login and the account
  stream's place.
- The docs page is `docs/managoat.md`.

## Upgrade notes

- Rolling back to 0.40.0 after this release has run: blocks saved as
  `managoat` aren't known to 0.40.0. Move `state/managoat/` back to
  `state/fountain/` if you roll back.
