# Arugula 0.46.3

Control's desktop workspace is closer to the #1018 visual direction:
quieter blue-gray borders, clearer selected sessions, aligned session
counts, distinct working tabs, and pane controls grouped on the right.
Pane headers give titles more room, with compact named type icons and
secondary repository metadata hidden before it crowds the title.

Appearance now offers **Use Control look**: near-black Slate, cyan focus,
flat surfaces and soft corners in one click. Existing palette choices
remain yours; select this preset to switch an older saved theme.

Terminal sizes, running processes and pane layouts are unchanged.
