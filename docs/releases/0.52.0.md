# Arugula 0.52.0

A Cloud workspace as a block (#1117): an agent puts one of your Cloud
workspaces beside its pane, and you watch and drive it there.

## Cloud workspace blocks

- **`show` kind `cloud_workspace`** opens a Cloud workspace (`cw_…`, and
  optionally one of its tabs) beside a pane. An unknown workspace or tab
  opens nothing.
- **The block** has an Overview (status, repositories, tabs, Changes, and
  the setup log when setup failed) and a tab per agent, the same views as
  control's page: read the transcript, prompt, answer approvals and
  questions, interrupt. It follows control live while it's on screen.
- **Who can:** anyone who can edit the session drives it; a viewer sees
  its status and tabs only. *Open* shows the workspace on control's page.
- The daemon reaches control for the block as the machine, and only for
  that workspace; deleting it, or reaching another one, is refused.

## Fixes

- `read_cloud` `git_status` and `diff` without a `path` read the
  workspace's first repository, and name any others, instead of failing on
  the machine's home directory.
