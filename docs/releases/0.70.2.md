# Arugula 0.70.2

A Doc on your machine can move to your team's project from the Docs page, `arugula doc move` or an agent's `doc move`, and its open pane and old id follow it there. Your machines' Docs stay on your machines, with no copy in the cloud, and a Doc you give a team is moved there, not copied. A room or thread opens where you left it, and the view no longer jumps when the keyboard opens, you send, or pictures and older messages load.

## Added

- **Move a Doc to your team** (#2492). The team Doc is made from the Doc as it is now, with its sections, pictures and layout, and the machine keeps only a hidden pointer to it: the Doc leaves the machine's Docs list. A pane showing it, an agent still filling it, `doc open` of its old id and a board's link all go on with the team's Doc. A public link made before the move keeps working, as it was. If the team Doc can't be made whole, nothing moves.

On the platform, a personal Doc's Share with <team> is now Move to <team>…, and asks first: the team will own it, its link keeps working, and nobody keeps a copy. A Doc written there moves in place, keeping its id, thread and pictures.

## Changed

- **The CLI and agents say "Arugula cloud"** (#2499). The web client moved to plain words in #2134 (#598); the command line, the
desktop app's menu, the daemon's messages and the text agents read follow
(#663). `arugula status` says "Not joined to Arugula cloud", and the help for
`arugula login`, `join`, `pr`, `issue` and the rest says Arugula cloud too.
Settings and what only the web shows are on "your machines page". Routes,
flags, origins and names are unchanged.

## Fixed

- **Chat keeps its place** (#2498). Leave a room scrolled back in the history and come back, on the same device: it opens at the same message, at the same place. A room left at the bottom opens at the bottom, and a room with unread messages still opens at the bottom with its New line. Threads do the same.

The view also holds still while the phone's keyboard opens and closes, when you send a message, and when link previews, pictures or older history load in above or below: at the bottom it stays at the bottom, and further up it keeps the message you were reading where it was.
- **Applying a delegated patch on a dirty checkout** (#2497). `delegate {kind: apply}` on a checkout whose files had uncommitted changes
said the patch applied "only in part" even when every file landed. It now
says it applied, and adds that it did so without a three-way merge because
those files (named) had uncommitted changes. "Only in part" stays for a
patch that really left hunks in `.rej` files or conflicts to resolve.

## Removed

- **Docs no longer copy to the cloud** (#2494). A machine no longer copies its Docs up to your Docs on the platform, and **Your Docs on the platform** is gone from Teams. A Doc on your machine reaches others by its public link, or by moving it to a team's project, where the team owns it and nobody keeps a copy. **Share with…** and **Update copy** are gone with the copies.

Docs you wrote on the platform outside a team stay in your cloud. The Docs page says so above them, and each one's ⋯ has **Move to <team>…** and **Download**, which saves it as Markdown: its title, then each section. Its pictures are left out, and the file says so at the end.
