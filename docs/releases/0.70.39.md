## Changed

- **Your own project is named Default** (#2667). Your personal project used to show as Personal, whatever it was called. It now shows its own name (Default, unless you've renamed it), on the hosted machines and run grants pages and everywhere else a project's name is shown. The owner label over your own projects, in the breadcrumb, settings, the move page and `arugula project list`, reads Just you. The `personal` address and `arugula project use personal` work as before.
- **Machines show the project's sessions** (#2668). In the app, a machine's page is in a project, and everything under Build follows it:
Machines lists your machines, the project's cloud workspaces and any other machine
with a session of it you can see, and counts only its sessions; Panes and Swarm show
only its panes; a machine's sidebar, tabs and panes show only its sessions. A session
of another project isn't there at all. A machine with none of the project's says so,
with New session on your own. Switching project from a machine's page keeps you on
that machine, on the session you last had there in that project, and a link to a
pane in another of your projects switches to it first. The machine's own page still
shows every session.

## Fixed

- **Windows finds Node for agent adapters** (#2670). The daemon looked for programs the Unix way: it split PATH on `:` and looked for `node` rather than `node.exe`, so on Windows it never found Node, npm or the adapter. It now splits PATH on `;` there and tries `PATHEXT`'s extensions (`node.exe`, `npm.cmd`, npm's `.cmd` shims), and an *Install* pane's command is written for PowerShell.
