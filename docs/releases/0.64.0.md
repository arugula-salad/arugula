# Arugula 0.64.0

The first wave of **feature discovery** (native #238): Arugula starts telling you about what it can do, at the moment it's useful. "Use Claude Code with Arugula" now sets up the hooks as well, so a terminal Claude's questions reach cards and your phone. A dev server starting in a pane gets a one-time chip to open it beside its terminal. And `arugula --help` is grouped. Also here: linking GitHub from the desktop app, and boards rows from newer builds.

## New

### Feature discovery

- **"Use Claude Code with Arugula" sets up the hooks too** (#1591, native #239). The button in Getting started, and `arugula setup claude`, now also run `arugula hooks install`, so a Claude Code started in a terminal pane puts its questions and permission prompts on cards: here, in the bell, on the swarm and in a push. The done lines name the settings file that changed. Getting started's Agents step has a **Questions on cards** check. When a terminal Claude is waiting on you and Arugula has never heard from its hooks, its pane says so, with **Set up**. A Claude that was already running picks the hooks up on its next start.
- **Hints, from facts, once** (#1591, native #241; decision aru-118). When the app sees something that makes a feature useful, it says so once, where that happened. The first: a dev server listening in a pane puts `:PORT is listening` with **Open beside** in the pane's header.
  - A hint shows one at a time, never while you type, and never again once you've seen it.
  - On control's page "seen" belongs to your account, so your phone doesn't say it again; on a machine's own page it's per browser.
  - **Tips**, under *This device* in Settings, turns them off.
- **`arugula --help` in groups** (#1591, native #248): Panes, Blocks, Agents, Sharing, Machines and control, Cloud and projects, Setup, the same as docs.arugula.io/cli. What hooks and clients run (`ask`, `hook`, `inbox`, `bridge`, `attention STATE`) is listed by `arugula help plumbing` instead.

## Fixed

- **Link GitHub in the desktop app** (#1587, #235). *Sign-in and account → Link GitHub* used to sign the window out. Now it opens your browser to finish, like installing the GitHub App, and the window says when it's linked. Control refuses a link started from the desktop app's window, the same rule as adding a passkey.

### Labs: boards

- **Rows from a newer build** (#1588). A row pointing at something this build doesn't know shows as a plain note, and editing its text keeps what it points at. This lets control roll back a release without breaking boards.

## Note

- Control's hub gets one new table, `account_prefs` (hints seen, Tips, and later What's new), created on start. The platform has no new migrations.
- The docs site has the hooks, the grouped CLI and hints (arugula-salad/site#40, #41).
