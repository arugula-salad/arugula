# Arugula 0.63.1

Fixes from the live test of 0.63's agent sessions.

## Fixed

- **A session's push no longer fails when main changed CI** (#1549). GitHub sees a branch that started before a change to `.github/workflows/` on main as changing that workflow, and the box's push token could write contents only, so the push was refused. The token can now write workflows too, still for the one repository and the session's own `arugula/*` branch, minted per push and revoked after (aru-115, amended). Since a session can now change CI on its branch, a PR draft whose branch changes `.github/workflows/` says so at the top: check those changes before merging. An `on: push` workflow runs from the pushed branch's own file.
- **Issue links in a session's prompt and PR footer point at the platform page** (#1549), app.arugula.io, not control's address, where they were 404s.
- **"Answered by" in a session's transcript names the person's login** (#1549), not an account id.
