## Changed

- **One Inbox count, from the server** (#2902). The Inbox page lists what needs you in three groups (Decide, Names you, Chat), as the server ranks them, and no longer shows a "Ready, merged or closed" group. A deploy waiting for your approval is still its card at the top, answered there. The Overview's Needs you is the project's slice of the same list: your agents' asks, proposals, reviews, mentions and threads with news, each opening where it is. Asks that wait on a teammate are folded under "2 asks for Jo ›", never counted for you. The switcher counts each project from the server too.

## Fixed

- **A chief of staff no longer waits on cards** (#2899). A chief of staff started from the Overview's Start, from "Run it on another
machine" or by an agent used to start in the default permission mode, and
nobody watches its terminal: it sat on a card for its first read of the staff
room, then on one for each tool after. Now every start gets what a board's
lead gets: mode `auto`, the lead's tools allowed (Bash, Read, Edit, Write,
Glob, Grep, WebFetch) and your own Claude Code settings. A start that names a
mode keeps it.
