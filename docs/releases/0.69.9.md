## Added

- **Swipe between levels in chat on a phone** (#2335). The level you swipe away slides off to the right as a card, and the one above
it shows underneath as you drag. Let go past a third of the width, or flick, and
it commits; short of that it springs back. A swipe goes where Back goes, so
history stays right. Swiping left from the list or a room returns to the last
room or thread you had open there. Vertical scrolling, long-press, the
composer's text selection and sideways-scrolling code blocks are unchanged.

## Fixed

- **Push doesn't name the owner** (#2319). Notifications a machine sends through a browser's push service (Google's, Apple's, Mozilla's) name a fixed Arugula contact instead of the machine owner's login. Phones and browsers already subscribed keep getting them.
