## Added

- **Status page in the app** (#2673). Status opens status.arugula.io in a new tab. It shows only on hosted Arugula, where the app's hub is control.arugula.io; a control you run yourself shows no link.

## Changed

- **A team watches only its projects' sessions** (#2669). Who sees a session follows its project. A session in one of the team's
projects is watch-only for the team's members: they type in it only when you
share it with them as editors, or trust them with a pane. A session in one of
your own projects, another team's project or none is yours, and whoever you
shared it with. Moving a session to another project changes who sees it at
once. A share with a person stays wherever the session goes; a share with a
team counts only while the session is in that team's project. Until Arugula
cloud says which team a project is in, no team sees its sessions.

## Fixed

- **A pane just started keeps its first card** (#2674). A pane learns its program's process id a moment after starting it. A Claude
Code hook that arrived in that moment was taken as coming from outside the
pane (an editor or the desktop app started from it), so its card never showed.
Now the pane finishes starting before it decides.
