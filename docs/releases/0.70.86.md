## Fixed

- **Cloud workspace agents reach the API again** (#2801). A cloud workspace's outbound TLS goes through its provider's proxy, which signs
with a CA the box's system store has but Node doesn't read. Claude Code and the
ACP adapters are Node, so on some boxes every turn ended in that error. The
workspace's daemon now points `NODE_EXTRA_CA_CERTS` at the system's bundle for
every agent and pane it starts, its sessions' agents included, unless it was
given one already. Existing workspaces get it with the daemon update.
