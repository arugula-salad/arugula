## Fixed

- **A red main wakes the chief of staff** (#2803). Its "main went red" doorbell watches `github.check.failed` with `match {"heads": "main"}`. That matches a check that ran on main's own head. `branches` held a pull request's base too, so before this a failing PR into main woke the chief of staff. A watch you make yourself can match on `heads` the same way.
