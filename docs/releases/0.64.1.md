# Arugula 0.64.1

Machines can update to this release. 0.64.0's daemon called itself 0.0.0, so `arugulad update` refused it. This release also fixes a chat message that could go missing, and a daemon that could stop when a client hung up.

## Fixed

- **Updating to this release works** (#1667, native #279). Since the daemon became a thin binary over `arugulad-base` (#1631), `arugulad --version` said `arugulad-base 0.0.0`. `arugulad update` checks the version of the build it downloads, so it refused 0.64.0 with "says it's 0.0.0, not 0.64.0". It now says `arugulad 0.64.1`, and a test holds it to the release. A machine still on 0.63.x updates straight to 0.64.1.
- **A chat message that arrived while the page was fetching the room is no longer missed**, and two more chat races are closed (#1657, native #217).
- **The daemon survives a client hanging up mid-request**, and hosted work notices a session that joins early (#1660).

## Changed

- **Daemon split, step 7** (#1663, #232): Labs' surface in the daemon is a trait. Nothing changes for people.

## Note

- No migrations.
- A machine already on 0.64.0 can't update itself: its own `arugulad update` still reads the new build's version correctly, but check by hand. If it refuses, run the install script (`curl -fsSL https://arugula.io/install.sh | sh`) or update the desktop app. A cloud workspace built on 0.64.0 gets 0.64.1 when it's rebuilt.
