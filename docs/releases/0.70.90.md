# Arugula 0.70.90

On the Issues page and an issue's, the path at the top reads Boards › Issues, each a link a level up, instead of only Boards. Swarm's legend lists a studio app only when a machine of yours has Studio on, and no longer lists Managoat, which is retired. A team Doc's pictures now show on its page, in the Docs list's preview and in the app, instead of their alt text. A session's tab in the Overview's talk panel finds its session again after a reload or a daemon restart, instead of saying it isn't in the project now. A card says "asks you" only when the question or the waiting session is yours; a teammate's says whom it asks, such as "asks Marcus", and doesn't count as needing you.

## Added

- **Your chief of staff reads boards** (#2811). A hosted session's `board_read` lists the project's boards with each one's lead
and progress, or reads one board (by its id or title) with its rows and who
works them. It reads as the person who started the session, in that project
only, and can't change a board.

## Fixed

- **The Issues page's path names Issues** (#2814). On the Issues page and an issue's, the path at the top reads Boards › Issues, each a link a level up, instead of only Boards.
- **Swarm's legend lists only what you can see** (#2813). Swarm's legend lists a studio app only when a machine of yours has Studio on, and no longer lists Managoat, which is retired.
- **A team Doc's pictures show on the web** (#2817). A team Doc's pictures now show on its page, in the Docs list's preview and in the app, instead of their alt text.
- **Overview's session tabs survive a restart** (#2812). A session's tab in the Overview's talk panel finds its session again after a reload or a daemon restart, instead of saying it isn't in the project now.
- **Cards say whom they ask** (#2816). On the Overview, its boards and in the iPhone, iPad and Android apps, a
card no longer says "asks you" because a teammate's agent on it is waiting.
It names the person, or says "asks someone" when Arugula can't tell. A
board's row opens by itself, and counts what needs you, only for yours.
- **One staff post wakes the chief of staff once** (#2815). It had armed a watch on its own staff room, so each post reached it as its
prompt and again through the watch. It now leads the room without watching it,
and Arugula refuses a session's watch on a room it leads.
