# Arugula 0.61.0

Docs are kept like Artifacts: a Doc outlives its pane, and you can open any of them again from a Docs page (#1492). Claude Code inside Arugula now reaches for a Doc instead of an Artifact.

## New

### Docs

- **The Doc library** (#1493): every Doc is kept on your machine under `<state>/docs/`, and closing its pane no longer files it away for pruning. Reopening a shared Doc brings back its *Update shared copy* menu. Search finds Docs whose pane is closed.
- **A Docs page** (#1494), in the rail and on the phone, with Labs and `docs` on. It lists every Doc with when it was written, who made it, and whether it's shared. **Open** brings it into the session you're in, or forward if it's already open. **Delete** asks first, and a shared Doc is unshared before it goes.
- **Open from Shared Docs…** (#1494): each row in control's list can open its Doc on the machine that shared it, while that machine is online.
- **The palette:** "Docs" opens the page, and "Open Doc: TITLE" opens one.
- **For agents:** MCP `doc list` and `doc open` let an agent go on with a Doc an earlier session wrote. Only the owner can delete a Doc.
- **Docs, not Artifacts** (#1486): the MCP instructions, the plugin's skill and a new `SessionStart` hook (`arugula hook`) tell Claude Code that a write-up goes in a Doc. In an eval, Claude chose a Doc in 8 of 10 runs, up from 0 of 10. `arugula hooks install` adds the hook to an existing setup.

### Agents

- **`start_agent` owns its worktree** (#1476): `worktree: {branch, base?}` makes the worktree, and `close` removes it only when its work is committed, pushed and merged. Otherwise it keeps it and says why.
- **A turn's result** (#1475): `prompt_agent` and `wait until: idle` return the agent's last message and the work it left: branch, push state, uncommitted files, commits and diffstat.

## Fixed

- **Pinned PR and issue blocks show their description and comments** (#1487), read from control's mirror.

## Note

- The first start moves each existing Doc, open or closed, into the library. It copies and checks every file before removing the old one, and it runs once.
- After this release, a daemon rolled back to an older version can't read share links made or moved by it.
