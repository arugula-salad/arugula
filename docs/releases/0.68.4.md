# Arugula 0.68.4

A project's issues and Docs are open to everyone in the project, whether or not they have chat turned on. Only the shown tab has a ×, and closing a tab by any route asks first, saying how many panes it stops. On the Docs pages, clicking a row shows the Doc beside the list; moving the mouse over the rows only highlights them. The link icon on a Doc, and Copy link in the Docs page and the block's menu, copy the Doc's link with one click: no dialog, no Done.

## Changed

- **Buttons, toggles and tabs share one look** (#2236). Bar buttons are 24px, page buttons 32 and touch buttons 40. Open and Closed,
the phone's tabs and the swarm's pickers are one segmented control, and a
toggle that is on is the accent tint with accent text wherever it is: the pane
toolbar, chat, the issues filters and the phone's keys. Boards' dashed "+ Add"
buttons are plain small buttons with a plus.
- **Issues and Docs without chat** (#2229). Project membership and roles decide who reads and changes a project's
native issues and Docs: owners and editors write, viewers read, and anyone
outside the project gets nothing. Before, someone who had turned chat off
for their own account couldn't open their team's issues or Docs. Now they
can, on the page, in the CLI and through their agents. Their inbox gets
the issues they're assigned and the ones whose description names them.

An issue's comments are still chat, so with chat off they read the issue
without its comments, and the page says so. A machine's Doc copies still
follow the account's own word for them.
- **One header on every page** (#2241). The Docs list, a board, settings, an issue and control's own pages now share the
platform's title: the display face, in capitals, with a name someone wrote
(a board, an issue) keeping its case. A 1px rule ends the header. A board's
groups are headed like the platform's sections, with a count and a rule under
them.
- **Closing a tab asks first** (#2238). Only the shown tab has a ×, and closing a tab by any route asks first, saying how many panes it stops.
- **Chips in five shapes** (#2242). A state keeps its dot, now at 11px on every page. A label is a raised box with square corners, a count is neutral unless it's unread or names you, and a linked thing (an issue, a board, a setting, a file) shows its id, its title and its state in the colour of that state. A merged pull request is purple everywhere. On a phone they're bigger, with a 44px target on anything you can press.
- **A box's GitHub token is its own** (#2234). A cloud workspace's setup clones each GitHub repo linked to its project with a
token minted for that box alone, which reads the repo's contents and nothing
else. The box revokes it once its clones are done, and gets no more until
it's rebuilt. Unlinking a repo also revokes these tokens and the one Arugula
keeps for reading the repo, on a best-effort basis: any it can't reach end
within the hour.
- **One bar on every pane and block** (#2244). A block's own bar now matches the pane's bar above it (34px, not 36), chat's room head is a bar with its topic inline, and a narrow room puts members and Go to session in ⋯ instead of wrapping its buttons. An issue's header shows at most two labelled actions; Edit title and Open on GitHub moved into ⋯.
- **Click a Doc to read it beside the list** (#2245). A Doc's preview reads and draws the whole Doc, so resting the pointer on a row
no longer swaps it in. Click a row (or tap it) to show it; ↑↓ and j/k still
move the selection, and Enter or a double click still opens the Doc. Other
lists keep previewing on hover.
- **A Doc's Copy link copies at once** (#2246). It copies the Doc's public link if it has one. Otherwise it copies the Doc's copy on the platform, which only you can open until the Doc is shared with the team ("Copied ✓" says so in its tooltip). A Doc with neither has Copy link switched off, saying why. Making a public link still takes the Share dialog's Create link.

## Fixed

- **A board's agent blocks are checked** (#2228). A person attaches a block from a machine they can reach, and an agent attaches blocks from its own machine. A block its own machine's agent attached shows to everyone on the board, as before.
- **Board rows let go of lost agents** (#2230). A machine now sends each agent block's state again every five minutes, and
with how long ago it saw it. A report older than twenty minutes counts as
unknown: the row follows its other work, and another agent may take it. A
machine that left control holds no row. A person's lane on a row is kept
when control can't read a block's grant for a moment. Machines on an older
Arugula keep working as before.
- **Board agent chips stay current** (#2240). A machine now says when a turn left no diff, so the chip stops showing the
one before. A self-hosted control older than this release shows such a turn
as "0 files changed, +0 −0" until it is updated.

A report that can't be sent is kept when control fails, not dropped, however
long control is out of reach. A close that control keeps answering with
server errors is given up after about an hour, so it can't slow every other
report. An agent block whose machine left control is read as an earlier
agent as soon as its report goes stale.
- **Cloud runs and sessions end** (#2231). A run on a cloud workspace stayed "running", and an agent session kept waking its box, when the workspace failed. Now:

- A run on a failed workspace fails, saying so.
- A run past 6 hours goes on while its box is busy, and fails once its box has been idle or offline for 10 minutes.
- A session on a failed workspace waits without waking it, whatever its state, and a rebuild moves it to the new box. With no rebuild within a day, it stops, saying so.
- A session a rebuild didn't move to the new box is moved again, and fails if it still can't move after 15 minutes.
- A failed run's inbox entry and push say why in words, and so do a stopped session's card and its history.
- **A board's stalled mark follows its blocks** (#2239). A row shows as stalled only to readers the board shows its agent blocks to, and a claimed row names its holder only while that machine may write to the project.
