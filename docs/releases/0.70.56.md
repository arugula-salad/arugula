## Added

- **wait takes an event, as watch does** (#2723). `wait {event, match, timeout}` is a short-lived watch: it blocks until a matching event happens, answers at once if it already has, and at its timeout says "still running" and cancels the watch. This machine's own types (`agent.idle`, `pane.exited` and the rest) need no account; the cloud's need the machine joined.
