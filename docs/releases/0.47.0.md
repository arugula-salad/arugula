# Arugula 0.47.0

Cloud workspaces (#1039): a session that runs on a Managoat workspace,
a machine in the cloud with your repositories on it, where each tab is
an agent and the tabs share its disk. It replaces Cloud runs, which were
one agent on a fresh checkout each time (S40, M114–M120). It needs
Managoat v0.39.0 or later.

## Cloud workspaces

- **Make one** from *+ Cloud workspace* in the sidebar, or *Start an
  agent → Run on: Cloud*. Give it repositories (each with an optional
  branch and credential), apt and npm packages, a setup script, env vars
  and its network. It sets up once; the sidebar and header say *Setting
  up · \<step\>*, then *Ready*.
- **Tabs are agents.** *+ Agent* opens one: which agent, which runtime and
  model (control's `ARUGULA_CLOUD_MODELS`, for example a claude and a
  codex pair), and which repository it starts in. Tabs run at once on the
  same disk, ask for approval in the tab and in the bell, and can be
  interrupted.
- **Settings and Rebuild.** Edit the settings at any time. The header says
  *Rebuild needed · N changes* and the Settings section lists Built against
  Saved (env vars by name only); secrets reach the machine at once.
  *Rebuild* sets a new machine up from the saved settings: the confirm
  says the disk is wiped, tabs keep their transcripts, and *Interrupt and
  rebuild* is offered while a tab is mid-turn. A rebuild waiting for a
  free machine can be cancelled.
- **When setup fails** the banner quotes the end of its output, *Setup
  log* shows every step's output, and *Retry* runs it again. A prompt to a
  tab sets it up again too, and a tab whose conversation failed starts a
  fresh one on its next prompt, below its old transcript.
- **Changes** shows each repository's branch, status and diff against
  HEAD, and opens files. It reads only when shown or after a turn, so it
  never wakes a parked workspace.
- **Parked.** An idle workspace parks after Managoat's idle time; looking
  at it doesn't wake it, a prompt does.
- **Delete** ends its tabs and removes its Managoat workspace, vault and
  environment. Its tabs' transcripts stay under *Past tabs*.

## Cloud runs are retired (M119)

- Nothing starts or cancels a run any more (`POST /api/cloud/runs` is
  gone). Past runs stay readable, with their saved results and download,
  under the Cloud agents panel's *Past runs*.
- `ARUGULA_CLOUD_DAILY_RUNS`, `ARUGULA_CLOUD_CONCURRENT_RUNS` and
  `ARUGULA_CLOUD_RUN_MINUTES` still parse, and log that they do nothing.
  Cloud workspaces have no caps.

## For whoever runs control

- New: `ARUGULA_CLOUD_MODELS`, comma-separated `runtime:model` pairs (the
  first is the default). Unset, it's `ARUGULA_CLOUD_RUNTIME:ARUGULA_CLOUD_MODEL`.
- Control's database migrates on start: `cloud_jobs` gains a `kind`, and
  the event, request and notification tables are keyed by conversation
  with their account. New tables hold Cloud workspaces, their tabs and
  their saved settings.
- [docs/managoat.md](../managoat.md) is rewritten around Cloud workspaces.

## For contributors

- `DEV_CONTROL_CLOUD=1 just dev-control` starts a fake Managoat with three
  Cloud workspaces (ready with tabs, rebuild needed, failed) and a past run;
  `DEV_CONTROL_CLOUD_FULL=1` adds a rebuild waiting for a machine. The fake
  lives in `web/fixtures/fakes.ts` as `fakeManagoat()`.
