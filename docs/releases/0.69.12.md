## Added

- **read_output reads an agent's messages** (#2365). `read_output` with `format: "messages"` returns only what was said, with no tool payloads or results, about 16k characters a page, and `next_offset` to go on. Terminal panes keep their raw output.

## Changed

- **Board attach takes block:local/N** (#2365). An agent attaches its block to a board row with block:local/N, block:%N or %N, and a refused attach names the exact block:<machine id>/<pane> and start_agent's issue.
- **start_agent says which MCP servers the agent has** (#2365). A lead that starts agents can now tell a missing MCP server from a missing grant:
the answer names the servers, says plainly when Arugula's isn't given (a chat has
none), and lists the issues, boards, trackers and threads grants this machine holds.
- **Worktree path in every agent answer** (#2365). `wait` (its `turn.work.worktree`), `describe` and `list` carry the absolute path of the worktree an agent block owns.

## Fixed

- **Close cleans up a stacked agent** (#2362). Closing an agent whose base branch was deleted after merge now checks its work against the default branch and removes the worktree, instead of keeping it.
- **link takes a list for to** (#2365). `link` already took up to 50 `add` or `remove` entries; a `to` written as a list
was refused as unreadable. It is now one link for each item, each landing on its own.
