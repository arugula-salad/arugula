## Added

- **Make a join token from settings or the CLI** (#2834). A project's token is for its team, or for you on a personal project; `arugula join-token --team ID` makes a team's. Each is good once, until it runs out, and shown only once. A team's owners and editors make them.

## Changed

- **Machines reach each other with control's tokens** (#2835). A daemon now asks control for a machine token to reach another machine (Arugula #1002, aru-141): `agents` lets it call that machine's agents (`/api/a2a/` only), and `drives` gives it full use of a cloud workspace of its project. Before, only a device certificate opened that channel, so a machine joined with a join token couldn't be reached or reach others. Where control doesn't make these tokens yet, or the other machine runs a daemon from before them, the daemon uses its device key as before. A daemon older than this one refuses another machine's token.
