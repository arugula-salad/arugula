## Added

- **#agents and a board's channel as panes on a board** (#2973). On a board, **+ pane** lists #agents and the board's own channel. Either opens beside the lanes as a pane holding the whole room: its messages, its threads in place, its tags and the box to write in. `g a` opens #agents there too. In Chat, a board's channel has **Open as a pane** (`o`), which opens the board with the channel beside its lanes. The pane is kept in the board's layout, like the lead's panes.

## Changed

- **A machine's tabs show their state** (#2982). On a machine's page, each tab now starts with its state: working, asks you, done or quiet. The line over the panes names the tab, the machine it runs on and what it is (a shell, an agent, a server), before the pane count. The layouts are **Tamed** (the active pane large, the rest beside it; it was "Main + stack"), **Grid** and **Columns**. Renaming a tab (double-click or F2), dragging tabs and panes, and the tab's menu work as before.
- **An agent you approve on a card runs in auto mode** (#2985). An agent started by a card you approve now runs in auto mode, with the tools a board's lead has, so it doesn't ask you for each command.
- **Machines lists each session as one row** (#2983). The Machines page now lists each machine's sessions one row each, under the machine's name, whether it's online, and whose it is (yours, a teammate's, this computer or a cloud workspace). A row says the session's state, what it is (a shell, an agent, a server), and how many panes it has, or that it needs you. Under a row are only the panes that need you and the one you had open last; the session's name opens it at its last tab. The **Agents only** toggle is gone, and its old address shows every session.
