# Arugula 0.63.8

The desktop app sends what its window can't do to your browser, setup installs Claude Code's hooks, and Docs have their own look.

## New

- **Setup installs the hooks** (#1591, #239). *Use Claude Code with Arugula* and `arugula setup claude` also run `arugula hooks install`, and say which settings file changed.
  - Getting started's Agents step gets a **Questions on cards** check.
  - A terminal Claude that needs you but has never reported through a hook gets a chip on its pane, with **Set up**.
- **Hints** (#1591, #241). Arugula shows a short hint from something it noticed, once per account: the first one is `:5173 is listening` · **Open beside** on a pane whose dev server just started. Only one shows at a time, never while you type. Turn them off with **Tips** under This device in Settings.
- **`arugula --help` in groups** (#1591, #248). Commands are listed under Panes, Blocks, Agents, Sharing, Machines and control, Cloud and projects, and Setup. What hooks and clients run (`ask`, `hook`, `inbox`, `bridge`, `attention`) moved to `arugula help plumbing`.
- **Docs look like Arugula** (#1593, #253). A Doc has its own paper, ink and leaf in light and dark, whatever the app's theme, with display headings, a reading measure, quieter tables and warm code. A shared Doc follows the reader's light or dark setting. Chat's Markdown is unchanged.

## Fixed

- **Link GitHub in the desktop app** (#1587, #235). *Sign-in and account → Link GitHub* used to sign the window out. Now it opens your browser to finish, like installing the GitHub App, and the window says when it's linked. Control refuses a link started from the desktop app's window, the same rule as adding a passkey.
- **The desktop app's account actions** (#1592, #251). Add or remove a passkey, link or unlink GitHub, sign out everywhere and delete your account: in the desktop app, each opens your browser up front and the window waits with *Check again*, instead of failing after you click. In a browser they work as before.

### Labs: boards

- **Rows from a newer build** (#1588). A row pointing at something this build doesn't know shows as a plain note, and editing its text keeps what it points at. This lets control roll back a release without breaking boards.

## Note

- Control gains a table, `account_prefs`, for hints seen per account (`GET`/`POST /api/me/prefs`). It's additive.
- Control's 5-minute log adds webhook-to-row times counted per UTC day, so the M173 gate reads a day's p95 across deploys (#1594, `docs/control-ops.md`).
