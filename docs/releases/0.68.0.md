# Arugula 0.68.0

A new browser now always checks who approved it, and a project's owners can revoke any grant over their project. Merging from Arugula works on a repo with a merge queue. Older ways of reaching a machine are gone: if a script uses `--peer`, `--token`, `--join`, `--sync` or `run --home`, it needs changing.

## Changed

- **A new browser always checks who approved it** (#2188). It shows its code and checks the approving device's answer before it trusts the account. A browser approved as the first device, and then told a different account root, stops with an error.
- **Owners can revoke any grant over their project** (#2168). That covers a machine's or a token's, whoever gave it. A write power on a viewer's machine is refused.
- **Merging from Arugula uses a repo's merge queue** (#2196). On a branch with a queue, a merge joins the queue, whoever is merging, and the block says it's queued. Until the queue lands it, the PR isn't merged.
- **One set of words for access** (#2181). The docs, the help, the dialogs and Settings now say *share*, *role*, *power* and *trust* the same way. Nothing behaves differently.

## Fixed

- **A hosted workspace's editors can read pane threads** (#2187). An editor could open a pane and read nothing on its thread once the machine had sent its reader lists.
- **The + Pane drawer shows the current directory** (#2207). It read the directory once when it opened, so a `cd` after that was missed, and the shell opened in the old directory.
- **Loading a Doc keeps its address** (#2208). The address lost the Doc's slug while loading, then got it back.
- **A pane's last record no longer gets in the way of removing its directory** (#2208). A daemon's panes could recreate a file as they ended, while something was deleting their directory.

## Removed

These were part of the older machine model. Machines now reach each other through control, and cloud workspaces cover what these did.

- **Synced history** (#2182). The daemon's `--sync`, `--sync-live`, `--sync-to`, `--sync-every` and `--sync-key-file` are gone.
- **The dial-out tunnel, host tokens and host invites** (#2185). The daemon's `--peer`, `--token` and `--join` are gone.
- **Remote blocks** (#2197). So is `arugula run --home`.
