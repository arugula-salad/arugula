## Added

- **A pane shows what its agent waits on you for** (#2910). An agent on your machine (an agent block, or Claude Code in a terminal with Arugula's hooks) that adds a to-do or raises an approval card now marks its pane as needing you once its turn ends, instead of "Turn finished". The pane names the oldest open card ("Waits on you: Run the migration (+1 more)"). It goes as soon as the answer reaches the machine or the agent cancels the card. It isn't pushed again, because the card already was, and it isn't a second item in your Inbox. Dismissing it hides it until the agent raises another card.

## Changed

- **Restart your running chief of staff from its tab** (#2907). Press **Restart** in the Overview's Chief of staff tab to have your running chief of staff pick up a new recipe. It asks once; the old one's turn stops, and the new one starts on the same machine, takes over your staff room and carries on from its notes there. If the new one can't start, the tab says why and offers Start again. Restart shows only while it runs on one of your machines that can start one.

## Fixed

- **A refused request says which field and why** (#2914). When Arugula cloud answers a tool's request with a 400 or 422 and a plain-text reason, the tool now passes the reason on. A `watch create` with `standing` or `exclude_self` against a cloud that doesn't keep them yet says "Arugula cloud doesn't keep standing watches or exclude_self yet: make a watch without them", where it used to say only "control answered 422".
