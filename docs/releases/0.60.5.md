# Arugula 0.60.5

A deploy's box gives up root on E2B, so deploys apply.

## Fixes

- **A deploy's box gives up root on E2B** (#1402). Before a deploy runs,
  its box drops the daemon's own root and keeps only the run user and the
  reseed. E2B's base image grants its user root in `/etc/sudoers` itself
  too, and the daemon kept matching the `sudo` group it started in, so the
  box refused every deploy ("this deploy box can't give up root"). Those
  rules go now as well, checked by `visudo` before the file is replaced;
  checked live on E2B.
