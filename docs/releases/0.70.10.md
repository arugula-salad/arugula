## Added

- **Control hears each session's project and card** (#2557). A machine now sends control the list of its sessions (`PUT /api/daemon/machine-sessions`): each session's id, name, project and card, and each pane's id, kind and card when it isn't its session's. An agent block's state report says its project and card too. Ids and names only: no terminal text, titles, file names or transcripts, and a GitHub issue isn't sent as a card. The list goes when the layout changes (or every 30 seconds if it changed otherwise), only when it differs from the last one, and whole every five minutes.

Against a control from before this, nothing is lost: a control without the route (a 404) isn't sent the list again until the daemon restarts, and a block report it refuses for its project and card (any 4xx) is sent again at once without them, and the next ones go without until every block is sent again five minutes later.
- **Move to project…** (#2554). In a project's Settings, under General, *Move to project…* opens a page: pick where it goes (a new project, with its name and owner, or one you can write), then what moves. A repo brings its boards, issues and sessions; a board brings its repo; a Doc on a moving board comes along. Before you move says only what you have to deal with (who will now see it, a Doc on a machine, an environment's secrets), and Comes along counts the rest, with each issue's new number. Links to the old numbers keep working. If something changes in the project while you're deciding, nothing moves and the page shows the new plan.

A machine's own Docs move from that machine: in the app, on your machine that's online, you can pick them and it moves them into a team's project once the rest has; anywhere else the page says where they move from, with a link there.

## Changed

- **Sessions shows branches, and cards' boards and lanes** (#2556). Read from `sessions/by-card`'s new fields. A cloud from before them still works: the page then reads the boards to place its cards, as it did. Open card goes to the card's drawer on its board either way; a board now opens its drawer from `#row=` naming what the row points at (an `iss_…`), not only the row's id.
