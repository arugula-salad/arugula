## Added

- **Joining asks whether people may type remotely** (#2690). `arugulad join` asks on a terminal (or takes `--remote-input on|off`), and Getting started asks on the machine's own page. Answering no is the same as `arugulad sharing remote-input off`: nobody who comes through Arugula cloud types there, you included from another device, while the machine's own terminals and page work as before. The answer is set on the machine only; nothing through Arugula cloud can change it. The machine menu says *Remote typing: on* or *off*.

## Changed

- **Installs check the release signature everywhere** (#2685). A daemon release's `SHA256SUMS` is now also signed with an SSH key
(`SHA256SUMS.sshsig`). `install.sh` checks it with `ssh-keygen -Y verify` where
openssl can't check Ed25519, as on a stock Mac, and `install.ps1` checks it with
the ssh-keygen that Windows 10 and later have. Where neither tool can check the
signature, both stop unless `ARUGULA_ALLOW_UNSIGNED=1`.
