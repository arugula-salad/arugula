# Arugula 0.63.0

The last of **thread = session** (native #129). A session now hears from CI and reviews on its branch, and it ends when its PR merges. **Try 3** runs a session three ways at once, and `@codex review` reviews what one pushed. New boxes start from a snapshot of their workspace's setup, and a cloud workspace can be **large**: 8 vCPU and 8 GiB, enough for a Rust build. This release also has the fixes from the first live test of 0.62.

## New

### Agent sessions

- **CI and reviews go back to the session** (#1531, native #137). When CI fails on a session's branch, its failed checks are gathered for up to two minutes and sent to the session as its next prompt, with each check's name, link and the end of its output. A review, and its inline comments, are sent the same way. A done session takes it as a new turn. Only insiders' reviews count, and GitHub's text goes in as quoted data. CI gets two rounds: after that the card says the session **needs a person** until someone replies in the thread. The thread gets a line for each batch.
- **Try 3** (#1536, native #141). From a session's card, an owner or editor runs it two more ways at once, `+ Claude, Codex` or `+ Claude ×2`, each in a slot of its own on the box, re-running its first prompt as the person who asked. The card becomes a compare view of the three: agent, state, diffstat, finish step and a diff on GitHub for each. **Pick** keeps one; the others stop, "not picked", and the one kept is the thread's session from then on.
- **`@codex review`** (#1536). In a session's thread, it starts a read-only review of what the session pushed: the diff from GitHub plus the thread, as quoted data. It pushes nothing and gets no push token. Its reply is posted in the thread as the person who asked, then it ends. A box without Codex reviews with Claude Code and says so.
- **Done when its PR merges** (#1533, native #142). When a PR from a session's branch merges, whoever opened it, the session ends once its turn does, and its slot on the box frees. The card says **merged ✓** and links that PR, and the thread leaves the Threads view until `@arugula` there starts a new session.
- **Agent on this** (#1533) on a native issue's page and issue block: it writes `@arugula work on this issue` in the issue's thread as you, and the session's branch is named for the issue (`i<number>-…`).
- **Diff ↗** on the card (#1533): what the pushed branch changes, on GitHub, until its PR is open. An editor on the box can't open a session's checkout, which belongs to the session's own user.
- **Project numbers** (#1533) on the project page: of the last 30 days' sessions, how many led to a PR, how many merged, and the median time from the `@` to the PR. A Try 3 counts once, and a review doesn't count.

### Cloud workspaces

- **Two sizes** (#1541, native #201): `small` (2 vCPU, 2 GiB, the default) and `large` (8 vCPU, 8 GiB). Set it with `arugula cloud create --size` or `cloud edit --size`, MCP `cloud create` with `size`, or **Workspace size** in the project's settings (owners and editors). A change shows *Wants a rebuild* until the box is rebuilt. A large box costs $0.5328 an hour while it runs, against $0.1332 for a small one, and a paused box costs nothing. Billing stays flat per sandbox minute.
- **Snapshots** (#1523, native #140). Once a workspace's box sets up all right, the platform builds a snapshot of a box set up from the workspace's spec, and new boxes and rebuilds start from it, already set up. Before the snapshot is taken, the builder box wipes every secret it was given and checks again. A snapshot follows its workspace's spec, size and release; when one is missing or out of date, the box comes from the template and runs setup as before. The workspace page says which it was.

## Changed

- **A session's agent asks no permission on its box** (#1540). Claude Code runs in `bypassPermissions` and Codex in `full-access`, and the block allows anything that still asks. The box is the blast radius: the session's own user, the firewall, no secrets (aru-115). Questions still go to the card.
- **The first prompt's rules** (#1540): ask with the agent's tool for asking (a question only in its reply ends the turn without an answer). Commit and don't push: the box pushes after the finish step. On an Arugula issue's thread, link the issue and never write `#N`, which on GitHub is another issue.
- **The PR draft** (#1540) is titled after the thread's issue, else the newest pushed commit, else the ask's first line. Its body puts the commits, the last turn's diffstat and the finish step's result under the template's `## Summary`, and its footer links the session and its thread. When the turns name no commits, it reads them from GitHub. Once the session's PR merged, the draft can't be kept or sent.
- **A follow-up in the box's transcript names its author's login** (#1540), not an account id.
- **UI consistency, round 3** (#1542, native #192–#200), the last planned round: done inbox cards count as seen, and agent tokens read as "<person>'s agent token" everywhere. Unknown paths get a real 404. The bar's Chat shows unread and @mentions. "Developer settings" replaces "Labs flags". The Doc block gets the shared bar. Merge offers only the methods a GitHub repo allows. Read-only links fit a phone.

## Fixed

- **A turn typed in a session's block is the session's** (#1540). Answering from the card's **Open** used to lose the turn: no finish step, no push. The box now follows the block, and such a turn ends like the others, with the finish step, the push and the turn's report. Its questions still go to the card.
- **The selected tab stays in sight** (#1547). Since 0.62.1 sized tabs to their names, names that arrived after a tab was picked could push it under the overflow menu.
- **CI compiles without the cache when the cache is down** (#1539).

## Note

- **The release builds a new E2B template, `arugula-workspace-large`,** for the first time, beside `arugula-workspace` (the release workflow's `template` job is now one job per size). Until its build finishes, creating a large workspace on 0.63.0 fails with "still being built".
- To get this release's sessions, snapshots and sizes on a cloud workspace, rebuild it once the templates are out. Its first snapshot builds after its box sets up all right.
- The workspace template has Codex and its ACP adapter. On a box without them, Try 3's Codex sibling and `@codex review` run on Claude Code, and say so.
- The platform adds migrations 0054–0057, all additive: snapshots (0054), CI and review feedback (0055), tries and reviews (0056), and merged sessions (0057).
