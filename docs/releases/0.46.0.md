# Arugula 0.46.0

A new workspace on a computer, in the web client and the desktop app
(#1018): a rail, a sidebar of the machine's sessions, a header that says
where you are, a toolbar for the tab's panes, headers on the panes, and a
footer. It was behind *Appearance → New workspace* while it was built
(M107–M112); now it's the only one. A phone is unchanged.

## The workspace (#1018, #1028)

- **One bar became six places.** The rail (Sessions, Panes, Swarm, Chat,
  Agents, Settings); the session sidebar, grouped into *Needs you*,
  *Working* and *Idle*, with search; the header (machine and connection,
  session, tab, command search, the bell, Share, people, account); the
  tabs; the pane toolbar; and the footer. [features.md](../features.md#the-workspace-046)
  walks through each.
- **Layouts and focus, for everyone on the tab.** *Columns*, *Grid* and
  *Main + stack* rearrange the tab's panes without restarting any, and
  *Focus* fills the tab with one pane and gives the layout back exactly.
  Both are the machine's, so every window sees them (#1024, #1025).
- **Pane headers are handles.** Each pane's number, kind, status, host,
  directory and branch, in the row the layout already kept above it (no
  terminal row is lost). Click to type there, drag to move, `…` for the
  menu.
- **+ Pane** says what it will make, where and in which directory before
  it makes it. **The bell** and the footer's *needs input* open one drawer
  of what waits on you, on every machine; looking doesn't answer it. The
  session's **overview** and its **activity drawer** show its tabs, panes
  and recent commands.
- **Keys.** Ctrl+Shift+1–9 go to a pane, Ctrl+Shift+Enter focuses one,
  Ctrl+Shift+E opens + Pane, and Ctrl+Alt+Shift+arrows resize. Each takes
  its key only when it can act; otherwise the terminal gets it.

## States, said plainly (#1028)

- **Reconnecting** shows in the header and over the panes; while it lasts
  nothing claims to be working or running, and what would change
  something is off, with the reason on it.
- **A guest or viewer** doesn't get buttons for what only the owner does
  (new sessions, Share, closing), and an editor's (new tabs, layouts) are
  off with why. A viewer is no longer offered *Use this window's size*,
  which the machine ignored for them.
- **An empty machine** says what a session is and makes one. **Many tabs**
  scroll sideways, the shown one stays in sight and `+` stays beside them.
  **Long names** are cut, whole in their tooltip. **A pane that can't be
  made** says why in + Pane, which stays open.

## Accessibility (#1028)

- **From the keyboard:** command search's *Move the keyboard to …* reaches
  the rail, sessions, tabs, toolbar and header; the tabs take arrows, Enter
  and F2. A control the keyboard is on keeps the focus.
- **Every icon button** has a name and a tooltip, with its key where it has
  one.
- **Contrast:** every palette's text now reads at 4.5:1 (WCAG AA) on its
  backgrounds. Palettes that fell short (Latte, Platinum, Solarized Light,
  and the dimmed text of the dark ones) are nudged lighter or darker where
  needed, keeping their hues.
- **Reduce motion** stops animation, and the terminal cursor's blink.

## Fixes

- *Share* in the workspace opened nothing (it did in the old bar).
- Hints for the desktop app's ⌘ keys no longer show in a browser, where
  they don't work.

## For scripts and other clients

- Two layout intents, `arrange` (`columns`, `grid`, `main_stack`, with an
  optional `main` pane) and `focus` (a pane, or `null` to give the layout
  back); a tab's `focus` is saved with the layout and sent in its view.
  Both need an editor's role (#1024).
- A pane's `branch` (its repository's checked-out branch, or a short sha
  when detached), read from `.git/HEAD` without running git.
- `GET /api/history` and `GET /api/events` take `session=`, and every entry
  and event has an `id` that stays the same between reads. A guest can read
  them for the panes they can read, from the point they were shared
  (#1027).

## Upgrade notes

The *New workspace* switch is gone, and a saved choice of the old bar is
forgotten. If you never picked a palette, the workspace is now Slate
rather than Mocha; a palette you picked stays.
