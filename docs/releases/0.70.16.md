## Added

- **Agents watch pull requests after their turn ends** (#2570). The `watch` tool's `create` takes `pr` (`OWNER/REPO#N` or a link, one or several) and `until` (`merged`, the default, or `closed`). The agent ends its turn, and when one of them gets there, Arugula cloud wakes that same Claude Code session with a follow-up naming the pull request, what happened, who did it and when. A watch fires once. It expires after 24 hours unless the agent asks for longer (up to 7 days), and then the agent is told it ended without firing. It's for repos linked through Arugula's GitHub App; for any other, use `wait` with `pr`. A watch belongs to the session that made it: `/clear` or a new conversation in the pane doesn't take it over. `list` and `cancel` show and drop a session's watches. It works from a terminal with Arugula's hooks installed, or an agent block, and needs Arugula cloud to support it.
