# Arugula 0.40.0

Arugula is now Fountain's UI (#942). Fountain is a headless backend for
agents; sign in to it from Arugula and its conversations, permission
requests and sandboxes show up as blocks and cards. It's out of Labs: there's
no `fountain` flag, and nothing talks to Fountain until you sign in.

## Fountain

- **Sign in from Arugula** (#945): `arugula fountain login [URL]` (or the
  web and the phone) runs Fountain's device flow and keeps the key on the
  machine, readable only by you and never shown to a client.
  `arugula fountain status` says which login is in use, and
  `arugula fountain logout` revokes the key. Without a sign-in,
  `$FOUNTAIN_API_KEY` and `~/.fountain/credentials` still work.
- **The account stream** (#945): `arugulad --fountain-account-stream`
  follows your account's events, resuming where it left off after a
  restart. Turn it on for one daemon, your home one.
- **The account view** (#947): *Fountain…* opens your conversations, with
  live status, unread dots, label filters and each conversation's spawn
  tree. Opening one opens it as an agent block beside the view. The Agents
  tab lists the account's agents, with *Run on Fountain*.
- **Permission requests are cards** (#947): a Fountain agent asking for
  permission raises a card, pushed to the phone, that the machine's owner
  can Allow or Deny.
- **A conversation as an agent block** (#948): an `agent: fountain` block
  talks to Fountain's API directly instead of running `fountain acp`. It
  picks up after a daemon restart with no replay, can Wake, Interrupt and
  Terminate the conversation, and opens the sandbox's changes and files.
- **Recipes on Fountain** (#950, Labs: agents): a recipe
  (`.claude/agents/NAME.md`) runs on Fountain from the same card that runs
  it here, as one Fountain agent per recipe, cloning the project's origin.
  The dialog says what doesn't travel (uncommitted work, unpushed commits)
  and which secrets Fountain is missing, and copies each one to a vault
  only when you ask.
- **Retired:** Fountain removed self-hosted runners, so the runner view,
  `arugula fountain runner` and the diff block's `run_as` are gone (#941).
  Wearing a Fountain agent locally (`arugula agent --as-fountain`, the
  catalog's *Run here*, M44) is retired too (#944): a saved block that did
  says why and doesn't start.

## Also

- **A team machine's other owners post and read under their own name** in
  threads and conversations (#935).
- **The editor extension can be published** as `arugula.arugula-editor`
  (#931): `just publish-vsix`, and a VSIX Open VSX no longer refuses.
- **An agent whose command doesn't exist can't take the daemon down**
  (#948, #949), on Linux or macOS.
