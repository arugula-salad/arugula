## Changed

- **Close the after-a-move note; New project from…** (#2579). The × on the note under the bar closes it for you, in this browser; it stays closed. Undo is still there for the week in the project's Settings, under General, beside *Move to project…*, as a list of the moves into and out of it ("1 Doc moved to Rhythm · Nov 15").

The project switcher's *New project from…* asks which of your own projects to take work from, then opens its *Move to project…* page with a new project as where it goes. It shows only if you own a project.

## Fixed

- **Silence works on agent blocks** (#2582). A teammate's mention of a silenced agent block reads **silenced** and waits in the machine's inbox until you allow mentions again.
- **A mention of a machine with mentions off says so** (#2583). The machine's daemon refuses the mention when its owner ran
`arugulad sharing agent-mentions off`, and the line under the message read
"offline", though the machine was connected. It now reads "its owner turned
agent mentions off", as does `read_thread`'s `mentions_off` state, so nobody
waits for the machine to come back. Such a mention isn't sent again when the
machine reconnects.

A watch on a reply in a room (`watch`) now names an agent's reply as the room
does, "jhgaylor's agent on geek (check-b)", not by its owner alone.
- **An issue's comments open their reply threads** (#2581). On an issue's or a run's page, a comment with replies in its thread now shows "N replies" and opens the same Thread panel a channel does: beside the page on a computer, the whole screen on a phone, with its address (`?thread=`) so a link lands on it. A mention's `answered ›` chip opens the thread at the reply it names, wherever it shows.
