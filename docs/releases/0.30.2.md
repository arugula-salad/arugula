# Arugula 0.30.2

## Your team's agents (Labs: `agents`)

- **The Agents page** (#403): **Agents…** in the session menu (or the
  phone's sheet) opens a page for this machine's agent recipes and the
  team's agents.
  - **Recipes** lists every recipe this machine has: yours in
    `~/.claude/agents`, and those in each project it knows (added on the
    page, offered from, or open in a pane).
  - *New recipe* and *Edit* use a form (name, description, model, tools,
    permissions, skills, MCP servers, prompt) that writes the Claude Code
    subagent file. An edit keeps anything in the file the form doesn't
    know.
  - Each recipe has *Run here*, *Offer* / *Stop offering*, and *Delete*.
  - **Team** shows the catalog by machine and owner, tasks waiting for your
    OK, and your grants with *Revoke*.
