## Added

- **Watches on a PR's checks and readiness** (#2574). `watch create` takes `until` `checks_done` (no check on the head commit is queued or running), `checks_failed` (one failed, told once however often it flips) and `ready` (checks green and GitHub says it can merge cleanly), beside `merged` and `closed`. For `ready`, Arugula cloud asks GitHub for the PR's merge state again whenever its checks finish, rather than waiting for its next routine read.
