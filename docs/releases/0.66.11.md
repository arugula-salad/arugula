# Arugula 0.66.11

Boards show work in flight and link the Docs they're for. A mention of a machine says where it went and when it's answered. Prototypes in a Doc take drags and can go full window. Control no longer relays GitHub's webhooks to machines: linked repos come from the platform's mirror, and a daemon older than 0.57 polls GitHub with its own login, as its other blocks always have.

## Changed

- **Boards' progress bar shows Doing and Review** (#2018, #541). The bar has segments for Done, Review and Doing, and reads "3 of 10 done, 2 proven · 2 in review · 1 doing". A board with nothing in flight reads as before.
- **Boards link Docs** (#2020, #2029, #517).
  - A board's Docs show as chips under its goal, and each row can link its own, on the card and in the drawer.
  - A project Doc opens its page; an agent's Doc block opens on its machine.
  - A linked Doc never moves a row's lane or counts as proof.
- **A mention of a machine shows where it went** (#2022, #502). Under the message, each mentioned machine gets a live line: delivered (and to which session), the name matched no session, waiting with no session taking it, offline, or answered (with a link to the reply).
- **Prototypes in a Doc take drags and touch, and go full window** (#2026, #507).
  - A drag that starts inside the frame keeps going outside it, and a touch drag moves the prototype, not the Doc.
  - ⤢ opens the frame full window without reloading it. Esc or ✕ closes it.
- **Prototypes can copy a value and keep settings** (#2027, #508). `window.arugula.copy(text)` copies on a click. `window.arugula.store` keeps a prototype's settings per viewer, per Doc section.
- **A refilled prototype reaches every open view** (#2028, #509). When an agent fills a prototype section again, open Doc blocks redraw it. A shared Doc that changed since its last share shows "Shared copy is older · Update" on its share control, and the shared page picks up an update in place.
- **Agents put prototypes in a Doc** (#2034, #510). The `doc` tool, Arugula's instructions and the Arugula skill steer an interactive or tunable prototype into a Doc's ```prototype section, not an Artifact or a loose HTML file. The `doc` tool says what a prototype may hold.
- **Open Beside: Board…** (#2032, #545). The picker (was "Pin a board") scrolls, filters as you type, and takes arrow keys. Boards people made come first, then started epic boards, and closed boards are left out.
- **Control no longer relays GitHub's webhooks to machines** (#2037, M174). The relay was announced in 0.58.0 to end on 2026-11-21, and ended early, since every machine but three runs 0.57 or later. Since 0.57, blocks on linked repos are pins onto the platform's mirror, which hears GitHub's webhooks itself. A daemon older than 0.57 now gets an empty answer when it asks to watch, and its GitHub blocks poll with its own `gh` login. Update it with `arugulad update` to get linked repos from the mirror.

## Fixed

- **`board_write relate` works** (#2030, #511). The relation is the field `relation` (`blocks`, `relates`, `duplicate_of` or `discovered_from`), and `to` is a string. Before, the op couldn't be called.
- **`start_agent` attaches to the issue's own project** (#2031, #430). It finds the project that holds `#N` among those the machine's boards can reach, then the one linked to the agent's folder. It also takes an `iss_…` id, and infers the issue from a `fix/<N>-…` branch.
- **A restarted daemon keeps who posted where** (#2033, #419). The record of which session last posted in each room and thread, and its unread mentions, survives a restart in `mentions.json`. Mentions no longer fall through to the inbox after one.
