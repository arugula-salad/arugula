## Changed

- **Typing through Arugula cloud is off unless you say so** (#2699). Unanswered means no terminal, a script, `arugulad join --token` without `--remote-input`, or the input ending. In all of those, a machine joining for the first time starts with remote typing off. An answer, `--remote-input on|off` or `ARUGULA_REMOTE_INPUT=on|off` still decides, and Getting started's question starts on No. The join says which way it went and how to allow typing: `arugulad sharing remote-input on` on the machine, or `--remote-input on` when joining. With it off, nobody types into the machine through Arugula cloud, you included, though you can still watch it from your other devices. Machines that joined before, and any machine whose owner already set it, keep what they have.

## Fixed

- **An open account dialog stays open on a machine switch** (#2695). The page shows a machine just after you sign in. A dialog from the account
menu that you opened before that (Teams, Machines, Shared Docs, Sign-in and
account, Add a machine) used to close when the machine opened. It stays
open now.
- **A shared machine shows up at once** (#2698). Sharing a session tells Arugula cloud before the share finishes, so the person you shared with sees the machine right away instead of up to 10 seconds later.
- **A Doc's title keeps keys typed at once** (#2694). Typing a Doc's new title the moment its editor opens, from Rename or a click on the title, no longer loses the first keys to the old title.
- **An agent block no longer waits forever to start** (#2701). When an agent block reopened its conversation after a restart and the agent
never answered, the block said "starting" for good. Now an agent that says
nothing for 30 seconds while its conversation opens (two minutes while the
agent itself starts) is given up on; one that's busy, replaying a long
conversation say, is waited for. If the earlier conversation can't be
reopened, the block starts a new one and says so in its transcript
("Couldn't resume the earlier conversation; started a new one."). If the
agent doesn't start at all, or can't start a new conversation, the block
stops with the reason and the last lines the agent wrote to its error
output. Sending it a prompt starts it again.
- **A PR named OWNER/REPO#N opens from GitHub** (#2697). Forgejo is used only when a clone's remote says so. When a pull request or issue can't be read, its block names the forge and item it tried, such as `GitHub: arugula-salad/arugula#2494: …`.
