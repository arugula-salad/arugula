# Arugula 0.55.0

Step 2 of the platform roadmap, second half (#1150): control's platform
(chat, Cloud, billing, projects and grants) can run on Postgres, on two
machines at once. The hosted control moves to it in a short announced
window after this release.

## Control

- **Two platform machines.** On Postgres, Cloud jobs are leased with
  `SKIP LOCKED`, so two machines never take the same one, and a machine
  that stops hands its jobs to the other within their lease. Chat's live
  events are rows the machines tell each other about (`LISTEN/NOTIFY`), so
  a message posted through one reaches a page held by the other, and a
  page that reconnects resumes from where it was on either.
- **Nightly backups of the platform's database:** an encrypted `pg_dump`
  to R2 every night, kept 30 days, with a restore drill
  (`scripts/platform-restore-drill`) that checks every table against the
  dump's record.
- **The window's tools** copy between the platform's SQLite file and
  Postgres in both directions, with the same counts and checksums.
- The hub reaches the platform through Fly's private load balancer
  (Flycast) once it runs two machines.
