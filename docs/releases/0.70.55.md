# Arugula 0.70.55

An agent can watch a linked GitHub repo's pull requests, checks, reviews and pushes (watch types lists them) and be woken when one happens. An agent can watch a connected Plane work item change state (such as reaching Done), and a board get a row, a lane moved by hand, or close, and be woken when it does.

## Added

- **Agents watch a linked repo's GitHub events** (#2721). `watch` with `event` set to a `github.*` type (a PR opened, closed or merged; its checks done, failed or ready; a check failing on any branch; a review or review comment; a push) and `match` naming the repo, PR or branch fires once when the event comes in through Arugula's GitHub App. A fork's or a non-member's event wakes only a watch whose match asks for `outside: true`. Also in the catalog: a native issue labelled, a forge draft answered, and a machine's daemon updated.
- **Agents watch Plane items and boards** (#2722). `watch` with `event` set to `plane.issue.created`, `plane.issue.updated` or `plane.issue.deleted` (match an item by `ident`, such as `ALL-2212`, and `state` or `state_group`), or to `board.row.added`, `board.lane.overridden` or `board.closed` (match by `board`). Plane watches ride the same access as native issues; board watches need the project's boards.read grant.
