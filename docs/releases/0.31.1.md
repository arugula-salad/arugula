# Arugula 0.31.1

## Agent blocks

- **With several agents working, the app no longer falls behind** (#713).
  - An agent block sends its state at most every 120 ms while it streams,
    not once per chunk of the reply (#717). Each send carried the whole
    block, so a few agents answering at once flooded every open app.
  - A client that falls behind gets each block's newest state, not every
    one it missed (#718), so a slow phone or a busy desktop catches up at
    once instead of working through a backlog.
