## Added

- **Join a machine with a join token** (#2514). A machine joined with a join token, or added with one click by a signed-in person, is let in on control's word (aru-141): it pins no account root, so devices don't reach it by their certificates. Channels with control's machine tokens and read-only links do. A machine joined the way it always has keeps working as before. A daemon older than this one won't load a join made this way, and runs as not joined until it's updated.
- **A board row's drawer shows its live session** (#2516). With more than one session on the row, chips switch between them. On the platform page the section is the session's state card; drawing the pane there comes later.
- **A session carries its project and card** (#2505). A session's work is a project and, maybe, a native issue in it (its card). Its terminals, and blocks without an issue of their own, show the card in `on_issue`, read when asked, so a card set after a pane opened shows on it too. MCP's `list` has `project` and `card` columns; `run` takes `project` and `issue`; `start_agent` takes `project`; `link`'s `card` sets the caller's session's; and `board_write attach` of an agent block puts the block on that row's issue. A terminal on a `feat/N-…` branch puts its session on `#N` when a board of its project has a row for it, never over a card set by hand. The current project of an agent's calls comes from its session's card, after its own issue.

## Changed

- **A new browser works without being approved** (#2513). A browser that isn't one of your account's devices no longer waits on *Approve this browser*: it lists your machines from Arugula cloud's directory and opens each one with a short-lived machine token (aru-141), fetched fresh for every connection. A browser that is a device keeps using its key. Machines need this release's daemon to take a token; an older one says to update it. Blocks shown through Arugula cloud (ports, editors), approving other devices and machines' joins, and team changes still need a device for now.
- **Every browser reaches machines with tokens** (#2518). Since 0.70.4 a machine takes a machine token from Arugula cloud (aru-141), and a browser that isn't one of your devices already used them. Now every browser does. A browser that has a device key still uses it when a machine is too old to take a token, or when the control it signed in to gives none (a dev or test control). `localStorage["arugula.machine-tokens"] = "no-key"` brings back the old default for one browser, and `"off"` turns tokens off.

## Fixed

- **A phone's page load of Chat is the list** (#2509). On a phone, a reload of the chat list, or a link to `/chat`, now shows the
list instead of jumping into the room you were last in. Opening Chat from
inside the app (the rail's Chat, the Chat tab) still opens that room, with
the list under it so Back climbs.
- **A pull request or issue that names no forge opens on GitHub** (#2515). Opening `owner/repo#N` with nothing to say which forge it's on went to
Forgejo. It's GitHub's, on github.com, again. A Forgejo or GitLab host, a
link's look, a clone's remote or an explicit `provider` still choose theirs.
