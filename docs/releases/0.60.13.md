# Arugula 0.60.13

Made as a deploy.

## New

- **The platform page looks like the rest of Arugula again** (#1449–#1453).
  app.arugula.io had lost the shell's look and your theme:
  - **Your appearance follows you** between control's page and
    app.arugula.io (#1449). The palette, finish and corners you pick are
    also kept in a cookie on arugula.io, so both hosts read the same
    choice. **Appearance…** is in the platform page's account menu and
    on its Settings. A tab already open on the other host picks a change
    up when it reloads.
  - **Finishes reach it** (#1450). Glass, Aqua and Brushed metal style its
    pages, cards, forms, room switcher and toast the way they style the
    shell's panes, and every palette colors it, light ones included.
  - **The shell's frame** (#1451): the same head bar, with "Arugula /
    Projects" at its left end, the selected place in the same look, and
    pages as panels around one centred reading column. The shell itself
    is unchanged.
  - **The swarm's cards** (#1452). Projects, a project's rooms and hosted
    workspaces, runs and the inbox are rail cards with a state bar,
    display headings, mono ids and counts. Each color stands for one real
    fact: your role on a project, a workspace's or a run's state, why an
    inbox item is there.
- **The swarm's fonts are shipped** (#1453). Big Shoulders Display,
  Instrument Sans and JetBrains Mono were named but never loaded, so the
  swarm, Getting started and now the platform page drew whatever the
  machine had. They're self-hosted now (about 106 kB, fetched only when
  text uses them). Terminals keep the font they had.
- **A Claude subscription can pay for hosted agents** (#1443). A project's
  Anthropic key may be a token from `claude setup-token` instead of an
  API key: `arugula cloud key set anthropic --project <project>` takes
  either.

## Fixes

- `arugula cloud key set`'s help keeps to one line (#1444).
- A hosted agent test no longer kills CI's runner (#1445).
