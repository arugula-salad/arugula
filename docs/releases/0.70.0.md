# Arugula 0.70.0

0.70 makes the project the place you work in. Your agents and the CLI pick the current project in one order: the one you name, then the session's, then the one your clone's repo is linked to, then your default. `arugula project list`, `new` and `use` manage projects from the terminal, and a grant over a team reaches all of its channels. Docs is one list everywhere, with My Docs and Team Docs, and a Doc's Share puts the link on your clipboard.

## Added

- **Projects from the CLI** (#2484). `arugula project list` shows Personal's projects, then each team's, and marks
the current one; `--archived` shows archived ones too. `arugula project new
NAME` makes a project, Personal's unless `--team` names a team you own.
`arugula project use PROJECT` sets the project of the session it runs in, by
id, `personal`, or name.

`--project` and `$ARUGULA_PROJECT` now choose the current project in the same
order as Arugula's MCP tools: what you name, then the session's project, then
the project this clone's GitHub repo is linked to, then your personal one.
`arugula project ls` is now `arugula project repos`; `ls` still works.

## Changed

- **Share copies the link** (#2479). Not shared yet: Share asks "Share this Doc with a link?", and Create link makes the link and copies it. Shared, with changes since: it asks "Update shared copy?", then updates and copies. Shared and current: it just copies. Open shared copy, Update shared copy, Unshare and Share with a team… are in the Doc's ⋯ menu.
- **One Docs list, with My Docs and Team Docs** (#2491). The machine's Docs page, the platform's and the phone's are the same list now, with time groups, each Doc's shape and layout, sorting and the reader beside it. A personal machine or project shows My Docs. A team's project, and a team's machine, shows My Docs (the Docs you and your agents made) and Team Docs (all of the team's), and the tab you used last stays. On a phone a Doc opens in the list's place, the sort is a menu, and a long press starts a selection. On the platform, New Doc is a dialog, and Delete is in a Doc's ⋯ menu.

## Fixed

- **The CLI finds a daemon with its own state directory** (#2488). A daemon started with `ARUGULA_STATE_DIR` keeps its socket there. In a shell
of your own, `arugula` used to look only in the default directory, so it said
the daemon wasn't running. It now reads `ARUGULA_STATE_DIR` too. `arugulad
flags --help` also shows a flag that exists today as its example.
- **arugula fs cat reads the whole file** (#2490). `arugula fs cat` on a file larger than 1 MiB, on a machine reached through
control, printed only the first megabyte and exited 0: the channel didn't
carry the file's size, so the CLI took it for 0. The channel now carries the
size and offset, and `cat` without a size reads on until a short page. If a
page fails partway, it exits 1 and says how many bytes it wrote and the
`--offset` to resume from.
