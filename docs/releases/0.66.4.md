# Arugula 0.66.4

Machines and pages keep what they've learned about trust, and a team's lock is an owner's signed word. Boards get their own page, relations and a reworked agent tool, agents hear an `@machine` or a reply from a teammate, and Docs and boards have Copy link. Update every machine.

## Changed

- **What a machine has seen stays seen** (#1879). Every daemon, hosted machine and the owner's page records when it first saw each certificate and each removal. A certificate first seen after its approver's removal doesn't count, whatever date it carries, and what a machine or page already holds can't be undone by a later answer from control.
- **The page keeps its trust between visits** (#1879). The owner's page keeps the certificates, removals and team rosters it has checked, in one transaction across tabs. If the browser can't keep them, the page lists no one else's machines and signs no team change, and says why.
- **A team's lock is signed by an owner** (#1879). Locking or unlocking a team signs a record on the owner's page; control stores the latest, and machines take a lock change only from an owner in the roster they hold. Control's plain flag can still lock a team but never unlock it. Teams shows an unsigned lock as control's claim. Hosted machines take the lock too.
- **Removing a device cuts it off at once** (#1879). Machines keep the answers to signature checks they've already made, so a refresh takes milliseconds and a removed device's connections close within a second.
- **Boards: asks, auto-attach, and which issue work is for** (#1880). A row can ask a person a question with options and a recommendation; a pull request attaches to its issue's row on its own; an agent started on an issue attaches to that row and shows its issue and board.
- **Agent blocks show their model and context** (#1882). The block shows the session's model, how full its context window is, and a mark for each compaction, telling an automatic one from the window running out.
- **Agents hear their mentions** (#1890, #394). A teammate's `@machine` in a thread, or a reply under that machine's agent's newest message, reaches the agent: control hands it to the machine's daemon, which gives it to the session that last posted there through the hooks inbox, framed as a teammate's message and never as its person's approval. Without such a session it waits, counted in `capabilities`, until `read_thread`. `pushed` names the machines reached, and `unreached` the ones that were offline or switched off. Each machine's owner can turn it off in Sharing or with `arugulad sharing agent-mentions off`.
- **The board page** (#1881, #369). Cards in the platform's style, groups you can add, rename, reorder and delete, one chip per agent that opens its pane, a row's title that opens its item, a detail drawer from the card or Details, and a layout for the phone.
- **The board agent tool** (#1885, #366). Rows are named by their item (`#N`, `owner/repo#N`, `ALL-12`), with `add` (up to 50 at once), `attach`, `detach`, `ask`, `note`, `group` and `drop`, and short answers (`verbose` for the whole board). `add_row`, `set`, `move` and `remove_row` are gone. A "Work on boards" grant bundle covers it, and a block pane given as `%N` now matches.
- **Relations between work items** (#1889, #403). Blocks, relates to, duplicate of and discovered from, with Plane's blocking relations mirrored. Boards show "blocked by #N" and how many rows are ready, and agents have `relate` and `unrelate`.
- **Which issue an agent is on** (#1888, #372). An agent working on an issue shows `#N` on its session row and swarm tile, and the swarm can group by board.
- **Copy link on boards and Docs** (#1887, #411). A board's page and block and a project Doc's page have Copy link at the right of the title: it copies the team's link and shows "Copied ✓". Its ▾ holds Open in browser ↗ and, for a Doc on one machine, Share link….
- **⌘U in chat** (#1886, #412). ⌘U (Ctrl+U off macOS) opens the file picker of the chat composer you're typing in, as it does for an agent's.
- **Plane connections** (#1891, #417). Project settings → Plane shows each connection's webhook URL, takes its secret after connecting, and shows the last delivery.
- **A passkey reset** (#1875, #393). A session alone can't remove your last passkey, or add a first one back once you've had one. If you've lost your passkeys, start a passkey reset from a fresh GitHub sign-in: it waits 48 hours, every device and your email are told, and any of your devices or passkeys can cancel it. Devices, machines and recovery codes stay.

## Fixed

- **Attaching in the desktop app** (#1892). In an agent block, ⌘U or the 📎 could open the picker and then drop the file you chose without a word. The picker now keeps its input until you answer.
- **Escape in full screen** (#1883, #392). Chat's pins, reactions, room edit and search mark their Escape handled, so it doesn't reach the window. The desktop app's own fix, that an Escape nothing handles never leaves full screen, comes with the next app update.

## Note

- Control gains a `teams.lock` column and `reset_requests.kind`, and the platform migrations **0074_board_asks**, **0077_work_relations** and **0078_tracker_last_delivery**, all additive. A page open from before this update can't lock or unlock a team until it's reloaded.
