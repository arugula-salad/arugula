# Arugula 0.66.4

Machines and pages keep what they've learned about trust, and a team's lock is an owner's signed word. Boards rows can ask a person a question, and agent blocks show their model and how full their context is. Update every machine.

## Changed

- **What a machine has seen stays seen** (#1879). Every daemon, hosted machine and the owner's page records when it first saw each certificate and each removal. A certificate first seen after its approver's removal doesn't count, whatever date it carries, and what a machine or page already holds can't be undone by a later answer from control.
- **The page keeps its trust between visits** (#1879). The owner's page keeps the certificates, removals and team rosters it has checked, in one transaction across tabs. If the browser can't keep them, the page lists no one else's machines and signs no team change, and says why.
- **A team's lock is signed by an owner** (#1879). Locking or unlocking a team signs a record on the owner's page; control stores the latest, and machines take a lock change only from an owner in the roster they hold. Control's plain flag can still lock a team but never unlock it. Teams shows an unsigned lock as control's claim. Hosted machines take the lock too.
- **Removing a device cuts it off at once** (#1879). Machines keep the answers to signature checks they've already made, so a refresh takes milliseconds and a removed device's connections close within a second.
- **Boards: asks, auto-attach, and which issue work is for** (#1880). A row can ask a person a question with options and a recommendation; a pull request attaches to its issue's row on its own; an agent started on an issue attaches to that row and shows its issue and board.
- **Agent blocks show their model and context** (#1882). The block shows the session's model, how full its context window is, and a mark for each compaction, telling an automatic one from the window running out.

## Note

- Control gains a `teams.lock` column, and the platform migration **0074_board_asks** (both additive). A page open from before this update can't lock or unlock a team until it's reloaded.
- `docs/control-e2e.md` lists exactly what still assumes an honest control.
