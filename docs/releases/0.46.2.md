# Arugula 0.46.2

Docs, in Labs: ask an agent for a report and watch it being written beside
the conversation.

## Docs (Labs, flag `docs`) (#962)

- **A Doc block** (#963). An agent calls the `doc` tool:
  - `doc new` opens a Doc beside its pane with an outline, each pending
    section showing what it will cover;
  - `doc fill` writes one section at a time, and each appears in place
    without a reload, on the web, the phone and the desktop app.

  Everyone the session is shared with sees the Doc. Only the owner's agent
  and CLI change it: an editor's or a viewer's write is refused. A Doc comes
  back after a restart, and `history` and `search` find a closed one's text.
- **No approvals.** The default `arugula hooks install` allows `doc` (and
  its plugin spelling), and an agent block allows it built in, so a Claude
  Code or Codex agent builds a Doc without stopping to ask.
- **Charts and drawings** (#964). In a section, a ```` ```chart ```` fence
  holding a JSON spec draws a bar or line chart, in the page's palette,
  light or dark. A ```` ```svg ```` fence is shown as a picture through
  `<img>`, so nothing in it runs. A bad fence is refused with one line
  saying what to fix, and the section stays as it was.
- **Pictures** (#965). `doc asset` saves a PNG, JPEG, GIF or WebP of up to
  2 MB in the Doc, from a file or as base64, and `![alt](assets/name.png)`
  shows it. What a file is comes from its bytes, not its name. The page
  shows pictures from `data:` URLs, so they also show through control.

## Upgrade notes

Docs are off until the `docs` flag is on: in a machine's *Developer
settings…*, or for a team's machines in *Teams…* (a team owner's). With the
flag off, agents aren't offered the tool.
