# Arugula 0.71.0

Arugula runs your terminals and coding agents on your own machines and lets you reach them from a browser, the desktop app or a phone. 0.71 is the release we're asking new people to try. Signing in is all it takes: no device to approve, no keys to copy, no recovery codes. A machine joins with one click or a join token. Your work lives in projects, with three spaces: Plan for boards and Docs, Build for every machine's panes, and Talk for chat. A board shows the agent sessions working on each card, and you can drive one from the card. Arugula cloud decides who reaches your machines, and it can read the terminal traffic it relays. Each machine can turn remote typing off and keeps a log of who came.

## Since 0.70

What 0.70.1 to 0.70.35 brought, for anyone starting here. Each release's own notes have the details.

- **Sign in, and that's it.** A browser, the desktop app and the CLI reach your machines with short-lived tokens from Arugula cloud. Approve this browser, recovery codes, the device reset and passkeys as devices are gone (#2513, #2518, #2642). `arugula login` prints a link to click Allow on in a browser that's signed in (#2653). Moving a machine into a team and sharing a session need no device key (#2639).
- **Adding a machine.** Getting started's Cloud step is one click: Connect, then Add (#2626). On a server, `arugulad join --token` adds a machine with no browser at all (#2514).
- **Who can reach a machine.** Arugula cloud can read the terminal traffic it relays. It's built to keep none of it, and the sign-in page, Getting started and the docs say so (#2599). On the machine, `arugulad sharing remote-input off` makes everyone who comes through Arugula cloud a viewer (#2507), and a machine's Settings lists who reached it, with their role and when (#2627).
- **Three spaces.** The rail is Plan, Build and Talk (#2594). Plan has the Overview, Boards and Docs. Build opens on every machine's panes in one list, grouped by machine (#2598), and Panes, Swarm and Machines open inside the app (#2532, #2534). Talk is Chat. The app opens on your project, where you left it (#2533, #2535).
- **Boards run the work.** Boards is a list, with the board beside it (#2649, #2656), and Not on a board is its first row (#2655). A card's drawer shows its agent's terminal live: answer its question in place, or take over and hand it back (#2516, #2548). A card's sessions show on its row as they change (#2601, #2644). A project's Overview is the work in flight, one line per card (#2550, #2589, #2596).
- **Sessions belong to a project and a card.** Every pane names its card (#2505, #2521), a session's project follows its repo (#2525), and you can put a session on a card (#2571) or move work to another project (#2554, #2559, #2560).
- **Agents and chat.** Agents can watch a pull request, a session, a thread, a run or a deploy after their turn ends, and you can see who's waiting on what (#2570, #2574, #2575, #2576, #2578). Silence or stop your agent from a thread (#2569). Agents see and save the files you post in chat (#2526, #2566, #2567). A follow-up waiting for Claude Code survives a daemon restart (#2530).
- **Settings in one place.** You, This machine and your machines' agents' grants are all in the app's Settings (#2623, #2624, #2645).
- **Docs.** Rename a Doc (#2500), move it to your team (#2492), and its outline marks where you're reading (#2646).

## Changed

- **Remote input off holds for shared sessions too** (#2643). `arugulad sharing remote-input off` makes people who come through Arugula cloud viewers. That now holds whatever is shared with them: a session shared with them or their team as an editor, or their role in the machine's team, no longer lets them type while it's off. Other people's devices are viewers too; only the devices of the machine's own account are as they were. A channel that opened while remote input was on closes when it goes off, and the person's client opens a new one as a viewer.

## Fixed

- **Apps started from a pane keep off it** (#2662). Claude Code's hooks name the pane they run in, and an app started from a pane inherited that name, so every session in the app used the pane. Now a pane takes a hook only from the Claude Code in front of it: the one at its prompt, or in the `tmux` window shown there. Elsewhere, Claude Code asks in its own dialog. Update `arugula` on the machine for this; an older `arugula` behaves as before.
