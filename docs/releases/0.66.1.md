## Added

- **`arugula-control account-delete`** (#1838). Support and operators can delete an account that can't delete itself from Settings, such as a test bot's. It's the same delete as Settings → *Delete account*, and refuses what Settings refuses. It shows what it would do first; `--yes` deletes. See docs/control-ops.md, *Deleting an account*.
