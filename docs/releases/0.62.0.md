# Arugula 0.62.0

**Thread = session.** Write `@arugula` in a project thread and an agent session starts on the project's hosted box, with the thread as its prompt (#129). One live card in the thread shows what it's doing. Replies go to the same session. When a turn ends and the project's finish step passes, the box pushes the session's branch, and the person who asked sends the PR.

## New

### Agent sessions from a thread

- **`@arugula` starts a session** (#1508): in a project channel, a reply thread, or an issue's or PR's thread. The first prompt is the thread itself, with its links read as the asker can read them, and GitHub's text marked as quoted data with its author's role (#1509). Only a project's owners and editors on the hosted beta can start one; anyone else gets a line saying why. With several boxes or repos, it asks in the thread.
- **One live status card** (#1512) per session, in its thread: queued, working, needs input, done, failed, or stopped responding, plus the repo, branch, time, the tool it's running or its last error, and the turn's diffstat. Its questions and permission prompts can be answered on the card by any owner or editor. **Open**, **Preview**, **PR**, **Cancel turn** and **Stop**. Each session also has a page.
- **Replies are prompts** (#1508): a reply in a session's thread from the asker or an owner or editor is queued for the session, credited to whoever wrote it.
- **The box runs sessions** (#1511): each session gets a user of its own on the box (up to three at once) and a clone of the repo, with the repo's `CLAUDE.md` / `AGENTS.md` read in as text. A restart neither loses nor repeats a prompt. A session's turns are billed to the person who asked (#1517).
- **A finish step** (#1519): set a command such as `just check` in project settings, or with `arugula cloud edit --finish`. It runs after each turn before anything is pushed; if it fails, the agent gets one try to fix it. The card shows the result.
- **The push and the PR** (#1520): the box pushes only its session's `arugula/<id>-<slug>` branch, with a token made for that one push. The card's **PR** button opens a draft, filled from the repo's PR template and the turns that were pushed, and only the asker can send it, as themselves. A machine never opens, merges or approves a PR.
- **Warm on @** (#1518): starting to type `@arugula`, in a room or a reply, wakes the project's box so it's up by the time you send.
- **The project setting "agents run on"** picks which hosted workspace takes sessions.

### Hosted boxes

- **Boxes keep their daemon** (#1510): it restarts if it stops, and the out-of-memory killer picks other processes first. A woken box is *waking* until its daemon is back, never *ready* before, and if it doesn't come back in 60 s the workspace says to rebuild it and its owners and editors are told (#124).
- **Sessions follow a rebuilt box** (#1517): they start again from the thread and their transcript.

### Elsewhere

- **Share this pane… / Watch me** (#1526): an invite can have the guest follow your window when they open it. MCP `invite_person` takes `follow`.
- **Agents file native issues** (#1507): Claude Code in Arugula files new issues with `issue_write`, not `gh issue create`, unless you ask for GitHub.

## Changed

- **UI consistency, round 1** (#1524, native #143–#159): chat no longer says it's off while loading. Issue and run pages open at their top. Deploy runs are titled "Deploy <env> · <commit>". Failed runs and deploys say why. Deploy… pre-fills the environment's repo. Sign-in and join screens scroll and fit phones. Read-only links say so and when they end. Control's dialogs take focus and close on Escape. The diff, file and swarm-follow views follow your palette. One "Needs you" count everywhere. One page header on every app.arugula.io page. One button set that follows Corners and Finish, with a confirm on Unlink, Clear, Revoke and other destructive actions. Every page has its own tab title, the right nav tab lit, and an "All projects" switcher.
- **Size between people** (#1506): switching to or typing in a shared tab no longer takes its size from someone else's window; only **Use this window's size** does.

## Fixed

- **Someone else's new tab no longer pulls your window to it** (#1522).

## Note

- Sessions need a hosted box made from this release's template: rebuild a workspace to get session users, the push and the finish step. A box from an older template never pushes, and its card says *Not pushed*.
- Sending a PR from your own machine (when the GitHub sign-in can't) needs this release's daemon there.
- The platform adds migrations 0049–0053. All are additive; 0049 adds the *waking* state.
