# Features

This page moved to **[docs.arugula.io](https://docs.arugula.io/)**, split
by topic. The workspace (the rail, the session sidebar, the header, the
pane toolbar, + Pane, layouts and Focus, the activity drawer, the bell and
Appearance) and the keys are on
[panes and sessions](https://docs.arugula.io/panes/#the-workspace); chat
blocks are on [agents](https://docs.arugula.io/agents/#chat-blocks). The
rest is on [blocks](https://docs.arugula.io/blocks/),
[pull requests and issues](https://docs.arugula.io/forges/),
[attention and history](https://docs.arugula.io/attention/),
[swarm themes](https://docs.arugula.io/swarm-themes/),
[sharing](https://docs.arugula.io/sharing/) and
[Guest SSH](https://docs.arugula.io/guest-ssh/).

Labs features are described for the team in [labs.md](labs.md), and
hosted (Cloud) workspaces in [control.md](control.md).
