Claude Code in a terminal pane with Arugula's hooks installed raises a notification when it needs you. The pane showed it, but your Inbox and a chief of staff watching for it never heard of it. A prompt to read a file outside the working directory, or to use a tool, now goes to your Inbox as a permission, and any other notification as a question. It leaves when the pane stops needing you. A pane that needs input some other way, with no hook, still isn't listed.
