---
section: Changed
title: Machines lists each session as one row
line: The Machines page lists each machine's sessions one row each, with what it is, how many panes it has and whether it needs you; "Agents only" is gone.
---
The Machines page now lists each machine's sessions one row each, under the machine's name, whether it's online, and whose it is (yours, a teammate's, this computer or a cloud workspace). A row says the session's state, what it is (a shell, an agent, a server), and how many panes it has, or that it needs you. Under a row are only the panes that need you and the one you had open last; the session's name opens it at its last tab. The **Agents only** toggle is gone, and its old address shows every session.
