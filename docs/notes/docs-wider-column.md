title: Docs use a wider column
line: On a wide screen or in a wide pane, a Doc's text, tables and charts get more of the width.

A Doc's column is 68 characters wide in a narrow pane, 88 from 1100px of width, and 100 from 1500px. It follows the Doc's own width, not the window's, so a Doc in a pane beside a terminal stays as it was. The Docs page and a shared link get the same. A phone is unchanged.
