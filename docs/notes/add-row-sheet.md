section: Changed
title: Add row and New issue are a sheet
line: Add row on a board, and New issue under All issues, open a sheet with a title, a description and Start an agent on it.
---
On a board, Add row (or `a`) opens a sheet: a title, a description, and Start an agent on it. It opens the issue, puts it on the board and, when you ask, starts an agent on it. New issue under All issues is the same sheet, and the New issue page's address opens it. To put an issue or PR that's already there on the board, use the board's ⋯, Add an existing item.
