section: Changed
title: Docs are one list
line: A project's Docs are one list, the latest changed first, with a Mine filter in a team; a Doc opens on its own page.
needs: control
---
Docs no longer have My Docs and Team Docs tabs, a sort, a search box or a preview: each row is a Doc's title, who made it and when, the latest changed first, and a team's list has All and Mine (`m`). `j` and `k` move, Enter opens the Doc's page, where its ⋯ renames, moves, downloads, shares and deletes it. A team's deleted Docs are under a folded Deleted row, each opening in place with Restore. A machine's own Docs page is gone: its Docs are in Go to… by title, and an old link to it lands on your project's Docs.
