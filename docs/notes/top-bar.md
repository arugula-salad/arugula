section: Changed
title: One top bar, a crumb you can climb
line: "Every page's top bar is the same now: where you are as a crumb that starts with the project (it opens your projects), then Go to… and Share."
---
The app's pages, a machine's page and a machine's own page share one top bar. Its crumb starts with the project, which opens the list of your projects, then the place and what's in it, each a step up; on a machine's page it's the machine, the session and the tab. The team's name is no longer the crumb's first step, and the command search field in a machine's header is now the Go to… button.
