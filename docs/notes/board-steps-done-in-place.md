---
section: Changed
title: Steps keeps done rows in place
line: Done rows now stay where they were in the Steps chart, struck through, with green arrows to what they unblocked, so finishing work no longer reshuffles the plan.
---
The Steps chart no longer has a ✓ column or a "now" band. Every row, done or open, sits in the column its links put it in, so the chart keeps the plan's shape as work finishes. A done row's title is struck through and its bar stays faded green; an arrow out of a done row is green, because what it waited on is met. Ready rows are still filled bars and waiting rows outlined.
