title: Docs on iPhone and iPad lists the project's Docs
line: In the iPhone and iPad app, Docs lists the current project's Docs, newest first, and one opens with a tap.
headline: no
---
The list is the web's: Today, Yesterday, This week and Earlier, each Doc with when it was last edited, and a mark for a tabs or a prototype Doc. In a team's project, My Docs and Team Docs sit at the top, and the app remembers the one you used last. Switch project from the menu at the top and the list follows. On an iPad the open Doc sits beside the list; on an iPhone it opens over it, with Back to return. A board linked from the Doc opens on the Overview, and an issue opens over the list.
