---
section: Changed
title: Projects opens the project you were in
line: On the platform page, the rail's Projects goes straight to the project you last had open in this browser, and to the list if it's gone.
headline: no
---
The rail's Projects used to open the list of projects. It now opens the project
last opened or picked in this browser. "All projects" in the picker still opens
the list. If that project is gone, or you can no longer see it, Projects opens
the list instead and forgets it. It's kept per browser, and signing out of the
page clears it.
