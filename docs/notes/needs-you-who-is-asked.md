title: Needs you counts only what asks you
line: An agent session your agent started asks that agent first, and reaches you after 10 minutes without an answer; a teammate's asks and failed checks no longer count for you.
needs: control
---
Your Inbox and its count now hold only the asks that need you. A hosted session that one of your agents started asks that agent first. It reaches you only if the agent hasn't answered in 10 minutes, and then it says it escalated. If the agent has stopped, it reaches you at once. A permission only you may give always reaches you at once. Under a project, a teammate's asks show as theirs and never count for you. Failed checks and failed runs still show in your Inbox, but as alerts: they don't count, and a board no longer raises them as an ask.
