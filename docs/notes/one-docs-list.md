The machine's Docs page, the platform's and the phone's are the same list now, with time groups, each Doc's shape and layout, sorting and the reader beside it. A personal machine or project shows My Docs. A team's project, and a team's machine, shows My Docs (the Docs you and your agents made) and Team Docs (all of the team's), and the tab you used last stays. On a phone a Doc opens in the list's place, the sort is a menu, and a long press starts a selection. On the platform, New Doc is a dialog, and Delete is in a Doc's ⋯ menu.
