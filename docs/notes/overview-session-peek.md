title: Peek at a session from the Overview

needs: control

The peek says the session's state, machine and branch, and reads its last lines from its machine only while the tab is open. A reply goes into an agent block at its next tool call, and is typed with Enter into Claude Code in a terminal or a shell. Open in Panes ↗ opens the whole terminal. A teammate's session is read-only, with Ask its lead opening the board's thread. A session in a cloud workspace is read from its box while it runs, and shows what it last said once its box is paused. A card with a session now opens its peek; the card's link in the peek opens the card.
