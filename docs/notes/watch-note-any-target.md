---
section: Changed
title: A watch's note goes with any target
line: A watch on a PR, a session, a run or a room can carry a note, handed back when it fires or expires.
headline: no
---
`watch create` took a `note` only with an `event`. It now goes with any target, with the same 200-character limit, and comes back in the message when the watch fires or expires. `match` still goes with an event.
