title: A 30-day Trash for team Docs
line: Deleting a team Doc puts it in the team's Trash for 30 days, and an owner, an editor or the person who made it can restore it.
needs: control
---
A team Doc has no other copy, so a delete is no longer for good straight away. The team's Docs page has a Trash link: each Doc there says who deleted it, when, and how many days it has left, with Restore. After 30 days it is deleted for good. A machine's copy of a Doc is still deleted at once, since the machine holds the original.
