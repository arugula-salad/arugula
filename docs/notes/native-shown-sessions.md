title: The iPhone, iPad and Android apps show only the current project's sessions
line: Machines and Home in the native apps show and count only the current project's sessions, as the web does; another project's, or a teammate's unplaced ones, no longer leak in.
headline: no
---
A machine on Machines lists only the sessions of the project you're in, and
its pane count and what needs you count only theirs. Home's Needs you, its
boards and their leads read the same way: a session placed in no project is
yours only on your own machine and in your personal project, so a
teammate's unplaced panes don't count, and a board's lead is found in that
board's project, not by a session of the same name in another. Both apps
read one rule from the shared core, the web's.

The machine list is in the phone's order: your online machines, the one you
used last first, then teammates' online machines, by name, then the offline
ones. Switching projects while Home loads no longer leaves the last
project's hosted sessions, asks or ideas on the new one's Home.
