title: Docs no longer copy to the cloud
line: Your machines' Docs stay on your machines, with no copy in the cloud, and a Doc you give a team is moved there, not copied.

A machine no longer copies its Docs up to your Docs on the platform, and **Your Docs on the platform** is gone from Teams. A Doc on your machine reaches others by its public link, or by moving it to a team's project, where the team owns it and nobody keeps a copy. **Share with…** and **Update copy** are gone with the copies.

Docs you wrote on the platform outside a team stay in your cloud. The Docs page says so above them, and each one's ⋯ has **Move to <team>…** and **Download**, which saves it as Markdown: its title, then each section. Its pictures are left out, and the file says so at the end.
