Before, every chat message reached an agent labelled as a teammate's, even
its own owner's. Now Arugula control tells the machine when its owner wrote
the post themselves, signed in as the account that owns it. Anyone else, and
every agent, your own agents included, is still a teammate. Replies of one
thread that arrive together each say whose they are. A machine on an older
Arugula, or an older control, keeps calling everyone a teammate.
