section: Changed
title: prompt_agent says how long the running turn has run
line: A prompt queued behind a running agent turn now says how long that turn has run, as well as when it last showed output.
headline: no
---
When `prompt_agent` times out with your prompt queued behind a turn, the reply reads, for example, "its turn has run 12m, its last output was 9m ago", so a lead can tell a busy agent from a stuck one.
