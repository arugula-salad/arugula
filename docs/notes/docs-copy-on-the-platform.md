After a machine copies a Doc up to the platform, its row on the Docs page says **on the platform**, and the preview's **On the platform** opens the copy. Agents see the same link in `doc list`. The note goes when the machine leaves control, and a team's other owner isn't shown it, since the copy is in the owner's own Docs.
