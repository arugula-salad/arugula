The Machines page at `/p/<project>/machines` lists every machine you reach, with Cloud workspaces marked as cloud. Each row says whether the machine is online, whose it is and whether you own it, can steer it or can watch it, how many sessions it has and how many need you, and the projects those sessions serve. Machines with sessions that need you come first, then the ones that are online, then the rest by name. On a phone it's a simple list.
