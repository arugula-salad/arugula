The account button is named by the login it shows, and a project's "All
boards ›" link says so. A Doc's link in a list of Docs is underlined, so it
isn't told from the text around it by colour alone. Appearance's palette
previews draw the colours the page will use, not the palette's raw ones, and
Copy reads at 4.5:1 on Latte.
