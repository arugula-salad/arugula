In Claude Code conversations, one that's running in a terminal outside Arugula on this machine now offers Move here instead of a greyed-out Continue here. It asks Claude Code there to stop (as Ctrl-C would, then a polite terminate; never a kill), waits for it to let go, then continues the conversation here with its history. If it won't stop, or isn't yours, it stays running and you're asked to quit it there. Fork here (it was Fork) still starts a new session from it without stopping anything.
