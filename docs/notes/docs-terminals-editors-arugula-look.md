section: Changed
title: Docs, terminals and editors in the Arugula look
line: Terminals, editor blocks and nvim are drawn in your look, on the same dark well as the panes; Docs wear Arugula's own colors; terminals use SF Mono.
---
A terminal's background is now the well it sits in, and its sixteen colors are the look's, each readable on it whatever preset or sliders you pick. VS Code and nvim blocks follow the same look. A Doc reads the same for everyone, in Arugula's own dark or light colors: its paper, ink, links and the named colors an agent draws with (leaf, pepper, sky, plum, sun, stone) changed with it, on the page, a shared link and the daemon's drawings. Terminals and agent output use SF Mono, falling back to the system's mono.
