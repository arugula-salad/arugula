A to-do is a task an agent can't do itself, such as an approval on GitHub or a script that needs your credentials. On iPhone, iPad and Android it now appears under the Overview's Needs you as well as in the Inbox. Tap the row to open it in place. It shows why the agent can't do the task and its steps in a monospaced box, with Copy. Add a note if you like, then tap Done or Can't. Your answer wakes the agent that asked, and your note goes only to that agent, so don't put a password or key in it. If the server turns the answer down, for example because the to-do was already answered, the row stays and shows why.
