title: Sharing a team Doc from its page stores the link
line: A team Doc's public link made from its page or the Docs list now opens; the page sends the sealed copy through the platform.
headline: no
needs: control
---
The page sealed the Doc and then sent it to an address only control answers, so a link made from the page never got its content. The page now puts the sealed parts through the platform, which checks that you may edit the Doc and passes them on. They are sealed in your browser, so neither the platform's relay nor control sees the Doc in the clear, and control still never has the key.
