title: Screen readers read the sessions and tabs
line: Screen readers read the session list and the tabs properly, a tab's close button is easier to hit, and the Commands button is named for what it shows.
headline: no
---
The session list is a list of groups, each with its heading and its sessions,
and a session's menu and its other buttons are reachable beside it, not inside
it. A tab holds only its name; the shown tab's close button sits beside the tab
list and is 24 by 24 pixels. The Commands button is named "Commands" and its
key chord, as it shows, so saying what you see to voice control works.
