title: List pages use the one button set
line: The Docs page and the Issues, Runs and Sessions pages, and Boards' answers and filters, draw their buttons with the app's one button set, with one main action and the rest under ⋯.
headline: no
---
The Docs page's Open is the page's one primary button, Cancel on a new Doc
is a secondary, and the ⋯ on a page's head is the bar's icon button. The
filters on Issues, Runs and Sessions are secondaries, accent-coloured when
one is set, so each finish (Aqua, Brushed metal and Glass) draws them as it
draws the rest. A Board's answer options and its Label and Person menus are
secondaries too.
