Open a project's settings on the Projects page: Access is the first section. It lists the team's roles; whose machines can act in the project because they're joined to a member's account, and what that reaches; every power a member gave their machines' agents or an agent token over the project, with whose it is and a note when it does less than the power now; whether an owner allowed cloud workspaces and runs with every device asleep; and the project's cloud workspaces, where an editor has full use. Each part says whose word it is. Nothing on it changes anything: it's a view. The same view prints with `arugula grants ls --project NAME`.
