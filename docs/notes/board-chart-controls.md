section: Changed
title: Board chart controls moved
line: On a board, Close epic is a quiet button beside Lanes and Steps, and Done and a new Links toggle sit above the Steps chart. Links shows every arrow until you hover a row.
---
Close epic moves to the right end of the Lanes/Steps row and turns red only on hover or focus. In Steps, Done and Links sit in a small row above the chart, with an icon and a label (icon only on a phone). Links is on by default and remembered in this browser: on, every arrow shows and hovering or tapping a row shows only its own; off, arrows show only for the row you hold.
