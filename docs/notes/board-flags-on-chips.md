title: Board flags sit on the chip

needs: control

Failed checks show as a red `cloud#16 · checks failed` chip, an agent waiting for input as an accent `waiting for you`, and a stalled agent as an amber `stalled 2h`. A small dot before the title marks a row that needs you, and **Needs you** counts the same rows. A real question keeps its card.
