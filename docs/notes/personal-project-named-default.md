section: Changed
title: Your own project is named Default
line: Your personal project shows its real name, Default, and the label over your own projects reads Just you.
headline: no
---
Your personal project used to show as Personal, whatever it was called. It now shows its own name (Default, unless you've renamed it), on the hosted machines and run grants pages and everywhere else a project's name is shown. The owner label over your own projects, in the breadcrumb, settings, the move page and `arugula project list`, reads Just you. The `personal` address and `arugula project use personal` work as before.
