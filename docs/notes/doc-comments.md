section: Added
title: Comments on Docs
line: Click a paragraph of a Doc to comment on it; comments sit in the margin beside it, and reach the agent that wrote the Doc.
---
A comment is a message in the Doc's thread that links to its section and quotes the passage, so the thread and the agents reading it see what it's about. It mentions the agent session that made the Doc; Docs made from now on record it. On a narrow screen the comments are listed under the Doc. Control also serves a page that's only the Doc, for the iPhone and iPad app to show.
