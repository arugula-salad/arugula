- **One list per scope.** You, Project and Team each show their sections as rows, with what's set on each line. A row opens in place, and a link opens it.
- **Appearance is Look's.** Theme, preset and the sliders are in Look (`s`, or Look in the top bar). Tips, the editor and lending this device are under Preferences.
- **Add a machine is on Machines.** The join command moved from a project's settings to Machines' Add a machine.
- **The Agents row** holds the model, workspaces, the standing grant, CI alerts and Claude spend.
- **A team's page is Settings › Team.** Old links to it, to Appearance and to the sections that merged still land in the right place.
