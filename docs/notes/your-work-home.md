Your work replaces the Claude Code conversations picker. Each repo shows its three newest conversations, then *N more*. A row's button continues it in a terminal pane, goes to the pane that has it, or, for one running in another terminal, moves it here. `⋯` has *Open as agent block* and *Fork here*. Conversations from every Claude Code entrypoint are listed now, not only the terminal's, the desktop app's and VS Code's; `claude -p` and SDK runs stay out. The Open now and All switches and the cost column are gone from it, and the "Pick up a Claude Code conversation" tip is retired.
