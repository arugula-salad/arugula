A lead is named by its Claude Code conversation's title, and Overview looked for it only by the name of the session its pane sits in, so a terminal's lead on your own connected machine read as "Watching … which this page doesn't reach". It now finds the pane by its title too. Where a session of yours really can't be read, it says which machine isn't connected to the page instead of calling it someone else's.
