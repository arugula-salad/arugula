---
section: Fixed
title: An agent can always continue a Doc it opens
line: Opening a Doc another agent or tab already has open now gives the agent a block of its own to fill, and says what each unwritten section was meant to hold.
headline: no
---
Before, `doc open` handed back the block that was already open even when the agent couldn't write to it, so the next fill was refused and no one could carry on. Now the agent gets a new block beside its pane, and the reply names the other one. It also lists each section: filled, or pending with its intent.
