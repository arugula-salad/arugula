section: Changed
title: Continue here resumes in a terminal
line: Continue here on a Claude Code conversation opens a terminal tab in its folder running your own claude --resume, with nothing to install first; Open as agent block is still there.
---
The conversations list's first action now opens a new tab, named after the
conversation, in its folder, running `claude --resume <id>` with your own
Claude Code, its login and its settings. A conversation already open in an
Arugula pane or agent block goes to it. If its folder is gone, the list says
so and offers to run it in your home folder. *Open as agent block* shows it
as an agent block, as before, and forks it from there. An agent's `show`
kind `conversation` still opens an agent block.
