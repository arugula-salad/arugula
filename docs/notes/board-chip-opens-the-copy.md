A machine Doc linked to a board (`board_write link_doc`) showed the title it had when it was linked, and opened nowhere with the machine off. Where the Doc's copy sits, a board of your own project, the chip now shows the copy's title and how much is written, and opens the copy. On a team's board the chip keeps the title it was linked with.
