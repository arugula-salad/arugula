---
section: Added
title: A team Doc can have a public link
line: Share a team Doc with a link anyone can open, from its page, the Docs list or doc share, and update or stop it any time.
needs: control
---
A team's Doc can now be shared with a public link, as a Doc on your own machine can. Owners and editors make it from the Doc's page or its row in the Docs list; the page says when the link shows an older version, and Update brings it up to date. Stop sharing takes it down, and so does deleting the Doc. Any member who can read the Doc sees the link; a viewer can't change it.

An agent's `doc share` on a team Doc asks the owner first, with the same card as a Doc on a machine: nothing is made public until they tap Share.

The link's key stays with the Doc on the platform and in the link's address; control only holds the encrypted copy.
