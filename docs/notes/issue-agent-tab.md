An agent working on an issue opens, from its chip on a board's ticket or as the first tab at the ticket's own level, as that issue's thread above its last lines; a post in the thread prompts the agent leading it, and when another session leads the thread, or none does, the tab says so and keeps a box to write to the agent directly. Under every agent tab's head, which says where it runs and whether it's awake, a line gives its rung ("lead of Launch", "on #12 for Launch", or the chief of staff's project) and who started it, and the next its parent's newest post to it: the board lead's in the issue's thread, the chief of staff's in a lead's board threads. At a ticket's level the issue agent's panes come before its helpers'. An agent a Claude Code terminal starts through MCP now records that terminal's pane, so it can be named as the starter.
