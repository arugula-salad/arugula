section: Changed
title: A Doc's Copy link copies at once
line: The link icon on a Doc, and Copy link in the Docs page and the block's menu, copy the Doc's link with one click: no dialog, no Done.
---
It copies the Doc's public link if it has one. Otherwise it copies the Doc's copy on the platform, which only you can open until the Doc is shared with the team ("Copied ✓" says so in its tooltip). A Doc with neither has Copy link switched off, saying why. Making a public link still takes the Share dialog's Create link.
