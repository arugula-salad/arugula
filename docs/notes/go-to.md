section: Changed
title: Go to… replaces the command palette
line: "⌘K (Ctrl+K, or Ctrl+Shift+K from a terminal) opens Go to… on every page: your projects where you left them, boards, Docs, a machine's tabs and panes, then the commands."
---
Go to… is one overlay for getting anywhere. Empty, it lists what you picked last; typing matches the start of words across your projects, their boards and Docs, and the machine you're on's sessions, tabs and panes, with commands ranked under places. `g p` opens it too. The rail's project tile opens it as a list of projects, each where you left it with what's for you there; New project… and New project from… are there. It replaces the command palette (Ctrl+Shift+P) and the project switcher; Ctrl+Shift+G (Go to directory) is now a command in it. It lists 25 of the menus' commands, not every menu row: the rest stay in each pane's, tab's and session's menu.
