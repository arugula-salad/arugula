Docs is a place on the rail of both pages, after Chat, wherever control has a platform page. It opens `/docs`, which shows Team Docs first; Mine is one click away and remembers your choice in this browser. A Doc that is a copy from a machine says which one. A machine on its own keeps its Docs page as it is.
