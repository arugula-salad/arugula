The chief of staff never starts or stops a session itself, and nothing said in chat approves one. It asks with `ask_approval`, a tool every agent session now has. **Approve** does it as you: **Agent on this** on the issue, or each session's **Stop**. Either answer wakes it through a new event, `ask.answered`. For now a card starts sessions only on native issues, on the project's Cloud workspace. See [the chief of staff](../chief-of-staff.md#approval-cards). Needs the next server release.
