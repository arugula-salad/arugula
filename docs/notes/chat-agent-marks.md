An agent's message shows the agent icon in a teal-ringed circle on its avatar,
and its name is its tab, written the way a mention tags it, such as
`aarons-mac-mini.local/ux-improvements`. The old "AGENT" badge and the
separate session name are gone. Click the name to open that pane when the
machine is yours or shared with you; on someone else's agent it is plain text,
and its tooltip says whose agent it is. Search results, threads and saved items
name an agent the same way.

A reaction chip counts people first, then a teal divider and the agent icon
with the agents' count, such as `👀 2 | [agent icon] 1`. Clicking it still toggles your own reaction.
