section: Changed
title: A run beside a board shows the run
line: A run that you or the lead open beside a board shows its page there (its state, timeline and log) instead of a link to it.
---
A run opened beside a board, by you or by its lead, now shows the run's own page in the pane: its state, what started it, its timeline and its log, kept current while it runs. The pane's × closes it; the run's page is still at its address.
