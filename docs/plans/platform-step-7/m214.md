M214: triggers: manual, schedules, events

Part of #TRACKER. Needs M212.

## What

- **Manual:** API, MCP (M216) and `arugula run --project <p> -- <cmd>`, or a named run spec.
- **Schedules:** cron-style, per project. The platform schedules, and the machine executes. That answers the open question in `docs/platform-features.md`.
  - A missed tick while the platform is down runs once, not many times.
- **Events:** rules matched on step 4's GitHub ingester: PR opened, check failed, push to a branch.
- **Run specs live in the project,** as rows edited on the page and CLI. A file in the repo can come later if asked for.

**Done when:** each trigger starts a run on testnet, and a schedule survives a platform restart without double-firing.
