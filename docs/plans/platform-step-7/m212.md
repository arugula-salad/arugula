M212: the execution contract on hosted arugulad

Part of #TRACKER. Needs M210 and M211. This is M89's daemon half. M86's permissions refactor stays out.

## What

- **Hosted `arugulad` advertises that it takes work,** and pulls the pending operations for its machine.
- **For each operation, it:**
  - verifies the standing grant and the operation's hash;
  - writes its ledger (`<state>/work/ID.json`) **before** it starts anything, so an id runs at most once;
  - runs the operation in a pane, so the live view is the ordinary end-to-end pane;
  - reports state changes, signed.
- **A run that needs the workspace awake** wakes it (step 5's M182), and holds it busy so it doesn't pause mid-run (M181).

**Done when:** on testnet, a run executes once even when the platform sends it twice, survives a platform restart, and its pane is watchable from the phone.
