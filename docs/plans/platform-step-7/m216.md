M216: MCP and CLI for runs

Part of #TRACKER. Needs M214.

## What

- **MCP:** `start_run`, `read_run` (state, log, paged), and `wait` on a run.
  - Scoped to projects the machine has a grant on.
- **CLI:** `arugula run --project`, `arugula runs list`, `arugula runs show`, `arugula runs logs`.
- **Agents may start and read runs.** Deploys are M218's, and they're different.

**Done when:** Claude on geek starts a run on a project's hosted workspace, waits for it, and reads its log.
