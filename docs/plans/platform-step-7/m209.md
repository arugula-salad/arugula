M209: per-project envelope keys for secrets

Part of #TRACKER. Needs M207. Comes before any deploy credential is stored.

## What

- **Each project's secrets are sealed with that project's own data key.** The key is wrapped by the platform's master key (`ARUGULA_CLOUD_SECRET_KEY` today).
- **Re-seal what's already stored,** in one migration that can run more than once safely.
- **Rotating the master key re-wraps the data keys.** The secrets themselves aren't touched.
- **A checked-in list of environments whose secrets exist,** next to `tables.toml`.

**Done when:**
- A test shows that a project's key can't open another project's secrets.
- Rotation works on a copy of production's data.
- Jake has the master key escrowed in Infisical (ask).
