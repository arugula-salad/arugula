M217: environments and deploys

Part of #TRACKER. Needs M210.

## What

These go in both dialects, with `tables.toml` rows.

- **`environments`:** project, name, driver, and the names of its secrets (sealed by M209).
- **`deploys`:** environment, source (commit or artifact), plan digest, state, the run that applied it.
- **`deploy_events`:** append-only, never updated in place. Each event has a hash chain, so anyone can verify the log.
- **The stale rule:** a deploy planned before another apply to the same environment can't be approved.

**Done when:** db tests cover the stale rule and the hash chain on both dialects.
