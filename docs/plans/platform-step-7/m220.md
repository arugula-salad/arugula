M220: the chant→Fly driver

Part of #TRACKER. Needs M219.

## What

- **Apply runs `chant run release`,** then `chant approve` as the approver's identity.
- **It writes chant's ledger** for the release. The platform links to the ledger entry from the run record (M207's run-records decision).
- **The Fly token is a deploy token scoped to one org,** sealed in the project.
- **Roll back** through chant and Fly's own rollback.

**Done when:** a test project on Fly deploys and rolls back through the platform, with the chant ledger entry linked.
