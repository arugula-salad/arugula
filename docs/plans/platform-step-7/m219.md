M219: drivers: a run with a credential

Part of #TRACKER. Needs M212, M218 and M209.

## What

- **Applying an approved deploy enqueues a run** on the project's hosted workspace.
- **The environment's secrets are injected for that run only,** then gone:
  - never written to the workspace's disk;
  - never in a pane's scrollback.
- **Short-lived tokens are preferred** over stored ones: installation tokens, Fly deploy tokens scoped to one org.
- **A driver interface:** plan, apply, verify, and roll back where the target can.
- **A driver failing mid-apply** marks the deploy failed and pages Jake, with the run's log attached.

**Done when:** a fake driver applies an approved deploy on testnet, and a test shows the secret isn't on disk afterwards.
