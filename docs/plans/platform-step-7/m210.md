M210: run rows: runs, events, artifacts

Part of #TRACKER. Needs M208.

## What

These go in both dialects, with `tables.toml` rows.

- **`runs`:**
  - global id (`run_`), project, workspace;
  - trigger (schedule, event or manual, with its source);
  - the spec (an S37 operation and its hash);
  - state, using S37's eight states;
  - who or what started it;
  - start and end times, exit code;
  - an optional chant ledger link.
- **`run_events`:** append-only state changes, each signed by the daemon that reported it.
- **`run_artifacts`:** name, size, digest, bucket key.
- **The name "Run" is free,** because cloud runs were retired.

**Done when:** db tests on both dialects cover every state transition S37 allows, and refuse the ones it doesn't.
